## Functional boundary

The preceding original SHA-chain `NATIVE_RENEWAL_PROPOSAL_VALIDATED` event guarantees the untrusted one-shot free response is bound to the exact original send/handoff and the existing native proposal validator. A new event by itself does not authenticate public Git source at the future publication moment, show the original protected owner policy remains enabled, compile a native candidate against the V1 contract or prove no matching draft branch/PR already exists.

`f139/nci04_v19_original_publication_preflight_no_write.py` adds `preflight_original_v19_candidate_without_writing`. Under existing original `SingleOwner` and an independent owner witness, it requires a fresh cold-valid original SQLite chain, exact original current-head candidate-validation event, original enabled, legacy suspended, no READY/active tasks, unchanged owner SHA and candidate source bytes SHA. It then:

1. Rebinds to the authentic previous original free-model handoff and its exact original lane, target SHA, file path, history and public tree.
2. Independently verifies the source's anonymous public Git commit/tree/file/blob bytes **again**; on denial, the caller has no source permission. No remote POST, no token and no private owner data reaches a provider.
3. Uses the **existing** original publisher's `_verified_original` to recheck protected FORGE main/source continuity and authentic owner policy issue #807; disabled or changed owner policy blocks this preflight.
4. Uses existing `_semantic_identities`, `prepare_proposal` and `parse_intent` to compile a **single native V1 candidate intent** for the exact one allowed public source file, with its before/after SHA and fixed qualification semantics; no arbitrary command, worker execution or science authority.
5. Uses existing original `_publication_history` and `_unique_branch` to refuse ambiguous historic draft writes and to examine matching refs and bounded paginated PR history for repeated candidate branches. On moved/occupied branch or unstable PR history, fail closed.
6. Cold-verifies that the original SQLite event-head and owner witness remain unchanged after these read-only provider operations. Returns a source-only public-draft manifest with candidate ID, original owner SHA, blob hashes, exact branch, compiled intent and `publication_authorized=false`, `original_write_calls=0`, `provider_requests=0`, `worker_dispatched=false`, `scientific_first_use=false`, `accepted_ref_mutations=0`.

All Git queries in the new tests are **fake GETs** and all original SQLite writes are isolated test fixtures; the live original DB, Windows task, actual GitHub source, model provider and free credentials are not touched. No separate scheduler/controller/queue, no paid APIs or CKB-plane.
