# F101 — Four actual learned public-development prototypes

**Scope:** F101 progresses the independent preregistered F100 designs from source-only hypothetical mechanisms to **actual bounded trainable prototypes** on newly frozen PUBLIC development data. Neither protected research original nor unattended GPT inference is executed.

- F99 original Wingless W-F10 and Yggdrasil Y-F9 historical DEV outcomes remain frozen negatives.
- F100's complete four-candidate hypothesis, controls, public seed blocks and threshold contract was committed first and qualified under [PR #376](https://github.com/spoonman136668-ai/FORGE/pull/376).

- F101's trainable implementation follows in `nativeevidence/f101_public_mechanisms.py` without changing the F100 threshold values or earlier parent experimental records.

## What genuinely executes

**Wingless W100-C1** uses a depth-aware recurrent soft relational propagator. **W100-C2** uses learned, query-sensitive soft observation/edge gating. **Yggdrasil Y100-C1** learns one-dimensional edge and query-role embeddings. **Y100-C2** uses two-component learned role-slot compatibility, invariant to arbitrary intermediate node renaming.

All four are small learned parameterizations, not answer tables and not coded oracles. Their weights are optimized through a deterministic bounded coordinate finite-difference cross-entropy method: at most **100 updates per model**, with no more than 19 trainable parameters per candidate, and no external inference provider. The matched public seed sets contain 32 training pairs and 16 development pairs per lane, fixed before implementation.

Every candidate is trained in three independent settings: complete information, size-matched missing-information ablation, and randomized-query ablation. Always-yes and original blind negative baselines are retained; a coded graph-traversal oracle is evaluated **only as a nontrainable control**. No predicted truth label is passed to a learned model or into randomized-control query selection.

The DEV report must include all four candidates whether positive, negative or mixed. The registered F100 development-only thresholds are checked as precommitted; they **cannot** confer first-use permission or imply independently accepted science. Any actual generalization gap is preserved as a negative finding.

## What this does not do

F101 does not issue new science first-use grants, use protected or sealed original seeds, dispatch Wingless/Yggdrasil workers, mutate accepted references, change optimizer production policy, connect CKB-plane, call Codex, use ChatGPT Work tasks or pay for an API. A GitHub-hosted deterministic training run is **not** itself autonomous GPT research.

F101 only runs under the **existing** FORGE integrated synthetic six-hour GitHub-hosted workflow, with real public development reports and SHA-256 artifacts on Ubuntu and Windows. The F98/F99 independent archive intake remains optional and quarantined separately. Full exact-head Linux/Windows qualification, adversarial tests and honest negative preservation are required.
