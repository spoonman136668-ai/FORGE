In each fresh **48-pair** public test block, every one of the 16 query-depth × true-source-position combinations occurs **exactly three times**; no query-only rule can exceed a 25% paired score. The assignment is frozen and shuffled independently within each query, rather than obtained by a source-position offset. New, disjoint diagnostic seeds are 69048–69095 (W113-A, query string differs from source ID by one substituted character), 69100–69147 (W113-B, transposed characters), and 69200–69247 (W113-C, deleted character). Source codes are sampled independently of the positive/negative labels, and only the correctly requested observation's sign changes across a pair. The requested code is never an exact equal string to any observation source code.

The prior F112 six-weight differentiable *engineered-feature* similarity metric is retrained for precisely 100 updates on **96 newly frozen public training pairs**, seeds 69000–69031 (three examples each), never on diagnostic data. Controls receive the same public query and source string information: the untrained six-feature similarity metric, an independently trained 64-parameter query-only attention baseline with the same 96 training examples/100 updates, the older F109 offset model with no privileged mapping, and a **deterministic edit-distance matcher** (computing source choice from public strings, then reading only one observation). The latter is a strong algorithmic control and is expected to be hard to beat; perfect public string matching does not establish neural representation learning. The coded truth is separate from the learned inference path.
