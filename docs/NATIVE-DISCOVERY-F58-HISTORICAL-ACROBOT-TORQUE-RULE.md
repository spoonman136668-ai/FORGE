## Frozen estimator family and fair controls

Use the exact existing F51 public 15-dimensional features `phi(obs6)` for each recorded step (no hidden physics state). Original recorded actions `a in {0,1,2}` encode torque `t=a-1 in {-1,0,+1}`. Target is the **actual recorded** two-component angular velocity increment, `y = [(v1_next-v1)/(4*pi), (v2_next-v2)/(9*pi)]`; use equal component weighting (per-record MSE = mean of the two squared normalized errors), preserving both physical channels. Clip **neither** targets nor predictions. All models use a single ordinary closed-form multi-output ridge fit, exactly `lambda=0.05`, all columns penalized identically and no hyperparameter search.

Four predetermined arms:
1. `factorized-torque` **candidate**: 30 features `[phi, t*phi]` for a shared drift + signed action-effect rule. The learned torque coefficient must arise from logged experience, never hard-coded simulator dynamics.
2. `action-specific-ridge` **strong conventional**: fully trained 45 features, one separate 15-vector for each action, with all actions represented in training. This is the primary strongest expressive baseline.
3. `action-blind-ridge` **conventional negative**: one fully trained 15-feature model from public state only, no action input.
4. `shuffled-torque` **credit negative**: same 30-feature factorization, but independently shuffle training-action labels with NumPy `default_rng(581000 + heldout_root)`; retain original true labels for excluded-root scoring. All other data and regularization unchanged.

All four get one fit with the same recorded actions/consequences and wall-time measurement. The negative shuffled arm deliberately breaks action→outcome credit in training. Each model must report feature count, source/training row identities, per-fold fit time, inference time, predictions and finite costs. No optimizer or code generation, no randomized model search, no paid services.
