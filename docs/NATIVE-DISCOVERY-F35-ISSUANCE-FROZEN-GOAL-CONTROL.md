## Distinct mechanism and falsifiable hypothesis

F34 found that replaying an old issued action with the current environment hypothesis can invent a second effect or lose its true effect. F35 replaces raw-history reinterpretation with a bounded **per-issued-event latent-state particle filter**. At the instant action1 is selected, create separate particles for each learned event hypothesis (mask and due time), store the immutable `due=t+lag-1,mask` in each particle, and propagate pending receipts through later regime changes without rewriting them. Each particle has a hidden-state *belief weight* but no hidden simulator state. On every actual sensor observation, multiply its weight by the correct sensor emission likelihood and normalize, merging identical (state, pending events) particles. At most two overlapping issued events can be outstanding in this every-other-step action schedule (lag≤3). Do not use true law or event queue from environment, oracle phases or upcoming observation.

The candidate is **four-hypothesis issuance-frozen**: learned A/B/C/D action mask+lag templates from exactly the same F32 isolated-pulse training data (A/B physical training only); current regime weights drive the distribution of newly issued event hypotheses. Previously issued event particles retain their due+mask; later regime reweighting can affect *new* action events only. The world-state belief is recurrent across observations, not replaced with each new pair of sensors. Regime weight updates use F32's original sensor-based evidence; no correct hidden phase or state. The candidate trains NO extra source observations and uses the same action decision threshold (strict P(goal|action1)−P(goal|action0)>0.05) and 24-action limit as controls.
