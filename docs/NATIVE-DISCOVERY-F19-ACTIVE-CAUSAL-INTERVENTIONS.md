## Hypothesis

With two outcomes still pending, a bounded causal learner can select genuine diagnostic actions to reduce uncertainty about an unobserved action-consequence law more quickly than six well-trained conventional active-learning policies at the same observation and action budget. Candidate: **pending-aware counterfactual partition selection**; controls include exhaustive pending-aware lookahead, exact one-step information gain and other conventional adaptive planners. Realized intervention value is measured on a uniformly enumerated causal probe suite *before* each scheduled reveal, not on an invented model score or terminal prediction alone. The strongest of all six conventional policies is the comparator; a tie or loss is a NO_GO. This hypothesis is expected to be difficult because exhaustive Bayesian exploration is an equally informed, same-class control.

## Frozen arms and causal environment

- Four DEV-only independent arms: synthetic seeds **107** and **109**, each under cue schedule **confounded** or **varied**. The world generator alone sees hidden rule IDs seed107=**3** and seed109=**11** (both action-sensitive). All learners use the same 8 identifiable masks from F18: `[0,1,2,3,8,9,10,11]`, which exactly span causal `f12Next` under phase 0. Seeds 59/83 and other independent first-use sources may not be accessed.
- Each policy controls **18 actual actions** on its own independently evolving state trajectory, starting from exactly the same seed-specific state. Every policy receives the same exogenous cues, step count, delivered two-step-delayed effects and action alternatives, but **never** the hidden law, world seed, unrealized counterfactual outcome or future label. `confounded` cue parity is `step&1`, so the passive comparator's action duplicates the cue; `varied` cue parity follows `f12Cue(seed,step,1)&1`. Both current and next exogenous cues are publicly provided to *every* planner and derive from the predeclared schedule, not the target rule. No oracle action decisions.
- At step t, **only the actual effect of action t-2 becomes credited**; two more actions remain pending. The policy selects action t using credited records, cue now, cue next, and its own previous pending action/cue pairs. The simulator then applies actual `f12Next(trueLaw,state,0,cue,action)`; unselected action results are not simulated as feedback to the learner. The oracle scorer knows the rule but cannot pass it back. Exactly 16 effects credited and 2 pending after step 18.

## Precommitted policies, controls and costs

All classifiers use exact maximally consistent (uniform tie) posterior over the 8 observable law masks on genuinely credited transitions, same model class, identical source information and no parameter tuning. If noisy/inconsistent records eliminate full consistency, choose masks achieving the maximum fit count, without inspecting the true rule. An action's hypothesis signature is its predicted binary causal XOR residual `(rule&1)*action XOR (rule&2)*(cue&1) XOR (rule&8)`. Hypothesis-partition collision cost is the sum of squared per-signature bucket sizes (exact integer work, no stochastic oracle).

1. **Candidate `pending-aware`**: minimize partition collision for the two *already-pending real interventions* and a proposed current action; tie-break in favor of action differing from the current cue parity, then lower action. This is a bounded greedy information-separation heuristic, not a hidden true-law estimator.
2. **Strong `queue-lookahead` conventional control**: exhaustively evaluate all four current+next action pairs using the same pending signatures and the publicly known next cue. Minimize partition collision, tie-break on lowest action pair (and choose the pair's first action); this is a stronger two-action planner.
3. **`two-step-ig` conventional control**: exhaustive current+next action pair partition, ignoring pending interventions; exact information planner.
4. **`one-step-ig` conventional control**: maximize exact binary posterior disagreement for the current action.
5. **`thompson` conventional control**: deterministically seeded posterior-index exploration via step and credit count; selected hypothesis favors an action producing nonzero intervention residual, with a fixed tie-break.
6. **`balanced` conventional control**: action `step&1`, no learned causal heuristic.
7. **`passive` conventional control**: action equal to current cue parity; this is a deliberately confounded negative-relevance comparator but never the strongest sole comparator.

Mechanistic ablations, *not* replacing conventional strong controls: `no-intervention` always action 0; `wrong-credit` uses the same pending-aware search, but learns using the existing one-step-shifted wrong-action/wrong-cue attribution. For comparable impact, both are scored on their own actual actions and matched causal-probe metric. No free intervention, extra information, more actions, additional model capacity or paid API.

For each arm, fixed checkpoints just before the action decisions at t=**4,6,8,12** (respectively 3,5,7,11 credited effects, because feedback for action t-2 arrives before the action-t decision), score the model's lexicographically first maximum-likelihood mask on **all 4 prior states × all 4 cues × both actions = 32** causal transitions without exposing any label to the policy. Total **128** correct decisions maximum per policy. This measures offline causal generalization after *real interactive action choices*; the score is computed only by an isolated evaluator. Also record the 4 checkpoint scores, actual action trace, credited and pending counts, candidate non-passive intervention count, full source/checkpoint SHA-256, deterministic partition/rule-match work per policy and the full conventional-control outcome set. Work counts are not wall-clock time, energy or end-to-end training cost.
