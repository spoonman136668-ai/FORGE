## Scope and mechanism

* `f139/rsi_r3_source_cycle.py`: finite four-option Python expression grammar; exact source-byte/hash identity; source-only generation function that executes only the exact reviewed parent snippet with `max` as its sole builtin; immutable G0→G1→G2 lineage; bounded and validated integer feedback; rejection of repeated operators and source tampering. The grammar is intentionally small and unprivileged. It does **not** implement arbitrary code generation or science selection.
* `f139/test_rsi_r3_source_cycle.py`: the original generator chooses G1 option 1, and the **generated** G1 source chooses a *different* G2 option 3. A negative control proves using original G0 for the G2 step would choose option 2. Additional tests reject counterfeit parent SHA, changed history, invalid sources, duplicate rows, invalid metrics and generation budget drift. Tests are deterministic synthetic development fixtures, not hidden benchmark trials.
