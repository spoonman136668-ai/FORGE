# F96 — frozen source-level comparator for real F95 implementation

**Scope:** Optimizer method engineering only. The separate FORGE Gate Advancement workstream owns autonomy, scientific owner/witness, first-use permits and deployment. FORGE never requires CKB-plane. Mind-Palace is a read-only context source, not scientific authority.

## What is authentically frozen

Sixteen deterministic relationship-composition cases covering eight condition categories were committed to `noveltyeval/f96_cases.json` at Git commit `dcb7777199fcaf9d52d78ef9961fc73e2e018911`, **before the evaluator source was added**. GitHub-hosted `cmd/f96eval` reads the exact frozen historical Git blob and demands byte-identical equality to the current worktree. Source edits after freezing fail closed. All 16 case results, including failures, are output, not a favorable subset.

**Critical distinction:** The benchmark was prepared by the engineering workstream, not an independent scientific authority. Git chronology alone does not create a blinded holdout, independently witnessed first-use or scientific acceptance.

## Four legitimate comparators under the same 16 source-visible tasks

1. **F95 typed relation composition:** the actual independently compiled F95 implementation in `noveltymechanisms`.
2. **One-hop typed lookup:** a bounded shallow baseline, intentionally unable to process long chains.
3. **Role-blind graph reachability:** a genuine multi-step connectivity baseline ignoring relationship names; exposes spurious shortcuts.
4. **Independent typed-graph reference:** a separate implementation of the full same typed composition operation, deliberately a **strong positive parity control**. Tying this reference is evidence of correct source-level implementation, **not** evidence of generalizing or being scientifically superior.

The tasks cover four-, five-, six- and eight-step composition, role swaps, role-insensitive distractors, branching/ambiguous targets, cycles, missing roles, correct edge direction, and single-hop checks. Expected outputs are frozen with the cases, verified against the independent equivalent reference first; a disagreement blocks the source-evaluation tool.

The evaluator records every target set, correct/incorrect classification, error type and per-control denominators. Failed cases and errors stay in the JSON artifact. No results are relabeled as positive scientific learning labels. The exact Git source readback creates a JSON and SHA-256 receipt in GitHub Actions; this **45-day Actions artifact is not a durable Mind-Palace raw-evidence archive**.

## Scientific evaluation boundary

The provided cases are unsealed, manually authored source fixtures. Even if F95 beats the weak controls 16/16, the equivalent reference is supposed to tie it. Hence no scientific superiority, zero accepted originals, zero independent prospective outcomes, zero scientific holdout use, no Dream-RSI/Pareto promotion, no ThetaEvolve accepted-result training and no controller/Cloudflare modifications are permitted.

The scientific successor requires a separately prepared frozen unseen-task cohort, authentic independent source and first-use custody, matched budget/strong controls, registration before execution, complete negative/invalid results, independent causal acceptance and durable evidence retention. That belongs to the scientific authority path and cannot be manufactured by this benchmark.

**F96 success definition:** actual code runs against pre-evaluator committed cases, all controls execute, exact typed reference expectations agree, negative controls are retained, source readback is authentic and the same code passes the full FORGE regression. It is a positive engineering gate, **not a successful original scientific experiment**.
