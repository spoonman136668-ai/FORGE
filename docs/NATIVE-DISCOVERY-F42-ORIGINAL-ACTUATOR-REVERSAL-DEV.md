## Frozen eight-arm comparison and intervention budget

All eight policies run one independently reset original environment per seed, at most 200 actual steps, all real action consequences charged; same 96-episode trained dynamics and 0..16 intervention-probe budget. A probe changes the **requested action** to 0 or 2, alternate by fixed `t//12` parity, at t divisible by 12, for at most 16 probes. Probes do not add extra physical steps or access future responses; report their actual number.

1. **contradiction-probe candidate:** starts assuming normal actuation. At any step with informative L, append its signed evidence to a bounded last-three queue; switch the assumed mapping only if **at least two** of these three observations favor the currently opposite hypothesis with |L|>=0.9, then clear the queue. Fixed periodic 12-step probe schedule (up to 16). Hypothesis state persists across returns, but not across independently cold-restored evaluation worlds.
2. **bayes-probe strong adaptive control:** same periodic probes and trained planner; before each likelihood update, mix posterior reverse probability toward 0.5 by hazard 0.03; Bayes update with clipped L, choose reversed if posterior >=0.5, prior p=.02.
3. **bayes-no-probe strong adaptive control:** identical Bayesian filter, no forced probing.
4. **rolling8-probe strong adaptive control:** same probes, last 8 informative L values, select reversed iff their sum is strictly positive.
5. **fixed-mpc strong conventional control:** global linear planner trained identically, always normal channel assumption, no probes, no online adaptation.
6. **velocity-rule strong conventional control:** F41 public momentum-following rule, no probes, same source-training observability and physical action budget; model diagnostic computed but planner not used to choose its real action.
7. **wrong-credit-probe ablation:** same contradiction candidate and probes, but invert signed likelihood evidence before updating the command-to-actuation hypothesis, leaving all actual physical action/reward records unchanged.
8. **no-adaptation-probe ablation:** same probes and frozen learned planner as candidate, never changes normal channel assumption.

Every adaptive method sees only its own real trajectory and equally defined source-trained dynamics. Realized experiences differ due to policies and are never artificially reused to make outcomes equal. Compute-cost/decision-time diagnostics and per-arm probes/steps/params are recorded, but **matched whole-process compute is not proven** by equal step caps or shared models. No oracle truth or hindsight competitor selection influences any arm's decisions.
