## Causal environment

World hidden state is a two-bit register `s ∈ {0,1,2,3}` with NO spontaneous transitions. At decision `t` observe two imperfect four-way sensors of `s_t`, public actuator cue `c∈0..3`, then perform prescribed binary action `a∈{0,1}`. Action0 is passive. Action1 schedules a genuine XOR-mask event for transition time `t+lag_world(c)-1` (lag 1,2 or3); events retain the **mask and lag chosen when issued**, including across phase boundaries. At each transition, XOR together every due event and apply it to the persistent register, then reveal two noisy sensors of the new state. Queued events can overlap and cancel. Observed output is the raw 2-bit state (world initial state is seed-derived, no observation offset). Simulator-only laws A: mask=[1,2,3,1], lag=[1,2,3,2]; B: mask=[2,1,3,2], lag=[3,1,2,3]. Never-before-seen C: for even cues use mask A + lag B; odd cues mask B + lag A. D reverses that pairing. Only the simulator knows which law is active. Sensors return correct state, +1(mod4), -1(mod4) with probabilities sensor0 [90%,6%,4%], sensor1 [80%,10%,10%]; noise uses the same deterministic F28 mixing salts and independent streams. Learners see neither clean state, due-event queue, actual law, next-state target nor future actions.

## Frozen train/test worlds and input fairness

Two **complete isolated-pulse training worlds**: seed 331 world A and seed 337 world B, 128 transitions each. Action1 only when `t%8==0`; cue `(t/8)%4`. All other actions are 0. Thus each cue receives **4 isolated pulses per A/B training world** with >=5 settling steps and 4 sensor reads after each action. All models train on exactly the same 256 real transitions, input actions, cue labels and noisy sensors. A/B training world labels may be used by archive-based models; held-out phase labels cannot. At the training boundary, cold-serialize the learned state; each transfer world begins with independent restored clone, no replay of training data.

Four untouched DEV transfer seeds: 347 balanced A→B→A→C, 349 skewed B→A→B→D, 353 balanced A→B→A→D, 359 skewed B→A→B→C. Each has 96 decisions and four contiguous 24-step phases. Transfer action1 when `t%2==0`, otherwise passive; balanced cue `(t/2+seed%4)%4`; skewed cue `(t/4+seed%2)%2` except `t%8==6` uses `(t/4+seed%4)%4`. The action schedule, initial state, sensors and consequence stream are identical for all policies within a world; every learner predicts before seeing next sensors. No scientific first-use seeds 59/83, no post-score train reuse, no oracle training.

## Fully trained model portfolio

All models produce a calibrated four-way probability of the next *actual clean register state*; score before observation. Training for causal event models uses all four sensor-time observations after each isolated pulse, and enumerates unknown initial state rather than reading the simulator's hidden state. For each cue and known training world, accumulate likelihood for all **nine mask × lag** hypotheses (masks 1,2,3; lags 1,2,3). Normalize the nine-way posterior, select deterministic MAP with lexical tie break, and preserve the A/B archive in the cold checkpoint.

1. **delayed-event-memory (candidate):** four transparent, mechanistic forecast hypotheses AA, BB, AB and BA: use A/B-learned masks and A/B-learned lags per cue. AA and BB use within-source; AB/BA use cross-source mask/lag. Use *only past and current real action/cue history* to construct XOR of due events for each hypothesis (lags up to3), convolve current noisy-sensor state posterior with that XOR. Maintain four regime weights, initialized uniform each world, updated on the next actual sensor likelihood with fixed hazard 0.07 toward uniform, and never consult hidden phase. No online learning of the frozen source archives.
2. **two-bank-event-bayes (strong control):** same fully trained A/B mask-lag archives, identical action queue and four-state sensor posterior, but mixture weights only over AA/BB (hazard 0.07); cannot use cross-source pairs.
3. **pooled-event-bayes (strong control):** fully trained nine-way mask-lag posterior for each cue from the combined A+B 256 real training transitions, one learned event hypothesis per cue; apply the same queued-history state filter.
4. **history-logistic (strong control):** fully trained four-output multinomial softmax, input features: bias, sensor-derived current-state one-hot, and per-cue action1 indicators at current and preceding two decisions (4×3), 17 features total; deterministic online SGD four passes per training transition, learning rate 0.05, L2 0.0001, trained on **noisy next-sensor posterior**, never clean target. Retain weights and use identical online adaptation for all 96 transfer steps; no privileged event-law access.
5. **history-blind ablation:** candidate archives and four hypotheses intact, but discard action/cue history more than current action; cannot represent consequences from earlier decisions.
6. **cold-zero ablation:** candidate with frozen source archives intentionally replaced by fixed uniform nine-way posterior MAP (mask1,lag1) at transfer, and no training replay.

Strongest conventional is min per-world NLL of models 2–4, selected **only by evaluator after outcomes**. Models are trained, not zero-shot; expose parameter counts, approximate floating-point work, and elapsed time as diagnostics. Training interaction counts are matched but parameter/compute budgets are not exactly matched; **never claim matched-compute SCIENTIFIC_PASS**.

## Frozen measurement and decision rule

Per transfer world log 96-action next-state **mean NLL** with probability floor 1e-9, 96-step MAP accuracy, return-world phase steps48–71 correct, novel C/D phase steps72–95 correct, first-8-after-switch correct, action/sensor/prediction SHA256, training checkpoint SHA256, transfer terminal SHA256, per-model work/parameter counts, and cold-vs-uninterrupted byte-identical result. All actual actions and both noisy sensor traces must be identical across arms, including ablations; simulator-law and scored clean register remain outside model methods. Validate training source pulse coverage 4 per cue per bank, all hypotheses normalized, reject unknown/first-use seeds and noncanonical/tampered checkpoints, and detect scientific-flag/score forgery.

Declare `F32_DEV_SIGNAL_UNVERIFIED` only if **all four** transfer worlds have candidate mean NLL at least **0.05 nats/step lower** than the strongest conventional, candidate return-phase correct count >= the highest conventional return-phase correct count, candidate novel-phase correct count >= highest conventional novel-phase count + **2/24**, candidate mean NLL at least **0.10 lower** than BOTH ablations, with exact source/provenance and all negative controls passing. Otherwise `F32_DEV_NO_GO` (tie/ceiling/absent evidence => NO_GO). No tuning training schedule, worlds, thresholds, hazard or candidate **after** scoring. A DEV signal does not establish independent scientific first-use, causal transfer ability, RSI, learning superiority at matched compute, or deployment.
