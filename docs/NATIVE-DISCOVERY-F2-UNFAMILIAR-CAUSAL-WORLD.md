# FORGE F2 — procedural unfamiliar causal-world and interference evaluation

## Status and engineering purpose

A bounded **synthetic source-development evaluator** expands the accepted F0/F1 engine without modifying any original controller, research lane, owner queue, worker, dispatch path, or optional AI-assisted capability. F2 does **not** claim novel learning, RSI or independent scientific acceptance.

The real F1 outcome remains `DEV_NO_GO`; its conventional feature-table baseline reached a 100% task ceiling. F2 is designed to expose causal regime shifts, sparse unfamiliar-world probes, realistic noisy feedback, cold restoration and interference, with a conventional comparator capable of strong factorized generalization.

**Development provenance:** a local source-development smoke check was performed before the hosted job; therefore this document is a frozen *development protocol*, not an independently sealed first-use scientific preregistration. No protected scientific heldout or original Wingless/Yggdrasil cohort is used.

- Base: FORGE main `a8474c1f96b94e780d976aa39ab0fb099c2ce506` after the F1 source-only integration.

- Existing `noveltymechanisms.Compile/Resolve` (F95) is the native relation representation. F2 adds a two-regime evidence memory and factor-composition readout. A learned state can be serialized and independently cold reconstituted with strict type/count bounds. It is not a neural architecture.
- The original F0/F1 evaluator, GenEnv, F94/F95 code, optional paid/AI workflows, source guards and full regression are unchanged.

## Fixed procedural environment

- Four cue factors, two mode factors, two intervention regimes; latent factors are generated by a pinned deterministic PRNG from seeds `17,31,59,83`, not disclosed to any trained model. A binary action has a sign-dependent effect; an exogenous, fixed common-random-number **20% reversal noise** affects observed consequences and scored outcomes.
- Each model sees the *same 48 action-consequence observations* in initial regime 0, then exactly *6 previously unseen regime-1 probes* at fixed cue/mode combinations, then *16 further regime-1 interference observations*. Neither test scoring outcomes nor hidden latent factors are fed back to the models.
- Each scored condition runs 64 decisions per seed (four cues × two modes × eight exogenous-noise replications), with an identical heldout shock stream for all arms. This exposes non-ceiling realized rewards and matched experience/action budgets; it does **not** establish matched whole-process CPU/RSS/FLOP budgets.
- Model observes the intervention regime label but not its hidden causal rule; the new rule is not a trivially global sign inversion. Original-world performance is tested before and after learning the new regime. Cold reconstitution must reproduce retained original-world behavior exactly.

## Controls and fixed evaluation

- **Native:** F95-relational, regime-separated associative memory with locally inferred cue/mode factor signs; updates only from observed transitions.
- **Conventional control 1:** exact context-table empirical estimator, fully trained on the same history.
- **Stronger conventional control 2:** independently implemented, exact maximum-likelihood enumeration of **all 32 factorized sign hypotheses** per regime. This control has the same action/consequence information and searches the complete finite hypothesis family rather than using weaker untuned parameters.
- Frozen minimum provisional *development* criterion: native changed-regime realized reward exceeds the **better conventional control by at least 5 percentage points**, improves over native no-probe performance by at least 10 points, and loses no more than 10 points of original-regime accuracy through interference, with exact cold-restored parity. This entire condition must hold for at least **3/4 seeds**, and the realized reward task must not be oracle-ceiling.
- The result `DEV_NO_GO` is preserved if any condition fails. Even a provisional development win is explicitly **not SCIENTIFIC_PASS**, given exposed synthetic generator rules, unsealed sample selection, small seed population and unmatched end-to-end compute.
- Retain exact per-seed baseline/native scores, warm/cold original-world accuracy, before/after probing, input and decision counts, snapshot bytes, optional wall-time diagnostics, fixed source and execution identity. Test corrupted snapshots, invalid actions, out-of-range effects, mismatched regime and deterministic replay. No outcome-driven tuning, new seeds, relaxed thresholds or a second attempt on the same frozen heldout cases.
