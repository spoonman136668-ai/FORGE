## Hypothesis and distinction from F45

F45's model-averaged long-sequence control failed even on fault-free MountainCar. F46 instead studies **goal-conditional, action-consequence information acquisition** in a tiny, *entirely synthetic but unfamiliar* source-defined 2-bit causal world. It asks whether selecting a **diagnostic real action** based on the information gained about unknown causal effects improves achieved goals against strong exact-Bayesian, trained empirical, random and mechanistic negative controls. The candidate makes a single model-internal choice each step, then **must physically apply that chosen action to obtain its consequence**. No future outcome, true mapping, hidden mode, true effective action or counterfactual simulator call can be read by a policy. This is NOT the original Gymnasium physics, not a novel neural model, not independently heldout scientific first-use and not an RSI or native intelligence claim. It tests one portable non-token learning primitive cheaply before heavier research.

## Frozen environment and masks

Observable world: current state `s in {0,1,2,3}` encodes two binary state bits; public goal `g in {0,1,2,3}` differs from initial state. Available actions `0,1,2`, where action 2 is inert. Each of six possible *hidden* fixed causal modes `m` determines the deterministic one-step state transition `s_next = s XOR EFFECTS[m][action]`, with effect vectors:
`EFFECTS = [[1,2],[1,3],[2,3],[3,2],[2,1],[3,1]]` for actions 0 and 1; action 2 effect 0 across all modes. **The model knows this six-element hypothesis grammar but not which hypothesis governs any episode.** All agents have access to precisely the same hypothesis grammar (including modes absent from FIT). Evaluation harness alone knows actual mode and calls the real `step` function; no policy gets its source ID, seed or outcome until the action has occurred. Each episode ends when the public goal is achieved or after 5 physical actions, with reward `-1` per step and `+10` on reaching goal; return is sum of step rewards.

The deterministic environment source may be inspected by reviewers and is therefore a **synthetic DEV mechanism evaluator**, not independent science. No hidden external data or protected scientific first-use. Deterministic LCG and Git SHA/JSON digest support exact cold replay.

## Frozen common FIT data and model priors

FIT-only eight source seeds `[2100,2101,2102,2103,2112,2113,2114,2115]`; each carries one of four causal modes `m=seed%6` (0–3), unseen physical modes 4–5 NEVER occur during FIT. For each FIT world, use **16 episodes × 5 fixed action-consequence observations** generated by a fixed LCG per seed, public start state and a behavior-policy action drawn uniformly from {0,1,2}. Do not terminate transcript collection on goal (training is open-loop observational); 8×16×5 = **640 actual synthetic action/next-observation records**. All candidate and conventional families consume the same immutable logged (current state, requested action, next state) records and the same training-time operation/time budget, no parallel extra environment calls.

FIT estimates (a) the frequency of hidden modes consistent with each world transcript using **only observed action consequences** (never the secret world ID), Dirichlet+1 on all six possibilities yielding a frozen shared `prior[0..5]`; and (b) one conventional fully fitted empirical effect table, per-action majority observed effect, tie lowest effect. All policies receive identical prior + empirical model, not hidden FIT labels. Require 640 transitions, all three actions observed, four independently identified source modes in FIT, immutable transcript SHA256. Models and policy state must serialize canonically and cold restore.

## Frozen policies (same data and actual-action budget)

All hypothesis-aware arms initialize with the identical FIT-derived six-element Dirichlet prior every episode and update it by exact filtering of causal hypotheses consistent with the **observed** `s XOR s_next` from the actually executed action. When a prior collapses to zero for a true unseen mode, keep the +1 support for all modes; if no mode remains, fail-closed (no invented outcome). All arms can use the same available public goal, current state and fitted prior.

1. **active-information candidate:** choose action maximizing `expected immediate goal probability * 4 - expected normalized Hamming distance to goal + 0.65 * expected posterior entropy reduction`; tie lowest action. Exact predictions enumerate hypotheses, with entropy in nats; information is only from hypothetical *hypothesis outcomes*, never actual future simulator calls.
2. **bayes-greedy conventional:** identical posterior and one-step public-goal score but entropy bonus =0.
3. **bayes-two-step conventional (strongest model-based):** for each requested first action compute exact expected `4 * (goal reached at first step, else probability of reaching within ONE more action by best follow-up computed after posterior from the first observation)`, with step/hamming penalty `-0.1 × expected min Hamming distance`; choose highest, tie lowest. Each branch is a model prediction, not physical step; identical six-hypothesis family and data.
4. **trained-empirical conventional:** greedy current-to-goal choice from fully fitted per-action majority effect table learned on the same 640 records; no online changes.
5. **seeded-random conventional:** deterministic local action PRNG (seed derived from episode, not secret causal mode) under the same five-step budget.
6. **wrong-credit negative:** same active-information choice, but posterior filters on `(actual_observed_effect+1)%4`, deliberately corrupting causal credit; no physical action is altered.
7. **no-feedback negative:** active-information choice but never updates posterior after physical consequences.
8. **info-only negative:** choose the action with highest entropy reduction alone, with ties lowest action, ignores public goals.

No candidate receives extra transitions, privileged mode names or experimental interventions. Conventional exact Bayes two-step is deliberately strong, and can falsify claims for active-information.
