# Bounded repair diagnostics R1

`repairregistry.Diagnose` is a read-only exact-match adapter over a pre-provisioned directory of canonical, content-addressed incident JSON files. All records must verify; a missing or corrupt archive fails closed. A finding is tagged `REFERENCE_ONLY_INDEPENDENT_QUALIFICATION_REQUIRED`. The result is never permission to edit the CI policy, widen process execution, spend scientific budget, start workers, or replay an experiment.

The caller must supply the exact repository, component, failure signature, applicability scope and ordered preconditions. The caller must authenticate the GitHub run, signed source identity, current file inventory and qualification evidence independently. This package does not authenticate remote GitHub run status, perform any repair, or provide background diagnostics. Never treat a registry digest as an independently signed attestment.
