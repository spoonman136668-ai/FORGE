## Deterministic root tasks and genuine intermediary node state

- For each induced split graph, sort root names by (SHA256(node UTF-8), raw node UTF-8). Candidate root first-hop arcs cap **128**; examined second-step arcs cap **4096**; distinct reached target nodes cap **512**; any over-budget root skipped completely, never silently truncated. Disallow returning to root or using the same physical original source triple in the two steps (even via reverse edge). Every counted path has a genuine shared physical middle node. Never join separate disconnected role occurrences.
- A qualifying root query is the *lexicographically smallest existing* pair of ordered signed source roles `(q1,q2)` for which one candidate target has ≥1 actual two-step joined path matching exactly those roles and a different candidate target has real joined two-step paths but **zero** paths of that precise pair. Select first lexicographically sorted eligible positive and first negative target. Candidate first-slot identity is deterministic SHA256(`F120O-order|` + source root UTF-8) low bit: 0 → positive first, 1 → negative first. Positive and negative root-specific candidate features include true paths only, never gold answer or label bit.
- Take first **64 TRAIN**, first **24 DEV** and first **48 TEST** qualifying root tasks, in original source node SHA order within their induced split, or fail the original frozen feasibility test. Nodes and original source triples cannot overlap across graphs, though the same nine relation ROLE LABELS may occur across splits.
- Build for each chosen root a sparse two-step **middle-node state**: map every actual middle M to counts of first-hop signed role arcs root→M and counts for M→candidate-0 and M→candidate-1 second-hop signed role arcs (with source physical-edge nonreuse). Different middle nodes never get merged before the nonlinear update; this is a true intermediate-node-specific hidden state keyed by source adjacency, **not** hashed ID equality supplied as an input feature. Do not publish middle IDs or per-example paths. A separate conventional histogram of physical ordered signed-type two-hop pairs for each candidate supplies F119 linear-composition baseline.
- This is not independent learning of graph connectivity: original source adjacency and equality of the intermediate node are explicitly provided by the inference graph engine. No claim that the model can reconstruct absent edges or unseen source structures.

## Frozen trainable nonlinear intermediate-state mechanism

Let Q and E be independently trainable 18×3 query/edge-role matrices, initialized by SHA256(`F120O-v1|Q-or-E|index|coordinate`) first uint16 mapped to [-0.05,+0.05], common bias b=0. Init scalar **alpha=1.0**. Gate for requested signed-role q and actual directed signed edge r is `g(q,r)=sigmoid(b+dot(Q[q], E[r]))`.
- For root and query `(q1,q2)`, for EACH genuine middle node m compute `f_m=SUM_(root→m signed role r) g(q1,r)` then `state_m=tanh(alpha * f_m)`. For candidate terminal t compute `mass(t)=SUM_m(state_m * SUM_(m→t signed role r with different physical source fact) g(q2,r))`. Score candidate `log1p(mass(t))`. This is a **nonlinear state update before propagation** (as opposed to F119's linear sum over role-pair counts), but the physical graph message routing is supplied. Candidate with higher score chosen, ties choose first candidate.
- Train **110 parameters** = 108 Q/E + bias + alpha, **120 fixed full-batch analytic-gradient epochs**, LR **0.35**, embedding-only L2 **0.005**, fixed 0.5 logistic contrastive preference via `softplus(-(score_positive-score_negative))`. Average gradient over TRAIN tasks only. No stochasticity, early stopping or hyperparameter sweep. Freeze threshold and all controls. Loss decrease and nonzero learned weight movement are necessary engineering assertions, never sufficient scientific improvement. Parameter fingerprint quantized to 8 decimals for OS reproducibility.
- **Baselines all trained on same frozen train induced subgraph and evaluated on same untouched dev/test induced subgraphs**: (A) constant first-candidate; (B) uniform untyped 2-step physical joined-path count; (C) frozen INIT of identical nonlinear gate architecture; (D) full 120-epoch trained F119 **linear** role-gated histogram architecture on the exact same TRAIN tasks (never previous F119 test data); (E) **exact symbolic typed joined-path traversal** should be 100% by construction, a privileged oracle. No withheld graph edge or original QA answer source from the TEST graph may be used for model updates; only candidate query-time test graph edges are used for query evaluation as allowed to all methods.
- Terminal primary metric balanced accuracy predicting whether candidate 0 is positive, with full confusion matrices; both heldout classes required. Preselected exploratory gain iff nonlinear learned model beats *all* untrained/linear/untyped/constant controls by at least **+0.05** TEST BA. Report outcomes even if it is worse or the source partitions are insufficient. DEV solely inspection-only, no tuning/selection.
- **No post-evaluation reselection**: original SHA split, exact eligible cohort, fixed parameters, source identity and metrics frozen. A later engineering variation must be separately preregistered and clearly developmental, and never rebrand itself as protected prospective first-use.
