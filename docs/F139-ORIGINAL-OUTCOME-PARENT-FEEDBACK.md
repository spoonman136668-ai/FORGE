the existing provenance pins. No new executable, scheduler, API or queue is
introduced. Historical pure-adapter rehearsals retain their prior default;
the live owner adapter always passes explicit verified-ledger eligibility.

VERIFIED means the existing engineering qualification passed. It does not mean
useful learning, task utility, scientific acceptance or optimizer reward. This
change does not enable optimizer training, protected first-use, independent
archival timing, scientific authority or accepted native repository changes.
Frozen tests, cohorts, architectures and negative controls are unchanged.

generation mechanism identity and needs a separately qualified original-owner
release before it can affect the installed V34 loop. The active owner is left
running on its existing qualified source during preparation and qualification.
