# R6 — Authentic historical first-use evidence → automatic successor proposal

**Target:** Close the manual handoff from original evidence qualification into the existing FORGE successor selector, without replacing the current single science authority or adding a scheduler. **R6 live autonomous original execution is not yet admitted.**

## What this integration actually executes

The existing `.github/workflows/forge-real-dual-lane-continuity.yml` already periodically fetches exact source-pinned genuine historical independent science for Wingless R32→R33 and Yggdrasil E1→E2. Its `gate.py` reaggregates original raw scientific results with pinned independent reviewers, exact original artifact checksums, frozen first-use claims and source lineage, preserving actual negatives and source-recovery evidence. This is authentic *historical scientific evidence*, not newly generated research.

R6 adds **one downstream job to that existing scheduled workflow**, consuming only its already verified real-evidence artifact from the **same** run, and using the preexisting, frozen `research/dual_successor/prepare.py` selector. It verifies that no original was replayed, recomputes deterministic successors for both independent lanes, compares a repeated calculation byte-for-byte, records a content-addressed read-only disposition and uploads a bounded evidence bundle.

- Wingless historical parent: `W-FORGE-R33-CONDITIONAL-TEMP-01` (negative). Proposed independent successor: `W-FORGE-R34-MARGIN-SUPPORT-01`.
- Yggdrasil historical parent: `Y-FORGE-PARITY-E2-ONSET1` (partial). Proposed independent successor: `Y-FORGE-E3-ONSET-LATENCY-01`.
- Both proposed successors were already frozen in the historical R34/E3 portfolio. This is **recovery/automation of the real-parent handoff**, not a claim that these hypotheses are the current frontier of new research or that additional originals have been executed.

The new job does not write a scientific ledger, GitHub claim, source PR, queue entry or accepted reference. Historical original attempts remain consumed and cannot be replayed.

## Minimal remaining live gate — not solved by the archive

R5's live `classification.PlanDualReadiness` requires **Ed25519-signed independent parent classification, pinned reviewer public keys, and independently persisted Classified journals**. The historical GitHub review artifact alone cannot be relabeled as that independent FSA attestation. No source-only workflow may manufacture keys or self-attest first-use on behalf of an independent authority.

To reach real R6 continuously running research, the **existing** single authorized science owner must supply authentic (not fixture) signed parent, frozen new candidate and one-shot consumed-cohort evidence. The already qualified existing worker path must then launch an actually new and disjoint original, retain raw start/terminal and negative evidence, independently review it and automatically advance to a second new original **without another human handoff**. If the current owner cannot emit that evidence, report blocked rather than pretend a historic proposal is autonomous science.

This R6 change does not add Cloudflare credentials, a billing dependency, a second FSA, a new scheduler, or any paid API. Wingless and Yggdrasil remain independent; CKB-plane and KTRADE are unchanged.
