Then replay this exact actual trace from the same initial world twice: original F36 observer (eps=0, original support fallback) and F37 observer (`eps=0.025`) with no changes to physical actions, sensor streams or source banks. Compute mean **prequential two-sensor NLL** for 96 steps using probability of actual next two-sensor observation *before* seeing it, with log floor 1e-12; report scorer-only clean-state NLL, support-fallback counts, work counter, observations/action/checkpoint/terminal hashes, and cold restore at t47 vs continuous byte equality. ## Frozen decision and stop rule

An **observation calibration component PASS** only when calibrated sensor NLL improves by >=0.05 nats/step for *both learned source families on all four worlds* (8/8), zero unsupported calibrated observation posteriors, and exact cold identity. Independently a **goal-control component PASS** only when the calibrated four-bank policy produces >=2 more real goal hits and >=1.5 higher net reward **than the strongest fully trained conventional planner (calibrated two-bank, calibrated pooled, original trained logistic)** on *each of four worlds*, and does not exceed the calibrated two-bank work counter by >10% in any world (work counter is a diagnostic constraint, not measured wall-clock parity). Both components passing and zero custody failures yields `F38_DEV_SIGNAL_UNVERIFIED`. Otherwise `F38_DEV_NO_GO`; record each component's independent result and every negative outcome.
