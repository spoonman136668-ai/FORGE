## Prespecified mechanism
Hypothesis: **An action-normalized causal posterior over 32 factorized sign explanations, with intervention selection targeting maximal disagreement among plausible explanations, will improve unfamiliar-world prediction per observation compared with the strongest fully trained controls and ablation planners.** This is a deliberately narrow causal-invariance model, not token prediction, and its 32-hypothesis class is **already available to the conventional F2 factorized control**; prior art advantage is NOT claimed.
- Reuse original `f2Counts` (intervention-normalized observed effect) and `f3Core.Snapshot/Load`. Each candidate explanation assigns independent signs to four cues plus one shared mode flip, 32 explanations. All start with the same prior. A hypothesis gets integer weight `3^matches` over regime-1 observed effects; mismatches contribute multiplicative 1. No world seed, true sign or post-evaluation label is used to compute weight. The fixed 3:1 ratio is an **arbitrary frozen prior** for synthetic DEV, not tuned from held-out results.
- Prediction is weighted vote over the 32 causal explanations for regime 1, deterministic tie to direct observed majority then +1; regime 0 uses existing direct `f2prior` memory. No model weights are updated during scoring.
- **Uncertainty policy** selects one of eight cue×mode coordinates not previously probed, maximizing the smaller of the total positive- and negative-predicting hypothesis weights (most balanced disagreement); ties use ascending coordinate index. The intervention **action** is step%2 for all planners. No oracle view of any intervention's effect until AFTER committing coordinate and action.
- Compare same causal posterior learner under *exact existing F5 fixed and random coordinate policies* as two planner ablations; they receive 6 observations each. At each generation cut (3 and 6) every arm trains four baseline models on the **same 48 original regime-0 + its own 3/6 actual regime-1 action-consequence observations**: F3 selected via prior observed feedback only, conventional empirical table, full 32-hypothesis MLE factorized control, F2 native frozen relation memory. Score each on the original 64-decision synthetic **development** evaluation; do not use these scores to select probes or hypotheses.
- Keep all six arms (2 seeds × 3 policies), both generations, exact actions/feedback, baseline outcomes, original-world retention and actual checkpoint cold replay, negative/tied arms, source/f10 receipt, and prediction-cost counters.
