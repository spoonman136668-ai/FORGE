## Fixed source-derived task and separation
- A signed role type is an exact case-sensitive source role label paired with explicit `Forward` or `Reverse` enum. Exactly **18** signed role types (nine roles × 2 directions) and **324** ordered 2-step type pairs.
- Source-only evaluator establishes each pair's binary **existential compatibility**, whether there exists *at least one* 2-edge walk on the full original public knowledge graph with that exact ordered signed-role pair. Self loops and duplicate source rows do not create extra labels. No question-answering score and no question/answer data.
- Split all 324 signed-role pair keys *before* any training or source-label inspection using SHA256 of literal `source-role\x1fdir\x1eother-role\x1fdir` UTF-8 bytes, take first eight digest bytes interpreted as unsigned big endian modulo **10**: buckets 0–6 train, 7 development **inspection-only**, 8–9 terminal held-out test. Publish only split denominators and class totals, no original role labels. F116 model and hyperparameters frozen in this file before graph feature data is evaluated; **never tune on development or test labels**, and report class-degenerate slices as **NOT_TESTABLE**.
- Independent 3-step diagnostic: all **5,832** ordered triples of 18 signed types evaluated against existence of real 3-edge walks on the source KB. For terminal 3-step candidate pool, require **both adjacent 2-role transitions hashed into the unseen test split** (buckets 8–9), take at most **256** 3-step tuples in lexicographic SHA256 ordering of full signed-role tuple. Run fixed pair-model probabilities through `min(p(t1,t2),p(t2,t3))` and fixed threshold **0.5**; compare with real source 3-hop existence, not just pairwise conjunction. If insufficient label diversity, declare 3-hop non-testable, no selective replacement.
- Restrict label construction to signed-role adjacency in whole-source graph; do not derive or publish per-entity answers, training language, gold labels or source role names. No source-KG query used as test input to model. Relationship composition is **existential** over the graph; it is NOT root-conditioned retrieval, variable binding, cognitive generalization or independent task-family evaluation.

## Preselected genuinely learned mechanism
- Two separately trainable role embedding matrices `L[18][4]` and `R[18][4]`, left-role bias `a[18]`, right-role bias `b[18]`, global intercept; logit `bias + a[left] + b[right] + dot(L[left], R[right])`. This is a **trainable logistic low-rank compatibility scorer** (not hand-coded compatibility table, not a language model).
- Initialize L/R deterministically from SHA256 of `F116O-v1|L|index|coordinate` or R, mapping digest 16-bit to [-0.05,+0.05]; initialize biases to **0**. Sequential **full-batch** gradient updates over train pairs only, fixed **200 epochs**, learning rate **0.12**, L2 penalty **0.01** on embeddings only, gradient averaged by train sample count; sigmoid numerically clamped to avoid overflow. No minibatch randomness, early stopping, tuning, validation-based selection or hidden test feedback. Log train log-loss before and after, learned weight checksum, and actual weight-change norm; if no weights change or loss nondecreasing, fail mechanism qualification.
- Frozen baselines: (A) **train-majority constant class** (ties predict 0); (B) **train-only left/right marginal** predicted using Laplace-smoothed role-conditioned positive proportions averaged left/right and threshold 0.5; (C) as descriptive upper bound only, full graph existential lookup itself is an oracle and not a learned model. Terminal held-out primary metric **balanced accuracy** (average sensitivity and specificity) plus raw accuracy and confusion counts. Compare learned with BOTH A and B without claiming win on a negative result. Predeclared *engineering exploratory improvement criterion*: heldout balanced accuracy ≥ best baseline +0.05, holdout has both labels, and 3-hop transfer nondegenerate; otherwise `LEARNED_TRANSFER_GAIN_NOT_DEMONSTRATED`. Training convergence alone never qualifies scientific acceptance.
- Primary scientific status **always NOT_ACCEPTED** in F116: public graph self-supervision is transductive; only 18 typed labels, artificial role compatibility, not a separately custodied unseen task family.
