# Eureka F20 — noisy, partially observed active causal probing (DEV)

**Preregistered November 9, 2026 before code/results** from existing inactive Eureka draft PR #1614 at F19 \`fc1372f7ce1bd7c9e864290750add86233080727\`. All F10–F19 negative outcomes remain frozen; especially F19's 128/128 strongest-control ceiling. This is a new experiment, not an F19 retune.

## Hypothesis and environment

A pending-aware contextual counterfactual-coverage policy learns a hidden causal response function more effectively from **18 genuinely selected actions** and **two-step-delayed noisy/erased feedback** than a fully fitted portfolio of strong Bayesian active learners under the same model, information, actions, and observation channel. Candidate is a bounded heuristic, not a claim of new intelligence.

Four synthetic **DEV only** arms: seed **113** (hidden law \`0xA6\`) and seed **127** (hidden law \`0x5C\`), each with **balanced** and **skewed** exogenous cues. For cue c in 0..3 and binary action a, the uncorrupted response is \`((law>>c)&1) XOR (a&((law>>(c+4))&1))\`. Learners use all **256 possible eight-bit masks** as an equally expressive prior; only the world knows its hidden law/seed. The public balanced cue is \`(3*t + seed%4)%4\`; the public skewed cue is \`(t/4+seed%4)%4\` for \`t%4==3\`, otherwise \`(t/3+seed%2)%2\`. Every learner sees the same current and next public cues and chosen-action feedback, never the hidden law or unchosen-action response. Each learner runs a separate real selected-action trajectory with common exogenous cues and corruption schedule.

The consequence of an action at t arrives at t+2. It is missing (-1) when \`f12Mix(seed^0x517cc1b7^uint32(t+1)*0x9e3779b9)%5==0\`; otherwise its true binary bit is flipped when \`f12Mix(seed^0xdab5a609^uint32(t+1)*0x85ebca6b)%8==0\`. These fixed generator streams are not supplied to models. The statistical channel is known (erasure 1/5, independent bit flip 1/8). A delivered nonmissing response contributes a likelihood ratio of **7:1** for correct versus incorrect hypothesis; missing observations contribute no evidence. Equal uniform prior over masks; posterior prediction for each of 8 cue/action probes is the majority weighted response, exact tie predicted zero. Every policy fits the same fully expressive Bayesian hypothesis family to its own genuinely credited observations.

## Frozen candidate, seven strong controls and negatives

\`pending-coverage\` candidate minimizes the number of **credited nonmissing plus already pending** probes for the current (cue, action); ties maximize posterior-predictive binary uncertainty, then choose action 0. Seven fully fitted conventional controls, each with the same 18 action budget and own credited posterior: (1) \`bayes-risk\` choose the action maximizing expected one-step Bayes correct count across all 8 probe labels after a hypothetical noisy response; erasure is action-independent. (2) \`bayes-ig\` maximize posterior binary predictive entropy from one noisy response (exact one-step mutual information ordering). (3) \`bayes-two-step\` enumerate actions for current and next known cue, maximize first information gain plus expected best next information gain marginalized over both possible noisy first outcomes. (4) \`credited-coverage\` minimize nonmissing **credited** counts (ignore pending), tie action 0. (5) \`posterior-thompson\` select one hypothesis by deterministic posterior-weighted step/credit-count pseudo-random index (not seed) and select action 1 only if its predicted output changes from action 0 to 1. (6) \`balanced-actions\` select step parity, and (7) \`cue-following\` select cue parity. All seven are candidate comparators regardless of how weak/strong a given arm is. Two mechanistic negatives do not replace controls: \`no-intervention\` always action 0; \`wrong-credit\` uses pending-coverage choice but fits feedback using the **previous** action instead of its actual recorded action. None has an outcome oracle or extra data.

## Locked measurements, evidence and verdict

Every model selects 18 actions. At steps **4,7,10,14**, after receiving the newly due t-2 effect but **before** selecting the next action, a private scorer measures the model's 0/1 predicted response over **all 4 cues × both actions**, 8 correct maximum per checkpoint; **32** total maximum. Oracle labels never update a model. Credit counts at these checkpoints: **3,6,9,13** including known erased records. After 10 actions, checkpoint with 8 credited (including erasures) and two pending, cold-load exact canonical SHA-256 state (including pending action identities) and continue **only** actions 10..17; after 18 actions, 16 credits and two pending, with final checkpoint equal byte-for-byte to a fresh uninterrupted replay. Record actual action traces, erasures/flips, selected-response trace hashes, per-policy milestone scores, deterministic model-work counts, the full seven-control comparison, ablations, forged-report negatives and source evidence. No unselected action gets simulated as policy feedback.

**F20_DEV_SIGNAL_UNVERIFIED** requires **all four arms** satisfy every condition: candidate at least **+2/32** compared with **the strongest score of all seven** conventional controls, >=**+3/32** versus **each** of no-intervention and wrong-credit, >=2 non-cue-following actual choices, strongest control <32 (nonsaturated), intact two-step credit, exact cold continuation and rejection of any forged authority.
