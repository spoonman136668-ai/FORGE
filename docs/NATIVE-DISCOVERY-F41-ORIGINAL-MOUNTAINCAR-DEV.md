## Frozen portfolio and model arithmetic

Candidate `regime-residual-mpc`: fit global ridge dynamics `[position,velocity,one-hot(action),bias] -> next two observed coordinates` with lambda 0.001. Fit additive independent per-velocity-regime residual regressors on the global *one-step errors*, three regimes determined by velocity < -0.002, |velocity| <= 0.002, velocity > 0.002; each uses the same six-dimensional feature row and ridge lambda 0.05. A deterministic training-only validation on held-out training episodes gates all local residuals **on** only when their combined validation squared state prediction error is strictly lower than base dynamics; otherwise they all remain off. For validation, both fits are computed only on the same non-validation training episodes. For final fit, repeat on all TRAIN observations with the training-only binary gate frozen. This test does not choose different thresholds or family. Keep the gate state in a canonical JSON checkpoint, cold restore without retraining.

Controls/ablations: (1) `velocity-rule`, the no-data momentum-following heuristic stated above; (2) `trained-behavior-cloning`, ridge one-vs-rest action classifier from public state+bias with lambda .001, all TRAIN observations; (3) `trained-fitted-q`, fixed 30 full-batch fitted-Q iterations with gamma .99 and ridge .01 using public polynomial state features [1,p,v,p²,v²,p*v] with one fitted head per observed action; (4) `global-linear-mpc`, exact same candidate planner but global-only learned linear dynamics on the identical TRAIN transcript; (5) `wrong-action-mpc`, same learned linear dynamics/planner except swap logged action 0<->2 in its dynamics training labels; (6) `no-dynamics-mpc`, identical planner with fixed identity transitions. These are 7 total arms including candidate; no controller gets the original physics formula or a hidden state. Strongest conventional = maximum mean return among velocity-rule, trained-behavior-cloning, trained-fitted-q, global-linear-mpc.

MPC planning for all four planning arms: enumerate `3^4=81` sequences of length 4, use only the arm's frozen learned public next-state predictions; step objective `-position - 10*abs(velocity)`; roll-out discount factor 0.92, ties lowest first action in ordered sequences; no call to original environment for planning; do not use observed reward/goal before real action. Hard cap 200 actual actions per DEV episode. Identity and wrong-action controls receive equal action-selection budgets. Decision timing and total fitting/rollout wall-clock cost are diagnostics only; not matched-compute proof.
