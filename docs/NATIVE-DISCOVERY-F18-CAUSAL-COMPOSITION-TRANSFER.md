## Hypothesis

An economical factorized causal mechanism learned from three source contexts can anticipate action consequences in a fourth, unobserved context. The representation is explicit XOR composition of the independently inferred causal law: `law(11) = law(00) XOR law(01) XOR law(10)`. This structure is itself an inductive bias, **not** a novel intelligence result. An independently fitted conventional joint factorized MLE with *the same* XOR hypothesis class and source evidence is the decisive strongest control. If that control ties or wins, claim no Eureka advantage. Other baselines include nearest-source MLE, pooled-source MLE, target-only online MLE, pooled-source-plus-online-target MLE, and a full-history empirical transition table. Negative controls: compositional no-action learner and one-step wrong-credit learner.

## Frozen worlds, information, and budget

Development seeds 101 and 103 only, distinct from F17 seeds 71/97 and reserved scientific first-use seeds 59/83. Two action policies: fixed step parity and deterministic pseudo-random action `f12Mix(seed ^ uint32(context+1)*0x9e3779b9 ^ uint32(step+17)*0x85ebca6b)&1`; cue `f12Cue(seed,step,context)`. Sources context labels 00, 01, 10 are **observable raw environmental features supplied identically to every learner**; target context 11 is never present in training, only at evaluation. Each context has its own initial hidden 2-bit state. Seed 101 source-law base=1, factorA=2, factorB=8; seed 103 base=10, factorA=1, factorB=2; law(context)=base XOR contextA*factorA XOR contextB*factorB. **Only generator** sees these hidden laws, never a fit or forecast function. Phase=0, so the unobservable phase bit is absent from the rule class. Each of 3 source contexts supplies exactly 18 action events, with 16 correctly credited delayed effects and 2 unresolved. Target context supplies 12 online actions with 10 credits and 2 pending; score target actions 2–9, exactly 8 predictions. All models see identical source credit streams and accumulating target credits, with no post-action label used before its t+2 reveal. No new tokens, transformer, paid API, agent, queue, controller or cross-repo data.

The candidate computes independent 16-rule MLE for each source task, then XORs its three fitted observable law masks and forecasts the target's next state from the last revealed hidden state and known actions. An exhaustive conventional same-class MLE enumerates all 8^3 possible base/factorA/factorB triples and scores all 48 source credits, selecting the first best triple deterministically. Fully trained controls have the same 48 source transitions, visible contexts and at time t the same target credits; those without factorization are not the strongest sole comparator. Source and target checkpoints use existing F13 canonical snapshots, exact SHA checks and byte-identical cold replay; any missing source, duplicate observation, leaked target label, forged report, altered negative or authority field is rejected.
