### Concrete code

- `noveltyeval/f97_intake.go` checks a signed source bundle against an explicitly supplied public key, its exact SHA-256, separately supplied registration/archive pins and the full F96 fixture bytes. The pins and public key are **source claims**, not authenticated off-provider trust anchors.
- Conservative *renaming-invariant topology screening* compares candidate directed typed-relation graph structures to **all sixteen frozen F96 source fixtures**. It preserves directed roles, anchored query root, query path, outcome cardinality and graph structure under nine deterministic refinement rounds, independent of node IDs and input edge order. Any detected prior overlap, repeated candidate, partial/unbounded population, forged class/source or reused pin fails. Equal fingerprints can conservatively reject some truly new graph shapes; **unequal fingerprints do not prove independence or eliminate all semantic contamination**.
- `EvaluateF97RevealedSourceOnly` scores the **complete, already revealed** cohort against the real F95 code, direct typed one-hop, role-blind multi-hop and independently implemented equivalent full typed reference. If the strong reference disagrees with the supplied target for any item, the *entire comparison fails*. Every negative and ambiguous result remains in the final denominators and case-level output.
- `cmd/f97audit` is an explicit opt-in, non-network read-only CLI taking an already-revealed candidate file, a separately supplied pin file and public signature; it writes a new output JSON with `O_EXCL`, refusing to overwrite inputs or accepted evidence. This command is not an autonomous experiment executor.
