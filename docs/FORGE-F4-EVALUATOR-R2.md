# F4 evaluator R2 — source-only classifier

Adds a deterministic Go **post-original classifier contract** for prospectively frozen F4 source. It validates both lane identities, exact frozen blob, raw schema, ordered heldout cohort receipts, bounded outputs and original provenance. Preserves MIXED as distinct from evidence INVALID. Synthetic classifications are never accepted FSA scientific claims.

The original heldout evaluator is **not implemented or executed by this change**. Tests use forged synthetic rows only, never F4 heldout science. Original one-shot release is blocked until a complete separately qualified science/workflow integration with write-once raw archival, independently verified GitHub startup, and authenticated FSA or explicitly scoped sandbox release.
