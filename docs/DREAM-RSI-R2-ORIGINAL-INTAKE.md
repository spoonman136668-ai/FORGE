The verifier rejects missing, tampered or switched entire ZIPs, substituted run IDs, unauthorized second attempts, forged result classes, changes to frozen metrics, missing STARTED evidence or source mismatch. Runs focused real-evidence tests, one full repository Go regression, vet and build per OS, Linux race on intake package, and an exclusive-create CLI catalog.
