## Operation on the existing two-platform GitHub workflow

F101–F104 train their separate small models and emit actual source-identity-bound public development records, each with SHA-256 receipts. F105 independently revalidates all four and issues one automatic next-direction proposal per Wingless/Yggdrasil lane.

F106 is a **new, actual bounded model evaluation stage** attached to that workflow. It rechecks F105's current-run report and checksum, reproduces F105 selection from the four current-run authentic parent files, and fail-closes if the selected direction differs from the preregistered and implemented C2 challenge family. It then trains each parent C2 model for exactly 100 frozen updates **on its old training split only** and evaluates on two completely new generator families with fresh seed blocks frozen before implementing the challenge.

Wingless: 48 public counterfactuals from seeds 64200–64223 with deliberately conflicting nonqueried observations; model has an unchanged strict one-observation read budget, and negative pairs differ only in the queried signal. Outcomes include learned, independently trained depth-blind, first-observation shortcut, exact coded control, family scores and false positives.

Yggdrasil: 48 public counterfactuals from seeds 64300–64323 using variable slot reuse and competing four-hop paths with connected cross-branch distractors; negative pairs change exactly one main-path binding input. Outcomes include learned, independently trained variable-blind, always-yes shortcut, exact coded control, family scores and false positives.

F106's new conditions are **development challenge generators**, not independently witnessed unseen scientific datasets. The model and frozen public challenge generator both exist in this repository. Only the previous frozen training blocks are used to fit the models. The coded strong controls are ground-truth/verdict checks and cannot enter the candidate predictions or fit.

## Feedback and honest negative-result policy

A passing or failing screen both produce full source-bound reports and a distinct **untested, non-dispatchable next-direction advisory**. New learned score below a frozen 0.75 paired accuracy, fewer than 0.15 absolute points improvement over blind, or worst new family below 0.60 is a retained negative outcome, **not** a CI/authority failure or grounds for tuning the challenge after inspection. Source missing, mismatch, tampering, missing controls, unexpected F105 choice or strong coded oracle mismatch **is** CI-failing.

F106 demonstrates one new current-run *decision → bounded fresh development assessment → negative-preserving feedback* step. A six-hour GitHub rerun on the same frozen source and data yields the same scores; this is **not sustained fresh autonomous science, unrestricted agent reasoning or genuine unattended GPT inference**. Repeated novel proposed-and-executed experiments with qualified custody remain separate work.
