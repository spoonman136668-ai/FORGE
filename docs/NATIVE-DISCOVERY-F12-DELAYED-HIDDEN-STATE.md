## Hypothesis and world
F11's static sign world exactly matches its conventional 32-hypothesis factor control, so targeting uncertainty is not proven beneficial. F12 deliberately changes **the question**, not the score threshold: a hidden-state dynamical world in which actions causally modify a two-bit state and consequences become visible **two steps later**. Unknown world law is from a fixed **16-rule causal shift-register class**, not copied into the learner, with four binary coefficients (action flip, visible-cue-parity effect, world-phase effect, and bias):
`h[t+1] = ((h[t] & 1)<<1) | (((h[t]>>1)&1) XOR actionCoeff*a[t] XOR cueCoeff*(cue[t]&1) XOR phaseCoeff*phase[t] XOR bias)`.
The upper bit of state is hidden; immediate sensor shows only low bit. At time t≥2, telemetry reveals the state **after action t-2**, not the current state or next label. A startup state at t=1 is permitted as a fixed calibration. No state oracle, true rule, seed mapping, future telemetry or evaluation answers are passed to any learner. Only the isolated synthetic development world generator may read the rule or ground-truth state.

**Fixed DEV split** seeds 17 and 31 only, *not* 59 or 83 or an external first-use benchmark. Each arm has 48 initial actions in phase 0, then six interventions after a phase transition, frozen fixed or deterministic random policies (two planners × two seeds = four arms). The action schedule must be selected before world transition is evaluated. Budget is exactly 54 actions/arm, with two delayed outcomes still pending at the G2 cutoff. At G1 (51 actions) only 49 transitions can be credited; at G2 (54 actions) only 52, so false full-feedback replay must fail.

## Falsifiable mechanism and matched controls
F12-Causal is an online, action-aware **16-hypothesis posterior** with a frozen 3:1 likelihood ratio for a correct versus incorrect *already observed* two-step-delayed transition. Weights use bounded max-score-relative integer powers, not ground-truth rules, for cold-portable deterministic counts. Predict the state **two actions ahead** by propagating a single internally consistent hypothesis through both consecutive transitions and weight-voting its terminal two-bit state. No evaluation labels update weights.

Fully trained controls share **exactly the same credited 49/52 action-consequence transitions and immediate sensors**:
- **F12-MLE:** strongest same-class, maximum-likelihood 16-hypothesis deterministic conventional model (tie lower rule ID), propagated through both steps.
- **F12-Tabular:** direct empirical 2-bit next-state distribution keyed by phase, hidden-state-at-credited-time, cue parity, action; trained to completion on all available credited transitions.
- **F12-NoAction ablation:** all same data but restricted eight rule variants with action coefficient zero. Tests whether intervention dependence is necessary.
- **F12-WrongLag negative:** same data but deliberately attributes the delayed outcome to the preceding action (one-step lag), not the true two-step cause. A result that does not beat this ablation casts doubt on causal credit assignment.
- **True-rule oracle:** **upper ceiling only** for a synthetic diagnostic, never counted as learned evidence or a baseline to beat; any learner exceeding this deterministic ceiling indicates leakage/test error. Model code must not call the oracle.

Scoring: 64 blinded-within-development two-bit future-state predictions per model per phase per arm, from eight disjoint 10-step synthetic episodes with **no update to training counts**, using the latest genuinely revealed delayed state and the last/current actions (eight scored t=2..9). Report original-world phase 0 retention and changed-world phase 1 G1/G2 scores, correct causal contrasts, calibration, cold restoration, snapshot SHA, complete score and latency/prediction-call counters. These are only repeatable synthetic DEV scores, not unknown-world scientific proof. Original-world and changed-world use the same world rule, so no claim of unseen task generalization.

**Frozen promotion criterion:** Causal G2 must beat the *stronger of MLE and tabular* by ≥4/64 correct decisions **on both seeds under both intervention policies** AND beat **both no-action and wrong-lag ablations** by ≥8/64 on every arm; no original-world retention regression relative to G1, cold G1→G2 exact source parity, no pending credit leakage. If not, report `F12_DEV_NO_GO`, retain every loss/tie; do not search parameters on these seeds. If met, report only `F12_DEV_SIGNAL_UNVERIFIED` (science still unverified). MLE shares the same exact 16-rule hypothesis class; thus a genuine gain may be difficult, which is intentional.

**Predeclared failure fence:** Any oracle outcome used before selection, future delayed transition counted early, missing action from credit history, noncanonical snapshot, corrupted digest, premature holdout 59/83, owner or scientific acceptance, discounted conventional competitor, winner-only filtering, or manual live FORGE scope expansion is FAIL, not a claim of gain.
