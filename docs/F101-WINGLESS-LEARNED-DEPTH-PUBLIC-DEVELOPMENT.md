## What is actually learned

A four-scalar learned recurrence reads **public graph edges and requested depth**, propagates source state along each directed edge for the requested number of steps, and learns a depth-sensitive gain and Bernoulli readout using 100 full-cohort gradient updates. The actual candidate prediction cannot invoke the coded exact-depth oracle.

The data generator uses new, separately frozen public-development seed blocks `63100–63115`, `63132–63147`, `63164–63179`: three paired counterfactual cases per seed, **144 pairs** total. First two blocks (96 pairs) train; last public group (48 pairs) is a development diagnostic, **not a protected test, sealed holdout, independent original or source-birth validation**. The generator contains a directed path of length 4–7, disjoint distractors, and source branches without a shorter path to target. This is a deliberately constrained demonstration; success cannot establish general relation composition outside these generated topologies.

The strong controls include an independently trained size-matched no-depth model, depth-input permutation, always-yes shortcut, and an exact-depth coded oracle **only for ground truth and control**. W-F10 is retained strictly as a historical negative source reference and is *not replayed or relabeled as development success*. Frozen F101 criteria: 75% paired accuracy, +15 percentage points versus size-matched depth-blind, 60% worst depth and public source group. All results are development-only and outcomes remain negative if those criteria are not met.

The source-only `nativeevidence/f101_wingless_public_depth.py` evaluates those actual learned weights and paired control predictions without any API/model service. `test_f101_wingless_public_depth.py` independently exercises seed isolation, complete cohort and control coverage, bounded updates, tampered frozen authority, source binding, and no candidate oracle call.
