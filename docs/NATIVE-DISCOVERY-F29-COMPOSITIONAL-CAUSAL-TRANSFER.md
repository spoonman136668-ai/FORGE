## Frozen model portfolio and algorithms

Eight independent arms; every arm gets identical actual training/transfer interactions, action schedules, sensors, cold restart and scorer targets:
1. **composed-causal-filter (candidate):** from frozen A/B 4-state delta posteriors for action0 and action1, form baseline distributions `P(base|bank)` and effect distributions `P(effect|bank)` by exact mod4 convolution of delta-action1 with minus delta-action0; form action1 delta for each AA/AB/BA/BB pair by mod4 convolution, action0 uses base only. Posterior over pair sources per cue starts uniform. Before each forecast, blend all four pair delta distributions with those per-cue weights, then convolve with the recursively filtered latent state. Each credited sensor transition updates the pair weights via its predicted delta likelihood with fixed hazard 0.02 toward uniform and Bayes renormalization; the state posterior is updated by exact sensor likelihood convolution with the candidate predicted transition. **A and B archives remain frozen**; no scratch local-law fitting.
2. **stationary-delta**: F28's trained recurrent Bayesian delta learner with 32 Dirichlet parameters; retains training across cold restore and adapts online.
3. **factorized-bayes**: F28's trained archive/scratch per-(cue,action) conventional Bayes mixture.
4. **switch-bayes**: F28's trained global-hazard three-regime Bayesian control.
5. **markov-bayes**: F28's fully trained 128-parameter conventional Markov model.
6. **online-softmax**: F28's fully trained four-pass SGD 4-class classifier.
7. **no-composition ablation**: exact candidate except forbidden to use cross-archive pair AB/BA (weights renormalized AA/BB only).
8. **wrong-action attribution ablation**: exact candidate but each incoming real action is inverted when learning pair-source weights (environment action and outcome remain untouched).

All conventional controls are trained, not zero-init; the baseline selection is *after* outcomes for evaluation only, never an online model choice.
