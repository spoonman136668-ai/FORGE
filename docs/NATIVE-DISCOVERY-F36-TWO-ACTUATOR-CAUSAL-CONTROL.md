## What is new, and falsifiable

Replace the exhausted four-state, one-actuator trial with a 16-state, **two-actuator** causal system and goal-directed choices. The state is a persistent 4-bit register `s∈[0,15]`. Action `a∈{0,1,2}` means no-op, actuator1 or actuator2. Issuing action1/2 at step t under a physical law enqueues an immutable `(due=t+lag-1, mask∈[1,15])` event; each due event XORs its mask into s at the due transition. Multiple events can overlap or cancel. There is NO spontaneous state change. Two noisy 16-way sensors reveal the register (first correct 92%, else one-bit-flip chosen by public deterministic hash; second correct 84%, else one bit flip), independent streams. No hidden clean state, pending queue, physical regime or due-effect oracle is accessible to any learning/planning method.

True A/B physical masks and lags are defined as fixed simulator-only arrays, each 4 cues×2 actuators, masks 1–15 and lags 1–3. Unfamiliar C/D physical laws are untrained cross-combinations: C takes A masks/B lags for even cues, B masks/A lags for odd cues; D uses opposite. The environment retains issued events and their source law across switches. Every learner uses only observed sensors, earlier actions/cues and public goals.

## Frozen fully observed training exposure (no clean-label leakage)

Training world 431 has law A; 433 law B; **192 real transitions each**. For cycle j=0..15, cue=j%4; at relative step0 choose actuator1, at step5 actuator2, otherwise no-op. The two real actuator pulses are separated by 5 steps, longer than max lag3. Therefore every world has **four isolated interventions per cue and per actuator**, with paired two-sensor observations before/during/after each event. Initial register and each sensor noise stream use fixed `f27Mix` seed-derived hashes, not scorer labels. All models train on **exactly the same 384 actions and sensor observations**.

For each bank, cue, actuator, learn all 45 mask×lag hypotheses using only sensor evidence: multiply exact emission likelihood over the pulse's observation sequence under each hypothesized mask and lag and marginalize over all 16 possible pre-pulse clean states. Prior uniform; normalized posterior after four pulse windows. Deterministic argmax with mask,lag lexical tie-break. Train a single pooled-event model on the same 384 real transitions. Fully trained conventional history model receives the same 384 steps; multinomial 16-class SGD 4 passes with bias, prior sensor-state one-hot and last three cue/actuator indicators, learning rate .05 and weight decay .0001. No model sees hidden physical masks, lags or clean scorer state, including during training.

## Frozen goal-directed test worlds and budgets

New transfer seeds 439 balanced A→B→A→C, 443 skewed B→A→B→D, 449 balanced A→B→A→D, 457 skewed B→A→B→C. Each 96 real transitions with four unannounced, 24-transition phases; all methods cold restore identical trained source state before each world and never replay original training data. Goal is announced every four steps (24 goals/world), fixed independently from agent actions: `goal=f27Mix(seed ^ uint32(goalIndex+1)*0x7f4a7c15 ^ 0x52dce729)&15`. Cue at step t: balanced `(t/2+seed%4)%4`, skewed `(t/4+seed%2)%2` unless t%8=6, where `(t/4+seed%4)%4`. A goal is scored only at the end of its four-step window. Agent acts on all four steps, no more than **36 nonzero actions per 96-transition world**, receives each actual post-action sensor pair, and replans at each step. It may select action0/1/2 at each step based on *predicted terminal probability of the fixed public goal assuming no further future actions*, subtracting a fixed **0.03** intervention cost from each nonzero-action choice; tie breaks to no-op. All methods get same goal stream, initial latent register, cue schedule, noise-function recipe, opportunities and intervention cap, but different actions create different on-policy sensor observations (do not claim equal realized traces).

## Frozen portfolio and planning

1. **compositional-issued-memory (candidate):** learned A/B 45-way pulse evidence, 4 causal composition hypotheses AA, AB, BA, BB. Retain each actual issued event's hypothesized due+mask at issuance and propagate it independently through physical regime changes. Recursively update state belief from sensor likelihood; update four regime-hypothesis weights with fixed hazard .05 and observed next sensors. At forecast, enumerate each of four hypotheses for all currently pending receipts and candidate next action to obtain 16-state terminal distribution; no simulator truth or future feedback. If a hypothesis gives zero likelihood, use **fixed sensor likelihood floor 1e-9**, count floor hits, never change thresholds after measurement.
2. **two-bank-issued-bayes (strong control):** identical event custody, 16-state filter and decision rule with hypotheses AA/BB (duplicate hypotheses to use the same four planning slots), trained on same 384 interactions; fixed hazard .05, same emission floor.
3. **pooled-issued-bayes (strong control):** same event custody and filter with one pooled learned event model (padded to four computational slots), same full 384 training observations.
4. **history-logistic (strong control):** fully trained 16-way autoregressive history model, same 384 training interactions and online updates; use four-step forecast that marginalizes next sensor emissions using a *non-training* cloned model, no clean-target feedback.
5. **drop-history (ablation):** candidate's learned causal model but discards outstanding event receipts at each action choice; its physical environment is unchanged.
6. **cold-zero (ablation):** candidate with all learned event templates replaced by a fixed mask1,lag1; no replay.
7. **always-zero** and 8. **random-budget**: action controls with same cap and deterministic seed.

Planners must all receive only public goal/cue and their own observed sensor/action histories; never phase label, clean target, simulator mask/lag or counterfactual outcome. Report full training transitions and pulses, model storage count, counted work, interventions, wall-clock total, source/goal/actions/sensors/checkpoint/terminal digests, cold vs warm byte-exact replay. A common action budget is **not matched computation**; do not claim independent scientific equivalence. All stronger baseline methods are fully trained on the same real observations.
