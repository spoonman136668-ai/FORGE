## Locked propensity and target

Source `f51.behavior_action(obs,rng)` has: with probability 0.60 take uniform 0/1/2; otherwise with probability 0.40, if `abs(obs[5])<0.2` then with conditional probability 0.10 take action 1, else momentum heuristic `h=2 if obs[5]>=0 else 0`; when `abs(obs[5])>=0.2`, take h. Thus exact behavior probabilities `b(a|obs)`:
- always, nonheuristic other torque: `0.20`;
- `abs(obs[5])>=0.2`: `b(h)=0.60`, `b(1)=0.20`;
- `abs(obs[5])<0.2`: `b(h)=0.56`, `b(1)=0.24`.
Every logged action's exact propensity must be between 0.20 and 0.60; three probabilities sum to 1 for every observation. This is an analytical **source-derived** propensity, not fitted from outcomes.

Acrobot observation `(cos(theta1),sin(theta1),cos(theta2),sin(theta2),v1,v2)` defines normalized real physical tip height `H(obs)=-obs[0]-(obs[0]*obs[2]-obs[1]*obs[3])`. Define actual recorded one-step change `y=H(next_obs)-H(obs)`, bounded in [-4,4]. Do not use `reward` as a proxy (almost all are -1) or claim y is undiscounted return.

For target arm `p`, on each of that fold's historical excluded-root observations: policy deterministic action `a_p(obs)`, recorded randomized action `a_b`; score **Horvitz–Thompson (unnormalized IPS) term** `z_p = 1[a_b=a_p(obs)]*y/b(a_p(obs)|obs)`. Estimate each arm's root-specific one-step y as `mean(z_p)`; compute root-specific *paired* candidate-vs-baseline contrast `mean(z_candidate-z_baseline)` from the same recorded observations (cancellation on identical actions). Also compute per-arm matched count, sum weights, IPS mean, self-normalized IPS mean (diagnostic only) and effective sample size `ESS=(sum w)^2/sum(w^2)`, but **never** use self-normalized diagnostics to select the outcome.

Aggregate each root's IPS mean with **equal 1/6 weight**, not an exposure-weighted pooled mean; compute differences against `momentum-rule`, `frozen-fqi`, and `rotated-credit`. Choose strongest conventional comparator as the higher of the two aggregate IPS means among `momentum-rule` and `frozen-fqi`, ties favor momentum; prespecified choice, no different estimator search. For each contrast, form **exhaustive six-root cluster bootstrap** using all ordered `6^6=46,656` resampled root-index tuples, average their corresponding root-level paired contrasts, use NumPy default linear 2.5th and 97.5th percentiles. This is a sensitivity interval from six related historical roots, **not a confirmatory population CI**. Also report rootwise positive contrasts, action-difference counts and distribution of matched behavior actions.
