## Retention boundaries

- No new D1/Cloudflare Worker/controller or paid API; no modification or disruption to current Wingless/Yggdrasil scientific workflows. Public GitHub logs contain **no raw archive ZIPs, import SQL payloads, tokens, DB UUIDs, or recovery bookmarks**. The D1 holds data; output and source scripts do not create downloadable original archives.
- Installed triggers enforce immutable UPDATE/DELETE for originals, chunks and seals, parent/range protection, and seal completeness. A sufficiently privileged Cloudflare database administrator who can alter schema remains capable of removing these protections. D1 is not a separately administered off-account immutable witness.
- The Time Travel bookmark was created before the import within an ephemeral runner, not continuously independently retained. No destructive restore test was performed; this is not evidence of guaranteed long-term off-account recovery.
