# Eureka F26 — Causal-effect information gain under scarce interventions (DEV)

**Prospectively frozen on 2026-11-09, before F26 implementation/testing/scoring.** Exact F25 parent `7cf32ad71d13f94f3740b5ce278f3cf2b7aa84f8`, whose result remains `F25_DEV_NO_GO` (1/4). F22–F24 negatives also preserved. Only draft PR #1614.

## Why a distinct experiment
F25's passive-baseline-known intervention trigger loses to standard Bayes on balanced cues (two controls scored 32/32, a ceiling that made a +2 gain impossible) but improves rare-cue coverage in one skewed arm. F26 instead computes **expected information gained specifically about each cue's latent causal action-effect bit** from do(1) versus do(0), using the same posterior and credited data available to conventional controls. It applies *evidence-aware per-cue budget reservations* (at most 2 credited or pending interventions per cue) to avoid spending all budget on common cues. No F25 threshold or old code is altered.

## Four sealed-at-protocol synthetic DEV arms
Seeds `193` and `197`, schedules `balanced` and `skewed`. Exactly 48 actual decisions per arm, `do(0)` free, `do(1)` costs 1, total budget 8. Unknown 8-bit causal laws (simulator/scorer only): seed193 `0x4b`, seed197 `0xb2`; independent cue baseline bits 0..3, action-effect bits 4..7. Genuine consequence: `((law>>cue)&1) XOR (action & ((law>>(cue+4))&1))`. Public balanced cues `f12Mix(seed XOR uint32(t+1)*0x27d4eb2d)&3`; public skewed cues `(t/5+seed%2)%2`, except every fifth step `(t/5+seed%4)%4`. Two-step delayed credit of actual chosen action. Erasures if `f12Mix(seed XOR 0x31415926 XOR uint32(t+1)*0x9e3779b9)%13==0`; otherwise bit flips if `f12Mix(seed XOR 0x27182818 XOR uint32(t+1)*0x85ebca6b)%17==0`. No learner sees true law, counterfactual outcome, first-use seed, future cue, hidden phase or uncredited consequence.

## Frozen eight matched control/ablation policies + candidate
Policy order: **effect-ig (candidate)**, **f25-causal-pair** (F25 published threshold, as-is), **bayes-ig**, **bayes-error**, **thompson**, **periodic** (`t%6==0`), **random** (deterministic `f12Mix(seed XOR uint32(t+1)*0x9e3779b9)%6==0`), **no-intervention**, **wrong-credit**. All 9 are independently trained online and use exactly the same per-cue 4-state uniform prior, factorized posterior updated with 8:1 likelihood from *real credited outcomes*, identical history capacity, timing and budgets; all score using the same binary MAP (`p>0.5`), except wrong-credit attribution is purposefully corrupted. `thompson` uses an independent deterministic sampler, not scorer truth. The candidate computes `IG_E(a)=H(E)-sum_y p(y|do(a)) H(E|y,do(a))`, using 8:1 likelihood, intervening only if `IG_E(1)>IG_E(0)+1e-8`, fewer than 2 same-cue action1 credits and no same-cue pending action1; otherwise passive. Both action options are evaluated on the same current posterior. No hindsight best-policy lookup.

## Scoring and qualification
Score all eight cue×action counterfactuals only inside the scorer at **t=10,18,26,34** (after due credit, before decision), yielding 32 correctness bits per trial. Exact clock; bound 8 interventions. At step24, capture canonical checkpoint (22 credits, 2 pending), restart in isolated state and require byte-identical actions, scores, final state to uninterrupted. Terminal: 46 credits, 2 pending. Record per-checkpoint counts, actions SHA256, checkpoint and final digest, work counts, and scorer trace. Tests must reject reorders/tampering, unknown seeds/policies and false science/owner/first-use labels.

**F26_DEV_SIGNAL_UNVERIFIED** if and only if ALL four arms: candidate >= strongest of **six** deployable conventional controls (F25 candidate plus five others) by **at least +2/32**; >=+3/32 against no-intervention and wrong-credit; 2..8 interventions; negative/cold-source/custody tests PASS. Otherwise **F26_DEV_NO_GO**, including ceiling. No post-score modification. A developmental signal is **not** SCIENTIFIC_PASS and never justifies automatic integration/merge/first-use/deployment.
