# Native discovery F0: action–consequence development protocol

## Purpose and status
Add a bounded, **source-only / synthetic development** evaluator beside the existing F95 typed relational-memory prototype. It tests a learning mechanism's ability to update from observed action consequences, choose actions towards goals, retain state after cold restoration, generalize to unfamiliar object identities, and withstand changed dynamics/interference. This does not establish general intelligence, scientific discovery, active FORGE RSI, or Wingless/Yggdrasil scientific acceptance.

This is a **development protocol, not an independently sealed preregistration**: synthetic dry-run smoke tests were conducted during implementation before GitHub CI. No real/consumed experimental inputs or authentic scientific first-use are allowed.

## Fixed cohorts and inputs
- Baseline exact FORGE main `525cd7eb45aaeb48706c5986103d509a0d92cc76` (tree `8b1e2def8ab8b98cdc544c8f1be767f7d239d5f4`).
- Seeds: **11, 23, 47**. Each seed uses 3 cues × 2 modes × 3 actions × 5 training rounds = **90 action–consequence transitions**. All models receive the **same logged actions and consequences**.
- Transfer is held-out *object identity*, not a novel causal-rule distribution. **36 goal-choice evaluations/seed**, no model updates on transfer outcomes. A separate inverted causal world tests transfer to unfamiliar dynamics and should be treated as a negative.
- Interference: 8 rounds of opposite causal effects on the same cues, with reassessment against the original world; no retention claimed when degraded.
- All source-internal environment outcomes are deterministic, synthetic and visible to reviewers. Neither sealed research data nor a private first-use token exists.
- Conventional baselines: object-conditioned empirical tabular action model and a **strong feature-compositional empirical table** trained with the exact same observed transitions. The original F95 typed-relation representation stores learned cue/mode/action consequences. These are not fully trained neural models; that is a limitation on future comparative science.

## Frozen evaluation
- Primary: goal-action optimality on unseen object identities, compared with **the better-performing conventional control** per seed.
- Development success requires candidate gain ≥ **5 percentage points** over the strongest control on **at least 2/3 seeds**, exact cold-restoration parity, and ≤ **10 percentage points** interference-induced loss. A tie means **NO_GO**.
- Separate diagnostics: fresh model, shuffled/inverted feedback, unseen reversed causal dynamics, all before any output or control selection. Preserve negatives, no threshold or seed tuning after CI.
- Account for training transitions, per-model process wall time, snapshot bytes and evaluation decisions. These are **development resource diagnostics**, not matched CPU/RSS/FLOP or whole-process cost qualification.
- Structural pass requires all comparators trained, unchanged test source semantics, model cold restore, invalid transition and corrupted snapshot rejection. **Go tests may pass even when the frozen benefit criterion fails.** Exact hosted Linux/Windows full regression, Go build, vet and Linux race still apply.

## Boundaries and decision
No new controller, scheduler, queue, model service, paid API, policy promotion, original-owner mutation, science first-use, Wingless/Yggdrasil source edit or dispatch. All code is additive and the normal owner remains on its pinned source. Optional existing AI-assisted FORGE capabilities remain intact.

Any synthetic advantage is **development-only**, with `scientific_accepted=false` and `general_rsi_proven=false`. Genuine scientific qualification requires independent original data, frozen conventional baselines, preregistered holdouts, matched information/actions/compute, multiple seeds, causal intervention, retention/transfer and external evidence; execution/promotion is separate and requires authorized original-owner/FSA gates.

After qualified F0, the next Eureka-style step is to connect candidate search to this evaluator **without giving it execution authority**; only evidence and independently admitted proposals may advance.
