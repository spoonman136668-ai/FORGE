# F139 G1 — Model-free source-candidate producer

## Why G1

F139's original Windows controller resumed at event171 on merged PR #834, and
its advisory lineage now binds a pre-outcome recommendation to a separately
qualified single-commit, single-file owner draft. The remaining candidate
supply gap is real: existing Dream-RSI, Pareto, ThetaEvolve and other research
advisors rank hypotheses but do not create executable native source code.

G1 implements **one finite structural generation recipe**, not a scheduler
or speculative unlimited self-improvement loop. The original F139 feeder,
owner SQLite, and immutable negative evidence remain unchanged.

## Source-generation hypothesis

`f139.nci04_candidate_producer.produce` accepts *externally verified* exact
Yggdrasil parent commit and source bytes, an immutable before-byte SHA256,
historical digest and already-consumed mechanism identities. The fixed
`tier-local-partial-pooling-when-unobserved-v1` recipe modifies
`yggdrasil/public_causal_cells.py` to borrow empirical action/outcome counts
from other public contexts only within the **same active/retained tier** and
only for the arm missing local observations.

It uses no paid inference, hidden oracle, larger model, cross-tier transfer,
additional learned memory or arbitrary untrusted generated code. Whether
cross-context borrowing generalizes to unfamiliar tasks or merely exploits
shared observational shortcuts is explicitly **UNTESTED**. The existing native
fixed-code and cross-platform regressions may produce a useful negative.

The output consists of deterministic candidate bytes, a content-addressed
candidate identity and an evidence-only hypothesis record. The generator has
no GitHub writer and no controller dispatch, source promotion, credential,
first-use or policy mutation pathway.

## End-to-end development acceptance boundary

1. Obtain the original public source from an authentic GitHub commit/tree/blob
   and independently check its exact SHA. Run the new bounded source generator
   with a prospectively frozen historical digest and consumed IDs.
2. Commit the generated bytes on a single-commit, single-allowlisted-file
   native source branch. Create an owner-authored **draft**
   `F139 autonomy DEV:` PR. An ordinary PR has no authority until the
   original F139 feeder independently GET-verifies the commit, parent, tree,
   before/after Git blob bytes, source-policy SHA and deduplicates its intent.
3. The unchanged original owner may admit at most two qualified development
   attempts per rolling ten minutes, while preserving all genuine failures and
   independent Ubuntu/Windows provider receipts.
4. Do not attach a fabricated `infogain.Decision`. A real advisory-bearing
   PR requires a separately frozen authentic decision record produced
   *before* observing its experimental outcome.
5. Development qualification is not scientific first-use. An independently
   protected unseen-family transfer cohort, fitted equal-information controls,
   causal ablations, retention tests and full resource accounting remain
   mandatory before any positive research claim.

## Future G2 activation, not granted here

To remove the human-authored PR bottleneck, independently qualify a bounded
source-proposal publisher and an authenticated existing-owner GitHub writer
that emits only eligible draft PRs, with an immutable pre-outcome advisory
record, full source authentication, duplicate prevention and stop-on-failure.
This step would need original-owner source transition/requalification and
must not create any second scheduler, queue or controller.

This G1 source-only artifact proves **structural code can be generated
deterministically** from an explicit mechanism hypothesis, not that a research
agent has independently discovered the right hypothesis or is continually
producing new science.
