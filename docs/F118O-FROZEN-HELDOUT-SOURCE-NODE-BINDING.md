## Actual connected source edges and strict node split
- Enumerate exact unique source triples and build per-node lexicographically first genuine incoming source edge A -r1→ B and first genuine outgoing source edge B -r2→ C. A qualifying intermediate node B has at least one incoming and one outgoing source edge. Duplicate original source rows do not multiply candidates. Self-loop-only examples may be excluded only by precommitted fixed rule: require A != B and B != C; source roles remain opaque and not features.
- Sort qualifying node IDs by (SHA256(raw UTF-8 node ID bytes), raw UTF-8 bytes). Before accessing source-derived example labels assign every node deterministically to TRAIN if first 8 digest bytes uint64 big-endian %10 is 0–6, DEV if 7, TEST if 8–9. Every split is **node-disjoint**, not merely row-disjoint; some A/C endpoints may overlap splits, but trained input depends **only on intermediate candidate IDs B and B'**, never on A/C, target answer or source role.
- Freeze first exactly **512** qualifying TRAIN nodes, first **128** qualifying DEV nodes, and first **256** qualifying TEST nodes (or fail, never shrink/reselect using performance). Each produces exactly one positive (first original incoming to B, first original outgoing from B) and one negative (the same first incoming to B, a first original outgoing edge from **different** B' in the same split, explicitly nonidentical intermediate ID). The negative B' is chosen deterministically: among all qualifying nodes in the **same split** with the *same first hexadecimal SHA256 nibble* as B, choose the next cyclic node in source-hash order, not B; fail if such B' does not exist. Every selected original edge must exist in source triple set and both intermediate IDs must be in the declared same split. No training instance shares an intermediate candidate node with DEV/TEST.
- Labels are exact **physical join identity**: 1 iff B==B'. The external graph ensures *both* individual source edges are genuine; mere existence of two source relationships is not enough. The two endpoint graph edges are test provenance, never inferred predictions. Equal/different labels and candidate B IDs cannot be used by the trained comparator except indirectly through the fixed numeric fingerprint features below.

## Precommitted learned mechanism and controls
- For each intermediate node name generate SHA256 UTF-8 digest. Model input is exactly **eight** per-byte equality indicators from first 8 digest bytes of the two candidate intermediate IDs: x[d]=1 if SHA256(B)[d] == SHA256(B')[d], else 0; this is an identity-derived *lossy surrogate*, not raw entity IDs or source KG traversal. Baseline SHA-nibble equality gets identical values for positive and frozen same-nibble hard negatives; an exact symbolic ID equality comparison is a privileged deterministic upper bound and must score 100% by design.
- Trainable 9-parameter logistic comparator `sigmoid(b + sum_{d=0..7}w[d]*x[d])`. Fixed initialization: weights 0, intercept 0; exactly **160** full-batch deterministic epochs learning rate **0.35**, L2 **0.005** only on weights, mean logistic cross entropy gradient; cutoff **0.5**. Training only on the 1024 TRAIN examples, no update on DEV or TEST. Report parameter SHA256 quantized to 8 decimal places to avoid OS libm string drift, weight norm, train logloss before/after, 9 actual parameters. If weights do not move or training loss does not fall, engineering mechanism FAIL.
- Frozen controls: (A) train-majority constant (ties choose negative); (B) first-nibble-equality heuristic; (C) exact symbolic B==B' identity comparator; (D) fixed 8-byte hash equality for collision sanity, labeled an untrained comparator, **not** a learned generalization. Report raw accuracy, balanced accuracy and confusion matrices on both DEV (inspection only) and TEST, plus pairwise distinct node count and no-collision count. No model reweighting, threshold change, cohort replacement, after-result tuning or architecture search.
- F118 **engineering exploratory success** iff unseen TEST both classes present, train loss decreased, learned TEST balanced accuracy ≥0.90 **and** not worse than untrained nibble control by 0.10 or more; no claim of beating exact symbolic benchmark. Always report measured negative if it fails.
- Scientific limits predeclared: identity hash bytes explicitly encode the answer predicate's equality signal and exact-ID baseline is perfect. Thus even a perfect learned result only proves that a tiny numeric comparator can approximate deterministic equality across unseen hashed IDs.
