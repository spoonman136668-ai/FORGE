## Frozen implementation and budget (before executable implementation)

1. Create an **independent source-only** `noveltymechanisms/largegraph` Go package providing deterministic immutable typed graph indexing for whole public MetaQA knowledge graphs, with lossless case-sensitive source entity/role names (no lowercase coercion), *directed* forward/reverse arc choice and a **caller-supplied typed-role sequence**. F95 code and its 128-edge API remain unchanged. The proposed index is not the existing F95 model and does not magically prove F95 correctness or generalization.
2. Parse original three-field source rows `subject|relation|object`. Keep exact source row count; suppress duplicates only when compiling a searchable index and publish duplicate count. Keep self-links rather than silently dropping them; publish their count and F95 incompatibility. Deterministic sort for all adjacency lists and returned endpoints. Disallow empty/binary fields and newline injection.
3. Hard intake budgets: **150,000 source rows, 50,000 unique entities, 128 distinct raw roles, 512 UTF-8 bytes per name/role, 7,000,000 source bytes**; fail closed if exceeded. No partial index. Query accepts only **one to three exact caller-specified role/direction steps**, each forward or reverse; no role derivation from question text or labels. Hard max **4,096 distinct nodes in each traversed frontier and returned targets**: overflow returns a typed budget error; never truncate, rank, sample, leak expected answers or silently certify a subset. An empty but valid binding is a negative resolution, not an error.
