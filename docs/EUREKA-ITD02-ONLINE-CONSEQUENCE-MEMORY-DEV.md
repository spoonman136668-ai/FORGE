## Concrete missing ability

F57's candidate is frozen during unfamiliar-world evaluation. It cannot test **learning from action consequences during interaction or persisting that newly learned state across cold restart**. Implement a small reusable, observation-only numerical learner whose behavior genuinely changes when its own action outcomes arrive. It must not ingest hidden simulator states, world types, hypothetical counterfactual answers, evaluator truth, policy labels or privileged future rewards. It is **not** a pretrained language model, transformer, token-level predictor or claim of novel intelligence.

## Frozen design / source API

- Pure Python **standard library only**, no Gymnasium environment imports, no `step`, `reset`, filesystem, HTTP, worker, queue, signer, controller or provider API. Deterministic CPU math on 2–6 bounded real-valued public observations and 2–6 discrete interventions, each with a finite observed scalar consequence in [-100,100].
- One online multi-action ridge model learns observed consequence as `theta[action] · [1, public_observation]` from **only executed action/outcome pairs**. Start each action's normal matrix at `lambda=0.1 * Identity`; allow `observed` to update just the actually selected action. No fictitious counterfactual updates, state oracle or private world IDs.
- Expose a **read-only proposal** choice among available actions based on learned expected consequence plus bounded exploration bonus proportional to the current variance proxy `sqrt(phi^T A[action]^{-1} phi)`. Proposal must have **no physical side effects** and cannot issue environment steps. An optional dry-run proposal record is only an inert request; the caller must separately obtain original execution authority and observe the real consequence.
- Every observation has a strictly sequential process-local `event_seq` starting at 0, finite values and exact action/public vector domain. Repeated, skipped, swapped or invalid observed events are rejected; no unbounded growth (`max_events` explicit ≤10,000). This is a local replay safeguard, **not independent FSA custody or first-use**.
- Checkpoint the full **learned numerical matrices and action evidence counts**, not only an opaque file-path receipt. Canonical versioned JSON, SHA256 integrity, complete data-event hash chain and bounded payload. On cold restoration require an externally supplied exact SHA256 and minimum expected event index; reject stale/tampered/NaN/invalid-dimension/nonpositive matrices. These external strings are not signatures/independent high-water. A cold-restored learner can receive **new** experiences and continue from learned state without rebuilding its old experience.
- Deterministic linear solves; fail closed on singular/nonfinite numerical values and ambiguous state, never silently reset. All arithmetic, snapshot and negative tests use source-free numeric fixtures only.

## Frozen development falsifiers / controls

1. Same 3-action 2D public numerical stream, at least 30 interventions per action, generated by a deterministic **test fixture** outside model code. Candidate must reduce held-out *interpolation* consequence MSE below 0.01 without hidden world inputs. Learned parameters must not appear before feedback.
2. An equally informed action-blind fitted ridge (same logged observed rows) and a rotated-action-credit negative each must have held-out MSE at least 2x candidate in this **fixture**. Include a fully fitted separate-action conventional ridge **as the strong upper control**: candidate is not required to beat it; report that no advantage is established.
3. Checkpoint after learned experiences, cold restore and append genuinely new numerical experiences; byte-exact model/canonical state after both direct and cold continuation; matching predictions and deterministic policy proposals. Tamper, rollback and sequential-event negatives reject.
4. Check both cases where exploration intentionally probes a poorly identified intervention and where `exploration_weight=0` selects the learned greedy action. Do not infer causal identification merely from random action counts.
5. Source audit must find **no** Gymnasium original import, experiment launcher, file writer, persistent credentials, private API, F57 seed list, scheduler, runtime activation or FSA bypass. Native FORGE original Linux/Windows full regression on final SHA is mandatory. Since native CI does not automatically discover standalone Python research tests, focused tests must actually execute on an existing eligible GitHub-hosted runner (temporary exact-branch, own-PR workflow addition followed by byte-exact restoration, or an existing supported native test route), not claimed from generic CI alone.
