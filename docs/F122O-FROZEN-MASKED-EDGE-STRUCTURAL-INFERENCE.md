# F122-O — frozen structural inference over genuinely withheld graph edges

**Preregistered as first F122 commit, before model implementation or F122 source graph inspection.** Engineering-qualified F121-O parent PR #431 exact head `886d8c9713156ec96bf066651b66b8b047ec4f72`; exact-head Ubuntu/Windows #39035871379. F121's trained 2-hop-to-3-hop signed-role gate reached 0.95 balanced accuracy but lost to a nonlearned **1.00** fixed signed-role matcher; its graph edges, joins, and perfect role-alignment indicator were supplied. F122 removes those shortcuts: **no source role type, gold edge presence indicator, exact node hash, or complete positive path is provided as a model input**. The model must predict missing authentic source edge existence from incomplete local **unlabeled graph topology**; explicit admitted residual edges and adjacency are still supplied, and the model is not learning raw graph construction from images or natural language.

## Feature budget, model and strict controls

- Model sees only **eight fixed structural features per (root,candidate) from RESIDUAL graph**: `log1p(deg(root))/6`, `log1p(deg(candidate))/6`, absolute difference of those two, `log1p(#common neighbor nodes)/6`, `sum_{shared neighbor} 1/log(2+degree(shared neighbor))/6`, `log1p(#simple 3-edge walks root→x→y→candidate)/6` with all path nodes distinct and residual edges only, `log1p(#3walks)/(1+log1p(deg(root)*deg(candidate)))`, and `log1p(sum residual neighbor degrees of candidate)/6`. Clip every feature to [0,2]. No signed-role type, raw source identity/equality, withheld original edge bit, target label, ground-truth path or original QA data.
- A connected walk is found only by actual residual adjacency; 2/3-hop structural statistics may be zero and are not guaranteed to include the missing source edge or a 'perfect path'. Entire incident masked pair removed, and no source physical edge count that was masked may leak into features. True unseen subgraphs may have different topology distributions, report honest negative.
- Trainable **8→6→1 tanh MLP** with 61 numerical parameters (48 hidden weights, six hidden biases, six output weights, one output bias). Init each hidden/output weight from SHA256(`F122O-v1|layer|i|j`) first 16-bit mapped [-0.05,+0.05], biases zero. Fixed **180** full-batch epochs, gradient descent LR **0.45**, L2 **0.002** on weights only. For each TRAIN task candidate pair, contrastive logit difference `score_positive-score_negative` optimized with logistic softplus loss; mean gradients per 192 tasks. No random seeds, minibatch, early stopping, threshold sweeping, validation selection, leakage or pretrained weights. Training must decrease loss and move learned weights, else fail engineering. Candidate with higher score chosen, ties index 0. Emit train initial/final loss and learned fingerprint 8-decimal-quantized for OS comparison.
- Strong frozen arms: (A) first candidate constant, (B) fixed larger **common-neighbor score**, (C) fixed **Adamic-Adar weighted common-neighbor** score, (D) fixed 3-hop simple path count, (E) **train-only 9-parameter linear contrastive structural-score model** on the exact same train features with same 180 epochs/LR/L2, (F) same MLP at its frozen untrained initialization, (G) **privileged original-edge existence oracle** with complete source pairs = 100% by task construction, clearly NOT an allowed inference model. Every non-oracle sees only residual feature vectors. No exact signed-role identity heuristic in this task because roles are deliberately removed.
- Terminal primary outcome: accuracy and **balanced accuracy** over 64 TEST tasks for predicting whether true withheld edge is candidate #0, with both classes required. Frozen exploratory gain iff learned MLP terminal BA≥max(all nonoracle controls)+0.05; record negative otherwise. Also report 48 DEV tasks as inspection-only, no hyperparameter tuning.
- Honest scientific status: masked-edge status is a synthetic label derivation from one public KG, negative sampling could introduce dataset shortcuts, and privileged full-graph original membership supplies labels. Even success cannot qualify genuine source-independent causal relation reasoning, Wingless/Yggdrasil scientific improvement, protected independent first-use, or autonomous research-policy optimization.
