## Frozen lexical linker (NOT a model and NOT independent evidence)
1. Train-only dictionary from **exactly one annotated Freebase topic per original parse**, indexing valid `PotentialTopicEntityMention` and `TopicEntityName` variants (strings 1–128 UTF-8 bytes), with valid `TopicEntityMid` (ASCII Freebase MID syntax `/m/[a-z0-9_]{1,64}` or `/g/[a-z0-9_]{1,64}`). Normalize mention lexical text by Unicode **NFKC**, `casefold()`, collapse *ASCII and Unicode whitespace* to a single space, trim outer whitespace. Retain punctuation and internal word order; no fuzzy edit-distance, embedding, guessed alias, cross-entity disambiguation or gold-answer use. Index only TRAIN parse instances; source labels explicitly used to construct TRAIN lexicon, so no claim of independently learned entity representations.
2. For each normalized mention, retain the **set of all distinct MIDs** seen; **ambiguous mention→multiple MIDs is forbidden** for resolution and remains counted. Identical duplicate TRAIN evidence does not increase entries; source row and parse denominator still counted.
3. The frozen runtime `Link(question, lexicon)` takes only original **RawQuestion**, not `Parses`, `Answers`, entity MID or a pretrained answer. Normalize the whole raw question with the *same* NFKC/casefold/whitespace rule (≤2048 original question bytes). Generate contiguous token n-grams **1–10 tokens**, matched using complete normalized whitespace-delimited lexical tokens with retained punctuation. No substring-inside-token, prefix, suffix, longest-only cherry-pick, or answer-informed tie breaking. Count all *distinct matched mention strings*. If zero matches, abstain `no_lexical_anchor`. If any matched mention is ambiguous (MID set size≠1), abstain `ambiguous_train_lexicon`. If matched unique mentions yield more than one distinct MID, abstain `multiple_candidate_anchors`; if exactly one MID, resolve. Source name can contain punctuation; ambiguous/incomplete annotations never become accepted evidence. Cap original dictionary ≤100,000 entries; cap candidate question token count ≤128 (oversize abstains, no truncation).
4. This is **in-sample, TRAIN-only lexical diagnostic**: original 20,358 question denominator, counts for unique resolvable, zero, ambiguous lexicon, competing MIDs and invalid annotation rows, without comparing to TRAIN gold MID or answers. No original question/mention strings, MIDs, relation labels, or per-row answers may appear in output artifact or logs. Only aggregate counts, source Git SHA256/object and freeze contract ID.
5. Separately inventory original TRAIN parse `InferentialChain` as **aggregate structural statistics ONLY**: chains that are lists, number of chain entries 0/1/2/3/4+ and number of distinct role **strings** (not names). No role-to-natural-language mapping, evaluation-label-derived planner, relation selection, predicate-to-MetaQA coercion, or actual Freebase graph. Syntax checking of original TRAIN metadata is allowed but this is not a qualified translator.
