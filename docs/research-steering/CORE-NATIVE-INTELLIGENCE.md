# ITD-02 research acceleration — Core Native Intelligence

**Status:** Operator-directed, advisory steering candidate (2026-10-25). This file does not change any controller, accepted source, frozen scientific protocol, protected first-use authority, or research runtime.

**Outcome:** Make the existing independent Wingless and Yggdrasil *native* models learn causal consequences, retain knowledge, and improve decisions in unfamiliar situations. Successful auxiliary prototypes are not a substitute for native model capability.

## Prioritized acceleration

1. **Decision-discriminating original environments (first):** select eligible source-public development interactions in which learned experience can change a legal action and subsequent actual outcome. Reject saturated evaluations where trained, shuffled, and untrained action choice is identical. Do not build a convenient substitute world or consume protected evaluation rights.
2. **Native integration fast lane (first):** every promising mechanism must identify an existing Wingless or Yggdrasil learner interface, its original state/checkpoint identity, an isolated opt-in development delta, exact fallback, and an integration acceptance path. Preserve accepted models; no model or checkpoint overwrite.
3. **Uncertainty-aware short-horizon causal planning (next):** learn observed multi-step action effects and uncertainty from allowed real source interactions, choose an informative action, update beliefs from the actual consequence, and replan. Compare against equally informed trained model-based/recurrent/graph controls. A hand-programmed planner alone is not native learned intelligence.
4. **Reusable multistep skills (later):** learn transferable action sequences and their termination/credit assignment; show useful consequences across new task contexts rather than a memorized macro.
5. **Adaptive plasticity protection (later):** preserve established knowledge while learning new tasks; permit bounded allocation, repair or consolidation only with measured interference, retention and memory/compute cost.

Use the existing Dream-RSI, ShinkaEvolve/Pareto, ThetaEvolve, Promptbreeder, DGM/GenEnv, BIO, NCI-10/11/12, compositional learning and content-addressed-reuse portfolio as eligible discovery aids. Qualified compatible enhancements **may be combined in development first**; require exact component identities and independent post-discovery ablation plus prospective confirmation, not preliminary proof of every component in isolation.

## Progress and boundaries

Report real chosen-action/return changes, retained capability after cold restart, family transfer, complete interaction/CPU/peak memory/checkpoint cost, conventional parity, and which candidate is actually integration-ready. Preserve all prior scientific negatives and frozen baselines (including Wingless R5/F8-F12 and Yggdrasil C31-C38); do not tune consumed sources.

Wingless and Yggdrasil remain architecturally distinct non-transformer, non-next-token cognitive foundations. Keep existing hash-pinned charters and `.research-autonomy/config.json` unchanged. Eligible public development can proceed **only** through its already-authorized contract; a protocol prohibiting original episodes must not be silently bypassed. FORGE/FSA retains the relevant protected scientific authority. No new controller, worker, queue, paid API, or accepted-ref mutation.
