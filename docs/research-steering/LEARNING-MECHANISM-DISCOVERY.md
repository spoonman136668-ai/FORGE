# ITD-02 research acceleration — Learning & Mechanism Discovery

**Status:** Operator-directed, advisory steering candidate (2026-10-25). Do not reset BIO, Optimizer, L9/L10 language work, the portfolio, any frozen experiment, or existing native research.

**Outcome:** Supply working, bounded native-learning mechanisms to the existing Wingless and Yggdrasil foundations—not more unrelated source-only prototypes or optimization gate counts.

## Seven optimizations; use existing infrastructure first

| Optimization | Priority / difficulty | Mechanism-discovery responsibility |
| --- | --- | --- |
| Decision-discriminating environment screening | First / easy-medium | Find eligible genuine source-public decisions where learned history plausibly changes the selected action and result; stop saturated tests early. |
| Native integration fast lane | First / medium | Attach each useful candidate to a real Wingless or Yggdrasil learner/state/checkpoint interface with opt-in rollback. |
| Uncertainty-aware short-horizon planning | Next / medium-hard | Explore multi-outcome retained causal belief plus brief planning, intervention and correction from actual consequences. |
| Reusable multistep skills | Later / hard | Learn compositional reusable options with learned initiation/termination and credible transfer. |
| Adaptive plasticity protection | Alongside / hard | Test selective consolidation, retention, forgetting and resource-bounded adaptation without catastrophic interference. |
| Learning-progress curriculum | Alongside / medium | Adapt only eligible development-task selection from measured learner deficits/progress; never expose or retune sealed validation. |
| Multi-fidelity research allocation | Supporting / easy-medium | Content-addressed cheap screens, diverse combined finalists, controlled full training, then independent evaluation; track total compute. |

Full shared discovery portfolio remains available to all three research workspaces: Dream-RSI, ShinkaEvolve/Pareto, ThetaEvolve, Promptbreeder, DGM/GenEnv, evidence-informed hypothesis discrimination, BIO fast/slow replay and uncertainty, NCI-10/11/12 memory, LCRM/causal/compositional learning, self-monitoring/repair, and efficient language/semantics.

**Combination-first discovery:** Multiple properly qualified mechanisms may be assembled into a reproducible candidate before individual attribution is known. Preserve configurations, budgets, source cohorts and checkpoints. If the combination improves actual learner outcomes, freeze it; independent validation then runs selective ablations and prospective controls. Do not insist each element independently wins before combination. Do not let generators select protected held-outs, claim own science, or write accepted models.

Candidate outputs must specify **native consumer**, tested action/consequence interface, trained improvement versus fair controls, cold state retention, exact source lineage, whole-process resources, rollback path, and integration readiness. Retire repeated small changes after credible scientific negatives unless the hypothesis is materially different. Never conflate engineered source-only or authored fixture PASS with external-world learning.

No new scheduler, controller, queue, API cost, source/protocol rewrite, unauthorized original-world first use or production integration. Existing FORGE/FSA and native architectural boundaries prevail.
