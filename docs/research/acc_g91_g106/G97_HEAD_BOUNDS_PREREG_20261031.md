## Hypothesis, controls, and analytic correctness certificate

Each attention head produces `y_h = Wout_h @ softmax(K_h @ q_h / sqrt(d)) @ V_h` (with compatible vector orientations). Softmax weights are positive and sum to one, so `||y_h||_2 <= max_j ||V_hj||_2 * ||Wout_h||_2`. Precompute this per-head conservative upper bound `B_h` (use **true matrix spectral norm**, not an underestimated predictor). Evaluate heads in descending `B_h`, adding their actual outputs. At each step, let `A=||accumulator||` and `R=sum_{unvisited} B_h`. Omit remaining heads only if `A>R` and `R <= 1e-3 * (A-R)`; triangle inequalities then prove relative output L2 error <=1e-3. A small `1e-10*(1+abs(B_h))` inflation is added to bounds to cover floating-point rounding. The candidate pays per-query head ordering, checks, attention scores and matmuls. Precomputed max value norms and spectral norms are reported separately, **excluded** from per-query speed (optimistic). No full-head output may be computed to decide which heads to skip.

## Frozen dataset and experiment

- NumPy float64, single BLAS thread. `H=8` attention heads, `N=128` keys/head, `d=16`, output width `64`, `8` queries per seed; seeds `[9701,9702,9703]`, regimes `normal` and deliberately favorable `three_near_zero_heads`.
- For each seed and regime, generate independent `K,V ~ N(0,1)` arrays of shape [8,128,16], `Q ~ N(0,1)` array [8,8,16] (query case x head x dim), and `Wout ~ N(0,1/sqrt(16))` array [8,16,64]. For favorable regime **only**, multiply heads indices 5,6,7 of `Wout` by `1e-6`. No weighting tricks or baseline-state leaking in the normal regime. Both arms use exactly the same generated inputs, sorted only on conservative bounds.
- Per seed/regime, precompute eight spectral norms and value maxima once; report initialization milliseconds. Baseline uses NumPy vectorized attention over all eight heads and the complete output projection; candidate runs per-head computations for visited heads. Exactly `3*2*8=48` cases.
- Warm both implementations once, then record **7 alternating paired trials** per case with full candidate cost. Persist all 48 raw cases: seed/regime/query index, rows scored, heads visited/skipped, end-to-end milliseconds, speedup, true relative-L2 error, certificate absolute bound, bound-audit correctness, early-stop flag, and environment.
- Every case must have finite intermediates/outputs; **relative L2 <=1e-3** and observed absolute error <= certificate + `1e-9` for every case; bound each actual isolated head norm <= inflated bound + `1e-9`. Report the per-query bound/check overhead; no uncharged model output reconstruction.
- Frozen **NO-GO** if any violation, missing case, or if median end-to-end dense/candidate speedup is below **1.15x in either regime** (normal negative control and favorable regime both required). Otherwise `CONDITIONAL_CPU_FEASIBILITY_ONLY`. This cutoff is screening-only, not a modification of any already frozen scientific acceptance threshold.
- No claims about head dispensability or learned semantic redundancy from synthetic low-output weights. A future survivor requires real model weight/value structure, optimized GPU kernels, held-out accuracy and separate authentic-science qualification before promotion.
