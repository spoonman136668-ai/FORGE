# ACC-G99 — outlier-preserving INT8 + FP32 sparse residual: frozen pre-screen

**Preregistered before code/measurements.** GPU-track G91–G106 exploration under FORGE draft PR #1329, independent of GPT-2 CPU and G79–G90. This is a **NumPy CPU proxy**, not a genuine CUDA fused kernel or authentic TinyLlama throughput result. Baseline main SHA `0810ecf3df6378bcbfe5239d30df836b7e12a602`. ## Hypothesis and costs

A rowwise INT8 weight matrix can be stored with separate, exact FP32 "outlier" weights. For each row, select exactly the largest `K` weight magnitudes, keep their original FP32 values and column indices, and zero those positions in the INT8 substrate **before** selecting the substrate's symmetric per-row scale. At query time, decode the substrate and add `sum(outlier_value * x[index])` per row. The stored bytes include the entire dense INT8 matrix, one FP32 scale per row, and K FP32 values plus K uint16 indices per row; this is an optimistic weight-only storage accounting, excluding padding/alignment, metadata, input and runtime buffers. Report separate preprocessing cost; exclude it from repeated inference timing while explicitly charging all runtime decode, gathering, residual and reduction operations. Quantization error is approximate; NO EXACTNESS claim.

## Frozen experimental inputs and comparisons

- NumPy CPU, float32 arithmetic and one BLAS thread, three seeds `[9901,9902,9903]`. Weight shape `[512,256]`, query shape `[8,256]`; independently seeded `N(0,1/sqrt(256))` W and `N(0,1)` x.
- Regimes `iid` negative control (no injected outliers), and `injected_outliers` deliberately favorable: for each row independently choose **exactly 4** distinct columns via the same seeded generator, and multiply those four existing weights by **32**. All queries independent of outlier position; favorable distribution is NOT observed in a model.
- Outlier quotas `K ∈ {0,2,8}` (must report all K; do not pick winner post hoc). Full per-row int8 scale `scale=max(abs(substrate))/127` (or `1` only for all-zero substrate); `quantized=clip(rint(substrate/scale),-127,127).astype(int8)`. Preserve selected outliers as original float32 with uint16 column IDs. No stochastic rounding. For K=0 no outlier allocation.
- Baseline `W @ x` float32, single-thread optimized BLAS. Candidate per query: `(int8.astype(float32)*row_scale)@x` plus exact sparse dot of outlier values and gathered query entries; **do not cache decoded FP32 weights**, and charge all temporary allocations. Per-query median timing from 7 alternating paired trials after warmup, including full output; dataset creation/compression excluded as both can reuse W across many queries.
- `3 seeds × 2 regimes × 3 K × 8 queries = 144` cases. Record every raw case, relative L2 and max-abs output error, baseline/candidate latency, median speedup, all finite flags. Record each compression setup time and actual accounted bytes per candidate. Report compression ratio `candidate_stored_bytes / (512×256×4)`.
- **CONDITIONAL_CPU_FEASIBILITY_ONLY** requires some **single fixed K** meet all conditions: every one of its **48 cases** has relative L2 error `<=1e-2`, both regimes' median measured speedup **>=1.15×**, and candidate accounted storage **<=0.65× FP32 baseline**. Any nonfinite values, skipped cases or broken byte accounting => **NO_GO_SYNTHETIC_SCREEN**. Avoid reporting a conditional result from favorable regime alone.
