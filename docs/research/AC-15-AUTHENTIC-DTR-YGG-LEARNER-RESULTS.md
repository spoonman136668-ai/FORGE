## Actual run and controls

The **unmodified** original DTR source process executed exactly **8 FIT episodes** with seeds `760000..760007` and **4 separately fixed DEV episodes** with seeds `760200..760203`, **12 additional genuine source-owned public episodes, 24 source-owned actions per OS**. Existing AC-14 source-public smoke used a different pair of seeds. Reserved public VALID seeds `760100..760103` were not touched, and no unknown-family / sealed scientific families were accessed.

For each stage, behavior action was predefined before seeing an outcome: stage-0 `index % 2`, stage-1 `(index // 2) % 2`. Public observable stage, binary observation, action, next observation, terminal reward and done fields were whitelisted; the original source `info`, latent confounder, private causal graph, `ctf_do` and environment object were never provided to learner or conventional control. Original `ctf_do` permission was confirmed denied. There were no learned model actions fed back to the environment during DEV or FIT.

Existing learner was **actually fitted** with `16` source-owned FIT observations via `PublicCausalCells.observe`. Stage-0 public next observation was its binary learning outcome, and stage-1 public terminal reward was its binary learning outcome, with address `2*stage+observed_bit`. This is an explicit associative control, not correct assignment of stage-0 causal credit for a later reward.

After FIT it produced the original **164-byte checkpoint**, which passed cold `restore` byte parity. During all eight DEV decisions, learner was frozen and **0 updates** occurred. A fully fitted tabular control received exactly the same 16 FIT action/outcome events and reproduced every `choose` recommendation and abstention; a fitted global action-count control was also recorded. This means a simpler fitted control ties the candidate, and no policy benefit can be inferred from the scripted, off-policy behaviors.
