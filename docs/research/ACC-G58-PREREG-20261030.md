## Four strictly precommitted backward schedules

All four use **full 4-block forward** at EVERY training step. On a *partial-backward step* detach the output of an unchanged prefix evaluated under `torch.no_grad()`, train only the remaining upper blocks and output head; lower-block and embedding parameters get **no gradients** on that step. Future full updates still update all weights. All methods retain the same complete inference parameters.

- `baseline`: full gradient through all four blocks all 480 steps
- `top2_half`: on odd-numbered **zero-indexed** steps (240/480), no backward through embedding + blocks 0,1; full backward otherwise. Upper blocks 2,3 and head trained at every step.
- `top2_two_thirds`: on steps where `step % 3 != 0` (320/480), no backward through embedding + blocks 0,1; full backward otherwise.
- `top3_two_thirds`: on steps where `step % 3 != 0` (320/480), no backward through embedding + block 0; train blocks 1,2,3 + head, full backward otherwise.

**Each arm** trains on identical total input tokens and runs 480 optimizer steps. Count full/partial updates, prefix forward and backward block counts, optimizer state bytes when available; do not claim fewer *tokens* or fewer *updates*. No dynamic selection or post-hoc schedule alterations. Pretest gradient-mask correctness, full-forward equality, initial-state equality and source identity.
