## Frozen scope
Implement a genuine analytically differentiated rank-4 LoRA adapter `y(x)=W0*x+B*(A*x)`, W0 deterministic frozen, A/B trainable. Objective `0.5*mean(sum_o(prediction-target)^2)`, synchronous full-batch SGD learning rate **0.05**, **4 update steps**, exact same initial parameters and examples for all modes. Source data are **synthetic locally generated** from public deterministic seeds, *not* a real pretrained LLM, training dataset, physical distributed cluster, or model-level first use. Include central serial **in-process** reference and **persistent local subprocess parameter-server** modes with **1/2/4 worker processes**. In worker modes, central coordinator broadcasts the current LoRA adapter and each worker receives its disjoint examples, computes true local analytic gradients; coordinator collects gradients, reduces them by sample count, applies the same update, counts request and response bytes. Worker startup, IPC, training steps and shutdown count in measured end-to-end wall-clock. All modes use identical math and end-to-end workload; split changes only process count. This is not all-reduce optimized DDP, GPU training or cross-host networking.

Frozen dimensions **16 and 32** for both input/output, rank **4**, seeds **211,223,227**, 64 FIT examples, 16 untouched deterministic validation examples, repetitions **2**, modes `serial`, `process_1`, `process_2`, `process_4`: **2*3*2*4=48** full training runs per operating system. Fixed source generation PRNG `random.Random(seed*1000+dimension)`; teacher and init LoRA drawn deterministically from it. In worker modes, send actual sample vectors/targets, full A/B, epoch as newline-delimited JSON over ordinary process pipes; response contains full summed analytic gradient, local loss and sample count. Always account serialized traffic and each spawned process; no uncharged cross-host bandwidth claim. Use `time.perf_counter_ns` for full measured training window (not validation or corpus generation), and report median by dimension and mode. Report process count, bytes communicated, per-case latency, validation loss and parameter hashes.
