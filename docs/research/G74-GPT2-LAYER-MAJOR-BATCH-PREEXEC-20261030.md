## Matched request scheduling intervention
- Exactly 12 independent heldout requests; process in four sequential waves of **three simultaneous arrivals**. Every request generates 8 greedy tokens with EOS stopping disabled; no answer caching, no future token or known label access, no training or input adaptation. First public nonheldout warmup for all control arms.
- Four arms on same warmed model/tokenizer and fixed 3 CPU affinity:
  1. `solo_serial`: three uncached manual incremental GPT-2 decoders serially per wave.
  2. `solo_parallel`: three independent uncached manual decoders in a max-3 threaded executor, including thread-pool startup/shutdown and future waits.
  3. `hf_batched`: Hugging Face pretrained `generate` on left-padded batch of three with causal mask and original per-token position mapping, explicitly batch-3, no cross-request cache; **strongest existing batching-library control**.
  4. `layer_major`: direct original GPT-2 manual batch-3 prefill then incremental decoder, one native model forward per layer across all three requests per step. Align variable-length prompts with left padding; correct position IDs from causal attention mask, no invisible per-row truncation. Verify exact original greedy IDs against both `solo_serial` and `hf_batched` per request. No claim of kernel fusion; measure all tensor construction, padding, masks, thread pool, logits, model computation and output extraction within whole-wave timers.
- Three fixed counterbalanced arm-order repetitions for each wave after untimed public warmup; 4 waves × 4 arms × 3 repeats × 3 requests = **144 measured responses**, each 8 original greedy tokens. Every wave has 3 independent originals and the same arrivals in every arm. No manual seed choice after results. All arms use one pretrained model object with PyTorch threadcount 1, resident model warmup excluded but report model staging/initialization and real package RAM cost.
- Record request input/output token hashes; per-wave and per-request completion wall (the synchronized/batch arms charge wave completion to all three requests); process CPU time, sampled process RSS (not true peak), batch shapes/pad counts and CPU affinity, model/dataset source hashes, complete original dependency freeze. Record all 48 arm-wave trials with per-request output digest and wall. No algorithmically irrelevant input parsing or sample rewriting.
