## Critical separation from U14
U14's established **universal lossless** counting obstruction is already qualified (PR #1294, run #41134850787, final commit `7c6776d840ef8ea9a942de9e5b73a4b9424d15d0`). ACC-63 tests the *distinct restricted hypothesis* that a **small hierarchical-seed surrogate dictionary** can reconstruct an independently specified weight matrix, selected from observed training entries and evaluated on withheld entries, at competitive representation/accuracy costs. This synthetic multiscale surrogate is **NOT a verified implementation of an original proposed fractal algorithm**, nor an actual pretrained LLM.

## Frozen study
Two signed-int8 square matrix sides **32 and 64**. Fixed hierarchical decoder consists of three additive pseudo-random block levels with integer coefficients from SHA256(seed, level, block-row, block-column), levels with blocks of width N/4, N/8, N/16; output clipped to signed value range [-8,7]. Candidate decoder seeds **0..31** (1-byte stored index); fixed integer hash domain/decoder, no trainable weights and no hidden target lookup.

Targets: three **in-dictionary hierarchical** seeds [3, 11, 23]; three **out-of-dictionary hierarchical** seeds [37, 41, 43]; and three deterministic independent **hash-array control** identifiers [101,103,107]. Hash-array controls are pseudo-random-looking but generated deterministically and are *not* mathematically incompressible or an independently sampled pretrained source. Per side this produces 9 targets; **18 total source matrices**. FIT/CHECK is a fixed split with 1/5 positions CHECK based on SHA256 of `(side,row,col)` with a distinct frozen split domain; the other positions FIT. At least 15% and at most 25% CHECK required; no CHECK entry used for selection.

Select one of the 32 hierarchical candidate seeds minimizing FIT mean absolute error (MAE), tie break by lowest seed. Evaluate exact reconstructed tensor bytes, CHECK MAE and CHECK exact-match share; additionally evaluate three deterministic int64 matvec inputs per target with exact output comparisons, plus max absolute output error. FIT-only conventional controls: global-mean integer, row-mean integer, and column-mean integer, rounding ties documented; report CHECK MAE for each. Do not choose a baseline by viewing CHECK. Report seed-payload byte count and full algorithm Python source byte count separately; **do not assert a real binary-size or physical memory advantage**. The 32 candidate seeds are charged as dictionary search evaluation, and full target generation must be charged in offline acquisition if comparing lifecycle resources.
