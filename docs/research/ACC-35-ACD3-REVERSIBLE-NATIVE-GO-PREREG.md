**New Stage-2 experiment:** a **real compiled Go** reversible compressed-prefix/radix memory with exact per-identity label-count storage. It learns shared history prefixes through insertion only, branching when previously indistinguishable histories diverge late; no hand-labeled equivalence classes or future labels supplied. Compare four arms on identical ordered public synthetic histories: (1) RAW exact full-key map and raw binary snapshot, (2) RADIX native reversible identity-preserving prefix trie with binary snapshot and exact cold restore, (3) ZLIB a *strong* conventional storage compression baseline using same full-key binary snapshot, decompress once at restore and answer exact lookups, and (4) UNSAFE prefix-only identity collapse on the same histories to demonstrate delayed-counterexample loss. ZLIB and RAW require no learned-world labels, no external source use; all have access to the same input sequence. No actual Wingless/Ygg model source or neuron/LLM corpus is accessed.

**Locked workload:** 1,024 public histories of length 64 and 512 exact-retrieval queries/session (256 seen and 256 absent), 16 consecutive *fresh full-cost sessions per worker* to exceed short-lived Windows child process timer granularity. Each history contains a 40-byte repeated prefix from 16 groups and independently generated 24-byte suffix; deterministic source-free PRNG fixed in code. Scenarios `BENIGN` target outcome depends only on group, and `DELAYED` target depends on late suffix state, forcing contradictory reward labels under the same prefix. An exact storage must reproduce every observed key and abstain on absent keys, including delayed contradictions; no partial future-only checking. Input generation, insertion, index construction, snapshot, cold restoration, evaluation/digest all charged in **whole-worker child process CPU**. Fixed 3 paired order-alternated trials per arm/scenario per OS; 4 arms × 2 scenarios × 3 trials = **24 subprocesses per host**, 16 sessions each. Record worker process CPU from Go `os.ProcessState.UserTime()+SystemTime()`, parent spawn-to-exit wall, and encoded snapshot length plus Go allocations; not production OS peak RSS/energy/VRAM. If CPU counters zero, classify **BLOCKED**; don't use wall as CPU.
 
**Correctness/acceptance:** exact RAW/RADIX/ZLIB query digests must agree per deterministic session, zero false answers and zero missed past histories; UNSAFE must demonstrably produce >=1 wrong/ambiguous delayed answer (negative control) and may not be counted as resource winner. Positive **engineering-only** requires all exactness checks, a witnessed radix split on contradictory delayed entries, and on **both Ubuntu and Windows**, in **both BENIGN and DELAYED**: radix median whole-worker CPU / RAW <= **1.15**, median radix snapshot bytes / RAW <= **0.75**, and radix median snapshot bytes / ZLIB <= **1.00**. Any miss = `ACC35_ACD3_NO_CROSSHOST_TOTAL_CPU_AND_STRONG_COMPRESSION_WIN`. This is expected to be difficult; no post-hoc threshold changes, selective scenarios, ignored memory metadata or forecasted speedups.
 
**Safeguards:** new Go 1.25 isolated `research/acceleration/acc35_go_memory/` module, pure source-free tests, exact 36-ID scoreboard regression, GitHub-hosted Windows/Linux qualifications and artifacts. No native original model integration, scientific unfamiliar-family first use, matched actual learning quality, accepted science, protected main, scheduler/F139/CKB-plane, paid APIs or autonomous queue changes.
