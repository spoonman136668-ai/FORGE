## Question
Can a strictly local, adaptive one-dimensional cellular-memory learner with bounded **nearest-neighbor information exchange** improve accuracy and *complete training/inference process CPU* over fully trained conventional frequency and local-memory controls on an independently generated binary action-consequence world, without learning a hidden answer table by oracle?

## Frozen public observations, source regimes, train/eval separation
- Fixed ring width **64 binary cells**. At every trial, every cell publicly observes its own and its immediate left/right prior-state bits (eight possible 3-bit neighborhoods), takes the public advance action, and receives the consequence bit from a source-generated unknown Boolean transition rule. All arms observe the same position, public neighborhood, action and consequence during FIT. **The unknown rule bits must not be passed to the learning arms**; they are held by a separate source generator. During heldout evaluation, candidate predictions must happen before revealing the true consequence to the auditor; no heldout training.
- Independent source seed blocks **96301,96303,96307,96309,96311**, source namespace `0x1dc6e99a83b2f041`, rule generator namespace `0x8bde31f247a96055`. Each cold child runs **256 independent reset episodes**, each with **256 FIT states** and **256 unseen evaluation states**, each state comprising all 64 cells. Independent FIT/evaluation state keys, same source sequence and rule IDs across arms. No labeling based on validation outcomes or post-result tuning.
- Exactly three regimes: **UNIFORM** (all 64 cells share one secret, independently seeded 8-neighborhood Boolean rule); **FOUR_REGIONS** (four contiguous publicly visible 16-cell regions with independent secret rules); **RULE_SHIFT** (four secret rules switch to independent previously unseen rules halfway through FIT, so the last 128 FIT states reflect the new regime; evaluation uses only final new rules, never an implicit oracle). All three are deterministic, source-hashed and independently seeded per episode.
- Generalization: heldout inputs are newly generated public binary configurations, including neighborhood combinations not guaranteed to have appeared within a cell's individual FIT stream. Record per-regime unseen-neighborhood coverage for all arms; count all errors. All source generation, rule generation, training, model-memory allocation, evaluation and truth auditing are charged to the same fresh worker. This is a **source-free microbenchmark**, not evidence of transfer to a substantially different world.

## Four immutable candidate/control arms
1. **GLOBAL_FREQ:** conventional eight-neighborhood frequency learner shared across all positions. Online counts for observed (neighborhood, consequence), prediction majority with deterministic tie=0, no hidden rule.
2. **REGION_FREQ:** conventional four-region × eight-neighborhood frequency learner. The four cell-position regions are public; update each region's counts identically from public FIT evidence, majority prediction/tie=0.
3. **CELL_FREQ:** conventional independent 64-cell × eight-neighborhood frequency learner (same memory capacity as the proposed cellular learner), no cross-cell sharing or fixed oracle.
4. **LOCAL_CA:** proposed cellular learner with exactly the same independent per-cell FIT counts as CELL_FREQ, plus **fixed one-hop left/right communication at inference**, not global pooling. For each class and each neighborhood, score is `4*own_count + left_count + right_count` from the *current frozen FIT count snapshot*, periodic ring boundary, choose majority with fixed tie=0. Each cell can read only its own or its two adjacent cells' local counts. All neighbor reads and update costs are charged. No knowledge of secret regional boundaries beyond public position, no validation-dependent weighting, no global answer table or shared trained weights.

Counters must be integer, saturating before overflow, reset at every session; no hidden target oracle or validation leakage, no predetermined rule-specific shortcuts. The conventional region baseline is a strong fully informed control, not a weak constant baseline; CELL_FREQ is equal-capacity direct ablation of neighbor communication. Every arm processes identical FIT observations and heldout inputs. Candidate local byte occupancy is reported separately from genuine OS physical RSS.
