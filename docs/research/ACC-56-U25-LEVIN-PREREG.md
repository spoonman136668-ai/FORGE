# ACC-56 — prospective original U25 Levin-style bounded program search

**Frozen before implementation.** The original 30-entry AC-08 register at `research/ac07_sourcefree/ac08_portfolio.py` Git blob `5126c860771fb024ccfc14c3f7ee8925edf29787` identifies one-based U25 as **Levin-style bounded program search**. Research base `45b5d8173538a566bf0f63a8e2ade2dedb6e6166`. Research only; no actual Wingless/Yggdrasil, LLM or FORGE autonomous production promotion.

Test bounded universal-search-inspired scheduling in native Go against matched uniform enumeration, shortest-program-first and error-ranked exhaustive controls. Freeze a finite, explicit grammar of integer unary functions using modulo-2^64 arithmetic: x, constants -3..3, x+c, x*c, (x+c)*d, (x*c)+d, and (x+c)*(x+d), integer constants c,d in -3..3. Distinct candidate canonical strings and deterministic instruction operation counts are part of evidence.

Public fixed seeds 106101,106103,106107,106109,106111. Four source target families AFFINE, QUADRATIC, CONSTANT, and NOISY. 64 targets per worker; 12 train observations and 32 withheld x-values on a nonoverlapping domain, with deterministic 1-in-8 training-label corruption in NOISY and independently generated clean held-out labels. All candidate generation and source/task truth independent of algorithms and included in complete-worker CPU/RSS. No access to held-out truth in selection.

Freeze evaluation **budget 64 candidate training scorings per task**; exact same budget for all four methods; no post-budget full-program re-evaluation for selection. Methods: UNIFORM (lexical candidate order); LENGTH (ascending canonical description bytes); ERROR_FIRST (fixed deterministic initial shortlist based on program operation count, then training error within evaluated shortlist; no oracle/heldout); LEVIN (bounded priority schedule by 2^(canonical code length bucket, capped at 16) × deterministic operation cost, with budgeted interleaving and minimum observed training errors within candidates inspected). Selection tie breakers are training error, canonical length, canonical string. Every method must report evaluated candidates, selected-program SHA256, input/train/holdout-truth/heldout-prediction SHA256, heldout exact accuracy and full cold child CPU (User+System) plus OS peak physical RSS. Cache free, one deterministic candidate universe; explicitly report that finite grammar and budget are a limited analogue, not Levin universal search.

5 seeds ×4 task families ×4 arms = **80 cold worker processes per OS**, comparing each same public target set. Independent crossOS 80/80 source, selected program and heldout output parity plus Linux/Windows full process CPU/RSS, source identity and 36 preexisting research screening checks.

Acceptance: no missing or zero CPU/RSS; all exact public-source/target parity and 80/80 workers both OS; LEVIN heldout median exact accuracy improves >=5 percentage points versus best of three controls in >=2 families, regression <=2 points in all remaining families, CPU <=1.10× fastest conventional and RSS <=1.10× that control both OS. If fully verified but thresholds fail: `U25_NO_GENERAL_VERIFIED_NATIVE_GO_LEARNING_WIN`; if pass `U25_RESTRICTED_SYNTHETIC_GO_LEARNING_POSITIVE_ONLY`; invalid source/holdout separation/missing CPU or crossOS parity => `ACC56_U25_BLOCKED`. No trained-model claim. Keep PR draft/unmerged, no protected main, FORGE autonomy/F139, Mind-Palace authority, CKB-plane, paid API or original native model changes.
