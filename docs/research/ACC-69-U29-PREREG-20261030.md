# ACC-69 / U29: topology-to-semantics identifiability test
Prospective frozen protocol, 2026-10-30. Original portfolio U29 "topology to semantic prediction", AC08 registry Git blob `5126c860771fb024ccfc14c3f7ee8925edf29787`. AC06 already observed same topology with different role labels; do not reclassify that older toy negative as new native scientific evidence.

**Claim under test:** an *unlabeled graph topology alone* cannot uniquely recover arbitrary independent semantic edge labels when the same graph may support multiple role assignments. This is a structural identifiability question, not proof that topology is useless when meanings correlate with structure.

**Frozen matrix:** graphs of **4, 6, 8 vertices**, each as an undirected cycle with numbered vertices and ordered edges; **16** independent public SHA256-derived graph-role assignments per graph size, with each edge labeled either 0 or 1 from hash domain `forge-acc69-u29-label-v1` plus (size,assignment,edge). Complete **48 assignments**, evaluate all edges as heldout outcomes, no ability to train on target test roles. Topology-only constant classifier chooses the most common edge-label over other 15 assignments for each graph size (leave-one-assignment-out, strictly no target role exposure; tie predicts 0). Feature using the assignment ID and deterministic public label oracle is a **cheating positive oracle only**, not an eligible model/acceleration result. A fair identity-aware baseline uses the other 15 assignments' *per-edge* majority labels (tie 0), identical source access. Evaluate average accuracy, binary cross entropy (add-one smoothed), wrong cases, role-label SHA256 and topology SHA256; no predictor may see the heldout assignment labels. Count at least one identical topology with contradictory edge labels.

**Preregistered decision:** `U29_TOPOLOGY_ONLY_UNIVERSAL_SEMANTICS_NO_GO` when contradictory labels exist for identical graph topology and exact complete information/source checks pass. This does not rule out statistical predictive utility above chance, learning on structured semantic tasks, typed graphs or semantic context. `U29_GENERAL_SEMANTIC_MODEL_ADVANTAGE=UNVERIFIED` regardless. Standard library Python3.11 on original GitHub-hosted Linux and Windows, minimum 12 focused tests, inherited AC05/06/07/08 regression, exact crossOS outputs and full final-head qualification. No GPU, pretrained model, RSS/CPU speed acceptance, native Wingless/Yggdrasil effect, model promotion, main changes, paid APIs or controller manipulation. Draft research only.
