## Distinct questions
1. **Exact algebra:** Iterative radix-2 in-place Number Theoretic Transform modulo prime **998244353**, primitive root **3**, implementing **circular convolution**, compared with a fully independent naive exact integer convolution. All n in **[32,128,512,1024]** are powers of 2 dividing p-1. No floating point or precision confounds.
2. **Real, scoped CPU costs:** compare Python3.11 stdlib exact NTT versus Python3.11 stdlib skip-zero naive on **dense** uniform signed coefficient residues and **sparse** (about 90% zeros) workloads, public seeds **[28101,28103,28107]**, **3 paired timing repeats** per size, regime, seed: **72 paired comparisons** (144 timed arms) per OS. Generate deterministic operands once outside timing using random.Random(seed + n*100 + regime_index*10000), full sample hashes and outputs. Verify result identity *after* each timed call. Warm both functions once per case without using warmup as a sample. Benchmark measured execution of Python functions only, not subprocess startup, real-model generation, CPU system/user, energy or peak RSS. Actual time via perf_counter_ns. Report per-case timings, medians and ratio naive/NTT; do not assert a full-model improvement.
3. **Semantic boundary:** a fixed circular convolution commutes with circular shifts. Test explicit position-sensitive map F(x)_i = i*x_i mod p at n=8 on one-hot e0. It violates shift equivariance (F(shift(e0)) != shift(F(e0))), proving there is no fixed convolution that implements every position-dependent transformation. This disproves only **universal fixed-convolution semantic representation**, not that NTT can be a useful component of a context-dependent or learned semantic model. Exact NTT result isn't evidence of language understanding.
