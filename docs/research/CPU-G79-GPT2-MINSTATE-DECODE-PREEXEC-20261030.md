## Frozen three arms and controls
- (A) `explicit_mask`: original pretrained GPT-2 manually cached decoder: initial original model prefill; for each of seven subsequent steps create a fresh `torch.ones((1,current_input_length),dtype=torch.long)` attention mask, pass it with one-token `input_ids` and past cache, and collect output tensors in a Python list before `torch.cat`. This mirrors G74 proven baseline. Full model original weights and greedy logits.
- (B) `hf_generate`: original pretrained Hugging Face `model.generate(input_ids=full,attention_mask=torch.ones_like(full),max_new_tokens=8,min_new_tokens=8,eos_token_id=None,pad_token_id=tokenizer.eos_token_id,do_sample=False,num_beams=1,use_cache=True)`. Strongest library single-request control.
- (C) `minimal_state`: same original model and cache using `model(input_ids=full,use_cache=True)`, then for subsequent one-token forwards pass only `input_ids=token,past_key_values=past,use_cache=True` with **NO explicitly constructed attention_mask**; original GPT2 causal mask/implicit token positions must preserve exact output on these single unpadded inputs. Record generated tokens into a preallocated `torch.empty((1,8), dtype=torch.long)` response buffer. Do not bypass actual pretrained model operations or future token observation.
- Fixed public nonheldout warmup on all arms before holding out. For each of 12 original requests, **four** counterbalanced paired arm-order repetitions (12×4×3=**144** full original model timed responses; **1,152 generated tokens**). Arm order cyclically rotated by request and repetition, reversed on alternating repetition. Include *whole request* (prefill, original generation and output extraction); exclude model staging/tokenizer setup consistently but record them separately. Inside each timed call all tensor mask allocation, token buffer/list, Python and PyTorch dispatch and cache lifetime are charged. Separate process time, wall time, sampled RSS (not true peak); expose each token output SHA and input ID SHA.
