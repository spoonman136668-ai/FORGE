**Question:** Can a bitwise hyperdimensional (HD) key–value superposition represent paired associations more efficiently than classical bitset or direct associative representations, retaining discriminative retrieval after increasing interference, under real whole-child CPU, OS physical RSS and representation bytes?

**Data:** Fixed public seeds 107101,107103,107107,107109,107111. Four independently generated regimes: LOW (8 stored associations), MEDIUM (32), HIGH (128), SHIFT (32 stored, 50% test keys unfamiliar). Every source key and value has a public independently seeded 4096-bit bipolar signature. Per episode keys and values are independently sampled using SplitMix64, source hashes emitted. 32 independently reset episodes per native child; 1024 queries per episode, including known association queries and in SHIFT unfamiliar keys. For known keys exact value ID is independent public ground truth; for unknown keys the correct answer is MISS. Candidate must not be passed ground truth during query.

**Arms:** DIRECT exact key-to-value mapping; BITSET conventional binary signature + nearest Hamming similarity after storing key-specific value signatures; BLOOM conventional bounded membership prefilter plus value-hash reference; **HD_BIND** 4096-bit XOR key/value binding, majority bit bundling with tie-break deterministic public seed and XOR unbinding, then nearest Hamming value decode, optional fixed null-detection threshold frozen before trials.
