## Question and precise mechanism

Under bounded CPU conditions, can converting *native-shaped float32 GPT-2 cached K and V state* into per-tensor symmetric signed INT8 plus a scale, and reconstructing it, save enough memory to justify the additional work compared with ordinary deep-copy under a frozen resource budget? Compression is **lossy**, so this source-free result cannot grant exact output parity, safe model generation, or challenge-decoder GO. A separately preregistered original-model challenge-and-verify trial would be required **only if** this strict feasibility screen passes. Do not promote from synthetic to original model without lawful source, paired real workload, original independent full-precision verification and whole-life cost.

## Exact inputs and controls

- Use standard **NumPy 2.1.3** CPU, Python 3.11, no GPU, model downloads, network datasets or paid APIs. NumPy's native PCG64 generator seed `751975` draws independent standard-normal float32 samples. Label them **synthetic native-shaped tensors only**, NOT genuine GPT-2 inference. Each length L in `(64,256,512)` has 12 layers, separate K and V tensors, each shape `(1,12,L,64)`; aggregate 24 tensors, 12 heads, head_dim 64 and 768 hidden channels. No data selection or seed tuning after seeing results. One OpenBLAS thread. Preserve deterministic original input SHA256 per length and exact package/python/runtime/platform metadata.
- Three controls/actions on identical inputs: `readonly` retains the 24 original arrays by reference (reference zero-copy lower bound; never claim compressed version faster than readonly); `deepcopy` independently copies each array, which preserves exact float32 values; `int8_codec` computes a per-tensor maximum absolute value and scale `maxabs/127` (or scale 1 if zero), quantizes with `np.rint(x/scale).clip(-127,127).astype(np.int8)`, persists each compressed tensor and float32 scale, then restores via signed-float32 multiplication. No data-dependent training, transform candidates, hidden oracle, future tokens or generic model benchmark substitutions. Measure codec logical stored bytes including 24 scales and any per-tensor metadata; report scratch allocation separately, and never call logical bytes a measured physical peak.
- Ten alternating AB/BA **paired timing repetitions** for each of the three lengths. Time entire deep-copy allocation and entire codec encode, compressed representation materialization, decode and fresh float32 restoration, including Python dispatch. Five untimed warmups per arm per shape; every timed trial uses identical frozen arrays, no operations outside timer besides standard loop entry. Readonly alias control with no payload mutation. Preserve raw times and original-hash parity of deepcopy. Record sampled process RSS **as sample only**, CPU process time, wall, physical core count/OMP budget and observed max pointwise absolute codec error; no true peak RSS or energy claim.
- Input positive and negative controls: verify deterministic equality of original input hashes across repeated reads; copy is **bit-identical** and not sharing storage, readonly is sharing storage, codec is actually smaller and not bit-exact for nontrivial inputs; zero tensor goes through scale 1 without division-by-zero; nonfinite or incompatible input MUST fail closed; codec roundtrip error bounded in original seeded samples and first-use negative tests. Never use compressed output to stand in for original logits, attention or verified tokens.
