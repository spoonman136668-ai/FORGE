# ACC-55 — original U20 minimum-description-length program search (preregistered)

**Immutable before any ACC-55 implementation or measurement.** Original one-based U20 is **minimum-description-length program search**, confirmed from the original 30-name register `research/ac07_sourcefree/ac08_portfolio.py` Git blob `5126c860771fb024ccfc14c3f7ee8925edf29787`. Original ACC34 stage-2 research base `45b5d8173538a566bf0f63a8e2ade2dedb6e6166`.

**Question:** Does ordering an explicitly finite, interpretable native-program search space by *minimum description length* improve discovery accuracy, held-out generalization, complete-worker CPU, and peak physical RSS compared with conventional bounded enumerative and simple fit-first baselines? Do not mislabel fixed handcrafted finite grammars as general program synthesis or native cognition.

Program grammar: integer expressions of one variable `x` using modulo-2^64 semantics: `x`, constants from {-3,-2,-1,0,1,2,3}, `x + c`, `x * c`, `(x+c1)*c2`, `(x*c1)+c2`, `(x+c1)*(x+c2)`, with deterministic canonical string encodings, no oracle or task-specific shortcuts, and explicit candidate description cost (byte count of canonical text). Create the **same finite candidate set** once per worker, and preserve predeclared distinct orderings, exact source generator, complexity accounting and candidate evaluation limits.

Workload families: AFFINE, QUADRATIC, CONSTANT and NOISY. Five public paired seeds 105101,105103,105107,105109,105111. Each cold worker solves 64 independent synthesis tasks per family, each with 12 training observations and **32 unseen held-out** `x` values drawn from a disjoint deterministic domain. Generate target truth independently via fixed target evaluator and independently evaluate held-out predictions. In NOISY introduce deterministic 1/8 corrupted training labels but keep held-out clean. No truth labels from test observations are available to the search procedure. Withheld tasks and exact task seeds are paired across all arms, and full target, training, test hashes stored.

Four independent algorithms on identical candidate universe and task budgets: ENUM lexical candidate enumeration with first exact-fit (or least training-error on noisy); COMPLEXITY fixed operation-count + canonical lexical ordering; FIT_FIRST training-error sorting followed by canonical lexical tie break, representing conventional loss-first selection; **MDL** minimization of code byte length plus 8× absolute clipped training misfit count (each incorrect observed label counts as one), using deterministic lexical tie break. Selection criteria may be frozen prior to held-out, and no algorithm may access held-out truth or use data-dependent additional candidate proposals. Every algorithm scores every candidate on training observations before selecting, so all consume matched training source and search budget, and reports actual candidates evaluated.

**Primary scientific endpoint:** exact held-out correctness fraction and training fit per task, per family and median over five seeds, and number of task families where MDL improves by >=5 percentage points over best conventional while sacrificing <=2 points in any family. A **general useful programming win** additionally requires MDL strict >=5 percentage point held-out improvement in >=2 of the 4 families on BOTH operating systems, no more than 2 percentage point regression in any remaining family, median full-child User+System CPU <=1.10× fastest conventional and peak physical OS RSS <=1.10× same control. Every task output, canonical selected program and source SHA must agree Windows/Linux; missing worker, zero CPU/RSS, wrong independent oracle, unequal candidate count, missing held-out separation or wrong source => `ACC55_U20_BLOCKED`. No trained model or Wingless/Yggdrasil generalization claim.
