## Claim and fixed workloads
Can a lossless 16-byte fixed-phrase grammar collapse repeated history into fewer persistent bytes with lower total Go CPU and real peak physical RSS than exact RAW, standard zlib, and a conventional fixed-phrase dictionary control? **Three source cohorts**, all immutable: `REPEATED` (256 KB source assembled from 16 distinct, deterministic 16-byte phrases with a biased recurrent cycle); `BURST` (256 KB source assembled from 16-byte phrases with rare deterministic transitions and new phrases); `ENTROPIC` (256 KB independent pseudorandom bytes). Five frozen paired seeds **98101,98103,98107,98109,98111**; each independent cold worker performs **32 complete reset histories** with a separate mixed seed per reset. Every arm receives exactly the same public byte history. No secret history-label oracle or pretrained dictionary.
 
## Four original/data-matched arms
- RAW: copy and persist entire original history; retrieve original exact bytes.
- ZLIB: Go compress/zlib BestSpeed on the exact source, then **decompress and validate every original byte**; require no missing history.
- FIXED: conventional fixed 16-byte block dictionary built from public history in first-occurrence order, store exact 16-byte literals + uint16 indices, including uncompressed escape blocks as needed; full decode with strict bounds.
- GRAMMAR: construct **online byte-phrase grammar rules** from the public first-seen 16-byte phrases; tokens reference prior rules in an in-memory learned grammar; all literals, references, rule construction, serialization and strict decoding charged. Encode repeated 16-byte phrases as a 1-byte grammar symbol if rule count <256; escape as literal otherwise. Grammar tokens and rules must be serialized and decoded in independent buffers; candidate may not retain raw source as compressed persistent state. The conventional FIXED baseline also uses original first-seen dictionary, but fixed uint16 indices. Important: GRAMMAR is a restricted fixed-phrase grammar, **not** a complete general grammar induction or a full hierarchical Sequitur/RE-PAIR algorithm.
