## Source, arms and scientific boundary
Use a deterministic state transition with 64-bit public state and 32-bit public stimulus, initialized by paired 5 fixed seeds 99101,99103,99107,99109,99111, independently reset across 32 sessions, 8192 steps/session. A fixed pure transition `F(state,input)` performs 64 rounds of integer mixing. Every method must produce exactly the same outputs and final state as the independent direct evaluation. Three cohorts: REPEATED_INPUT (reuse one of 16 public stimulus values), RECURRENT_STATE (state resets to prior checkpoints every 64 steps, same state-input pairs repeat), and NOVEL (independent public state-input pairs). Source generator is independent of each candidate and fixed before outcome inspection. No hidden labels, future target values, prefilled caches or synthesis of expected outputs.

Four arms: DIRECT recomputes exact `F` every request; LRU64 exact lookup cache capacity 64 keys; LRU1024 exact lookup cache capacity 1024 keys; **U05_LOOKUP** exact open-addressed bounded 256-entry state/input-to-output cache with deterministic replacement. All caches charge lookup, insertion, reset, byte occupancy, source generation and independent reference verification; no approximation. Guard against apparent gains from simply repeating input when state differs: cache keys include **both state and input**.

Five paired seeds ×3 cohorts ×4 arms = **60 cold native Go workers/OS**, each processing 32 resets ×8192 queries, with genuine whole-child process CPU, OS peak physical RSS, exact prediction/source SHA256, actual cache hits/misses, and persistent cache bytes. Source and output SHA parity mandatory across Windows/Linux.
