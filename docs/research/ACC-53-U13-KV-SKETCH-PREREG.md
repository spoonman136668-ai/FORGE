The bounded key-value memory evaluation below is a synthetic Go microbenchmark; not neural KV attention or native Wingless/Yggdrasil performance.

Public keys are uint64 with exact public uint64 values calculated from `mix(key XOR seed)`, sampled independently per seed and workload. There are 5 fixed seeds [103101,103103,103107,103109,103111], 4 workloads, 4 arms and 32 independent session resets per fresh native worker. Each session inserts 8192 public key/value pairs then evaluates 8192 public queries. Workload types: REPEAT (queries 512 repeated inserted keys); UNIFORM (uniform queries across all inserted keys); SHIFT (first half queries inserted keys, second half new unseen keys); COLLISION (inserted keys with deliberately shared low hash bits, queries same inserted keys). All source/query sequences generated independently of arms and paired by hashes. Values must never be fabricated for absent keys.

Methods: EXACT full 8192-entry map; LRU512 bounded exact entries; HASH512 bounded open-addressing cache with deterministic replacement; **SKETCH512** deterministic 512-bucket count-min-style associative KV sketch with one signature and stored value per bucket, storing signatures to reject collisions, deterministic replacement on insertion. The U13 candidate is an **approximate/partial associative sketch**, not exact full-history storage. Every child computes input, expected truth and output SHA256; output SHA will **not necessarily equal** truth for partial caches.
