## Concrete question and frozen tasks
Can a native Go **12-dimensional fixed random recurrent reservoir**, with a trained 13-dimensional linear readout, provide exact-accounted CPU/memory acceleration **at comparable test accuracy** over realistic strong equally informed models on short temporal dependencies? It cannot claim to prove native Wingless/Yggdrasil intelligence, neural LLM runtime acceleration, language generation, GPU training, general transfer or scientific first-use.

- Deterministic binary public observation stream, independent training/held-out streams, seeds **73101, 73103, 73107, 73109, 73111** with a disjoint generator key for training versus evaluation, no query of held-out data during fitting. Each child reads 4096 training bits, independently generated 4096 eval bits; no oracle input at prediction time. All paths see the same input bits, time order, labels and available history. Include source hashes for both streams, prediction trace SHA256, squared-error sum, full process CPU and OS peak RSS.
- Frozen scenarios: **PREVIOUS_BIT** predicts x(t-1); **DELAY_3** predicts x(t-3); **XOR_1_3** predicts x(t-1) XOR x(t-3). Target is constructed only from preceding public bits; the first 12 positions are excluded identically from scored training and held-out evaluation, not supplied as fitted future labels. Held-out generator is independent, not a shuffled subset of training. On each split start with a zero state; no carryover training state into holdout.
- Four arms: **BIAS** (train-set fitted constant baseline); **LAG12** (strong exact 12-step observed-history register, fitted readout by 13-dimensional ridge regression or SGD; fixed explicit target selection is prohibited—can only learn weights from training examples); **LINEAR12** (fixed 12-unit stable linear recurrent state with trained readout; matched state/readout size); **RESERVOIR12** (fixed 12-unit tanh recurrent state, 13-term learned linear readout). All arms must train the same prescribed number of epochs and examples, except BIAS whose trivial mean fit is fully charged; do not hide reservoir fitting or use information from future bits.
- **EXACT_LAG diagnostic** retains the public task-specific lag selection and, for XOR, the correct Boolean combination; it is an impossible-information/oracle-assisted lower error bound, not counted as a learned competitor or acceleration winner. If implemented, never use it to select a model. A fully trained fitted LAG12 is the primary strong baseline.
- Freeze 12 state units, input/recurrent weights drawn once per seed from independent deterministic pseudorandom key stream in [-0.4,0.4] with fixed spectral damping 0.25 for per-unit recurrence and 0.20 neighbor mixing. 13 learned readout coefficients, including bias; same learning rate 0.02, 25 SGD epochs, fixed order, no held-out tuning. Preserve exact provenance of parameter initialization. A BIAS mode uses the same training labels. No extra hidden parameter search, variable capacity, model architecture switch, posthoc hyperparameter sweep or explicit previous-bit oracle in RESERVOIR12.
- Historical/architectural distinction: a fixed reservoir with only trained readout is not an independent non-transformer Wingless/Yggdrasil integration. Native Go **engineering** benchmark only.
