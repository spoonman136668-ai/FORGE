# ACC G61 — frozen preexecution larger causal-LM GPU attention-kernel study

**PREEXEC FIRST: committed before any G61 benchmark source or execution.** Read-only isolated FORGE-CODEX-REMOTE Windows runner with verified NVIDIA RTX 5070 Ti Laptop 12 GB, CUDA 12.8. Original G60 authentic RTX baseline source: draft PR #1260 (do not merge). This experiment is **not** a new acceleration method. It measures PyTorch's established optimized SDPA attention kernel against conventional eager attention on a realistic 1.1B pretrained causal model, as a prerequisite to future *novel* candidates tested against SDPA (not against eager).

## Frozen cases and metrics
- Prompt lengths `(128,512,1536)` tokens; generation `32` tokens, batch 1; context+generation must remain <=2048. Use identical independent public authored prompt and all tokens for both arms. Both use `past_key_values` incremental decode, NOT full-sequence recompute. Sample no hidden data.
- GPU sync before/after prefill and after decode. Two warmups per arm/case; **five paired repetitions**, alternating AB/BA order per rep to control ramp/thermal drift. Store individual prefill, 32-token decode and total inference seconds; store exact generated-token token IDs (or hash) and verify **every eager/SDPA generation pair matches bitwise**, initial logits maximum absolute error, actual VRAM max allocated/reserved, GPU identity and pinned Python/CUDA versions.
- Compare eager vs optimized SDPA in ratios (eager median / SDPA median) separately for prefill, decode and combined. **No novel-acceleration success claim** even if ratio exceeds 1.15. CUDA execution engineering admission PASS only if original checkpoint hashes and model architecture match, genuine CUDA backend + 2 attention classes confirmed, all 3 contexts ×2 arms ×5 paired measurements complete with strictly positive timings and exact generated-output parity.
