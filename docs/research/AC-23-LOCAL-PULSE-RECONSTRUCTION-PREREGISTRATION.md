## Frozen causal-mechanism hypothesis
Under the AC-21 external fixed-tag eight-cell transport, gate logits learned through terminal reward error rise too little to retain public history strongly. Test one alternative **genuinely locally updated** gate objective that has no terminal reward, model prediction error, future observation or distant information in the *gate update*. Each of the two source cells self-reconstructs its previously public binary pulse `p` from its own gated trace `p sigmoid(theta)`. The local reconstruction loss is `0.5[p - p sigmoid(theta)]^2`. Its own gradient update is:
`theta <- clip(theta + 0.20 * p^2 * sigmoid(theta) * [1-sigmoid(theta)]^2, -5, +5)`.
Only cells 3 and 4 update, from their own initial public observation `s1` and actual public action `x1`. Fixed gate-init logits = `[0,0]`. Learning rate **0.20** chosen and frozen before implementation and any new scores. This is *unsupervised* gate reconstruction, not the original AC-21 reward-modulated retention-gradient rule; it does not guarantee more effective future predictions.

The terminal reward prediction remains the unchanged AC-21 eight-weight sigmoid head at cell 5, initialized to original `W0`, trained by `ETA=0.06` on genuine FIT terminal rewards only. Input stage0 `(s1,x1)` and stage1 `(s2,x2)` are sequenced via `LocalPublicEpisode`; signal tags and exactly **two** neighbor-only packet rounds remain fixed handcrafted scaffolding. The terminal predictor must not read all four public bits directly; no source-private `u`, hidden `info`, raw environment object, oracle or counterfactual label is admitted. The two local gate updates must be **identical whether the terminal reward is 0 or 1**, given the same gate state and public stage0 pulses. No architecture/current Ygg or Wingless source changes.
