## Mechanism under test

A bounded eight-site per-episode binary latch first receives actual public s1 and observed scripted x1 **only** at original ring sites 3/4. After the following public s2 and observed scripted x2 arrive, sites 5/6 are set, preserving earlier sites. No initial-stage oracle about second-stage observation/action is allowed. The latch is fixed and is not a learned recurrent memory. Only the unchanged original historical LocalTaskRuntime is reward-trained on FIT: one terminal reward target is routed to readout sites 4/5 per episode. Original local per-cell feature neighborhoods are site4 (3,4,5) and site5 (4,5,6); the original learner has shared genome and cell-local role weights.

For assessment an **external, fixed two-cell probability average** combines the reward outputs, rather than a learned local consensus. Consequently a successful AC-21 would establish only that the original native learner can fit on temporally assembled public site information, **not** that native learned retention, distributed local-to-local readout, autonomous causal discovery, or memory/generalization has been proven.
