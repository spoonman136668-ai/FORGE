## Directly tested claims and exact scope
- **U07** hyperdimensional bipolar vector binding and **U18** vector-symbolic superposition memory. This is a restricted, real compiled Go retrieval experiment, **not** an LLM inference speedup, a production Wingless/Yggdrasil learned memory or a full holographic associative memory (U10 stays untested beyond AC-06 toy screening).
- Learned inputs: 16 discrete public labels and previously unseen numeric public key IDs; keys and label streams generated deterministically only from fixed seeds, never answered via external oracle. Candidate builds one **512-dimensional signed-integer bundled memory vector** using ±1 key × ±1 label elementwise binding; decode each query by 16-way dot-product unbinding. No exact per-key labels may be retained in the pure superposition variant.
- Baselines: (A) **DICT** exact fitted key→label public memory (cold checkpoint); (B) **BUNDLE** single-vector candidate with no key membership and no abstention (must show unknown-query false positives); (C) **BUNDLE+MEMBERSHIP** candidate storing only exact known keys to abstain on unseen keys, not labels (still potentially wrong when binding collisions); (D) **SHUFFLED** negative control: same vector memory, deliberately permuted labels on FIT and exact original labels at evaluation; cannot be counted as candidate success.
- Workloads fixed **16, 64, 256, 512** source-free keys, **seeds 11,29,47**, 16 labels, 512 vector dimensions, 256 fixed equally selected known-key queries per cohort and 64 genuinely absent-key queries per cohort. Source label rule deterministic but nontrivial, chosen before code; the query scorer uses only actual FIT stored key/value bindings and never derives truth from key ID formula. Every negative/unknown answer in exact DICT is abstention, BUNDLE's unconditioned guess is a false positive, and BUNDLE+MEMBERSHIP must abstain. At least 5 independent whole-worker repetitions per arm × seed × size per OS; one cold training, initial checkpoint serialization, independent cold restore, and original selected queries per process. Child OS process CPU charged using Go `os.ProcessState.UserTime()+SystemTime()`; parent wall tracked separately. Actual bytes of cold serialized checkpoints and Go runtime `MemStats.Sys` / `TotalAlloc` included; no fake OS peak RSS/energy/VRAM claims.
- **Zero information leakage:** exact answer-to-evaluation dictionary may be held by evaluator only, never passed to BUNDLE or SHUFFLED retrieval. Generate 256 known/64 unknown query IDs before each test; source training uses only per-key inputs and labels. Exact candidate correctness measured against DICT independently. No privileged learned-memory oracle, hidden source metadata, future outcomes or programmatic known-label fallback.
- **Development-engineering positive** only if for **every seed and every key count**, BUNDLE+MEMBERSHIP is exactly correct on ALL 256 known and 64 unknown queries (same full utility as DICT), and on each OS each count its 5-trial median whole-worker CPU ≤0.90× DICT, checkpoint bytes ≤0.90× DICT, and Go runtime Sys ≤1.10× DICT. Otherwise **negative** with exact false positives/known-errors by cohort. BUNDLE unsafe speed/storage cannot count. SHUFFLED must show a mismatch (not forced constant).
- Output per original U07/U18 candidate: observed correct/incorrect counts, absence-of-key false positive counts, exact bytes of checkpoint and 5 whole-worker CPU runs each size/seed/arm, cold-restore bit-exact output and query digests, change-free source birth and code SHA. Six focused source-only Go tests and five portfolio 36-ID audit checks, Windows/Linux Go test, vet, build, workflow frozen executable source before trial. **No first-use original environments, protected main, original native models, FORGE F139 controller/autonomy/queue, new scheduler, paid APIs, G29/Atlas waiver or research science admission**. Draft/unmerged. U10 holographic methods, U08 reservoir, U22 low-rank and U24 cellular automata remain explicitly registered for separate native experiments; a negative in this limited U07/U18 analogue is **not** a blanket rejection.
