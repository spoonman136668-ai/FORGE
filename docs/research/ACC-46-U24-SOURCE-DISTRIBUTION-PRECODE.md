# ACC-46 source-family completion — frozen prior to executable

**Append-only PRE-EXECUTION source specification; does not replace the ACC-46 first preregistration.** This addendum is committed **before Go implementation** to make the protocol's unspecified FIT/heldout binary-state distribution reproducible and to make unseen-pattern evidence nonvacuous. Frozen arm algorithms, 5 seeds, 256×(256 FIT+256 heldout) sessions, three regimes, numeric thresholds and research-only scope are unchanged.

## Independent state distributions and source custody

For each original prereg seed/episode, derive public episode base from SplitMix64 at `seed XOR episode*0x9e3779b97f4a7c15 XOR 0x1dc6e99a83b2f041`; derive FIT state index with `Mix(base XOR 0x66bfa97102c3d58e XOR step*0xa0761d6478bd642f) mod 64`. **Every FIT binary state consists of exactly two adjacent one-bits on the 64-cell ring** at that selected index and successor (all other cells zero). This purposely leaves heldout neighborhoods unobserved in each cell's local FIT stream. All arms see the identical constrained FIT states and the same 64 action consequences, and cannot read secret rule bits.

Heldout state = `Mix(base XOR 0x90a3cef1b624d578 XOR step*0xe7037ed1a0b428db)`, an independently keyed, unrestricted 64-bit configuration. All arms see identical heldout states, with predictions scored before truth reveal. Do not mutate learner counts on heldout steps.

Original fixed group rules: per seed/session generate four secret 8-bit neighborhood truth tables by `Mix(base XOR 0x8bde31f247a96055 XOR group*0xbf58476d1ce4e5b9)`, and for RULE_SHIFT independently generate four new tables using `Mix(base XOR 0x47e526b3f19a68cd XOR group*0x94d049bb133111eb)`. UNIFORM uses only first rule; FOUR_REGIONS uses four original rules; RULE_SHIFT uses original four for FIT 0..127, new four for FIT 128..255 and heldout. The rule is never passed to the candidate. For all regimes four groups of sixteen contiguous cell positions are public.

Source and truth hashes use fixed little-endian integer bytes, not Go map iteration or platform floating arithmetic. Source hash includes rule identities, each FIT and heldout input and consequence; report a separate FIT-only and heldout truth SHA and a prediction SHA. Define unseen as a heldout `(cell index, neighborhood 0..7)` pair **not observed for that cell at any of its 256 FIT steps**, report number of unseen heldout cell samples and exact correct count. If unseen count is zero, block scientific/engineering positive rather than inventing a zero error; expected source design ensures unseen samples.

Counter types **uint16**, saturated at max, with three independent allocations: GLOBAL 8×2×2 bytes = 32, REGION 4×8×2×2 = 128, CELL/LOCAL 64×8×2×2 = 2048. Candidate LOCAL score 4×own outcome-count + left + right, periodic boundary; update just its own count. Candidate cannot consult conventional control counts, per-class labels after evaluation or any oracle. No window-size/hyperparameter search or change after observing results.

This is a deliberately difficult **heldout distribution shift** protocol (two adjacent active training cells versus unrestricted test states). A failure is evidence for this exact source family, not proof local learning cannot improve other cellular worlds. Do not optimize sources or retune thresholds after measurement. Commit original-name and source-first Go hash assertions, run 60 actual cold workers/host and independent cross-platform source/FIT/heldout/prediction parity. Stage remains draft and unmerged, with no native Wingless/Yggdrasil model integration or controller changes.
