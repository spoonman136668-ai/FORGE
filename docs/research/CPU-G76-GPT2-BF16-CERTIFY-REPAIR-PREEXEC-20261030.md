## Candidate and conservative score-certification protocol
- Precompute once from the *same original* FP32 `W` of shape `(50257,768)`: `W_b = W.to(torch.bfloat16)`, per-token `||W||_2`, `||W - float32(W_b)||_2`, and `||W_b||_2`; precomputation time, temporary and retained logical bytes recorded. At each authentic original hidden `h`, compute `h_b=h.to(bfloat16)`, `s_b=float32(F.linear(h_b,W_b))`, 50,257 approximate logits, determine smallest-index winner on BF16 ties. Compute **one candidate's true FP32 dot** `torch.dot(h,W[winner])`; NEVER use original full-head token inside method.
- Bound errors conservatively for each token using Cauchy Schwarz: `||h-h_b||*||Wrow|| + ||h_b||*||Wrow-Wbrow|| + gamma768_fp32*||h_b||*||Wbrow||`, gamma `768*2^-24/(1-768*2^-24)`, and conservative BF16 output-rounding margin **0.01*(abs(s_b)+bound+abs(exact_candidate_score)+1)**. Call this `E_i`. Only certify when every nonwinner's approximate score **plus E_i is strictly smaller than the exact candidate FP32 score**, otherwise run full original `F.linear(h,W)` and argmax. Any nonfinite BF16, bounds, logits, candidate, uncertain index or numerical ambiguity -> fallback, not speculative acceptance. Index ties favor the smallest; exact candidate may have rounding discrepancy versus full torch reference, caught by independent parity check.
- The guard/bound is an *engineering conservative estimate, not a formal interval proof of every possible device's IEEE BF16/FP32 instruction behavior*. Engineering exactness is empirically enforced for every selected genuine sample and separate adversarial synthetic near ties, NaN/Inf, equal logits, and large perturbation fixtures; do not claim universal mathematical exactness from 480 checks.
- Each paired candidate call records certified flag, fallback flag, conservative gap, predicted token, original FP32 token (outside candidate), BF16 scoring time within candidate, total wall/process CPU, sampled process RSS and count of unresolved competitors. No mismatch allowed. Every full baseline uses the independent original FP32 head. Precomputing BF16 weights is charged in amortized total. Report standard PyTorch BF16 CPU runtime and model creation separately.
