## New falsifiable mechanism

A future selective neuron compute engine might omit the lower-contribution half of the GPT-2 original 3072-neuron MLP output projection. For each *original* NewGELU activation a_j and unchanged c_proj row vector W_j, define the (per-sample) contribution estimate `importance_j = abs(a_j) * ||W_j||_2`. Retain **exactly the 1536 largest** contributions, zero other 1536 values, compute original c_proj dense FP32 reference and masked dense FP32 projection using the same original pretrained weights and bias. Record L2 output error (relative to reference) and maximum absolute element error. **Importances depend on complete FFN activations and weight norms; that selection itself is expensive. This feasibility experiment DOES NOT claim end-to-end FFN acceleration, does NOT skip c_fc/GELU or reduce kernel FLOPs, and does NOT preserve exact logits/tokens of a masked model.** Any useful next-stage test needs a separately frozen predictor that avoids computing omitted units, a performant compact sparse-kernel implementation, full original-model token-quality validation and paired whole-token speed against strongest available dense engine. No accuracy/quality GO here.
