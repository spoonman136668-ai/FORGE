# ACC-47 implementation addendum: deterministic data and finite-state transition contract

This addendum is committed **before executable** and does not alter prior candidate identities, five seeds, 32 episodes, 1024 FIT + 1024 heldout rows, four cohorts, four arms, or acceptance criteria.

Public 16-bit feature vector = low 16 bits of SplitMix64(seed XOR episode*0x9e3779b97f4a7c15 XOR step*0xbf58476d1ce4e5b9 XOR namespace). FIT namespace 0x479c66e21e08a5f3 and heldout namespace 0x870d21fea9b3654c, with heldout steps starting at zero. Parity/OR/conjunction target labels are computed **only by the audit generator**, never queried by methods. All methods receive public FIT feature and consequence only; heldout predictions precede audit labels. With 1024 FIT examples, all 4-bit combinations are typically seen; don't invent a requirement of unseen combinations. Report coverage and error honestly.

FREQ16 is Bernoulli naive Bayes with public FIT counts and fixed integer approximate log-likelihood scoring using class-conditional frequencies; no future examples. PERCEPTRON uses 16 signed integer weights and one bias with one mistake-driven unit update per public FIT row. LUT4 fixes feature positions 0,1,3,4 before reading outcomes; each 4-bit bucket stores learned majority counts, tie=0. This is an explicit conventional low-dimensional lookup control, not selecting features using heldout labels.

TSETLIN16 uses 16 two-action automata represented by uint16 [0,65535] with the center at 32768 and 16 fixed positive/negative votes: included feature if state>=32768, excluded otherwise. On each FIT example, after computing its own prediction, if wrong, update each state by +1 for feature bit matching the true class and -1 otherwise; if correct, update only states corresponding to matching features +1. Clamp at endpoints. Predict one if number of included active features >=4; else zero. This is a deliberately restricted finite-state Tsetlin-family learner, **not** a full multiclause Tsetlin Machine. All learners reset between sessions. No secret rule bits, no stored FIT labels outside model state.

Source digests use fixed little-endian entries; output predictions are deterministic integer bits. All OS comparisons require identical source, FIT truth, heldout truth and predicted hashes. An accuracy negative on these worlds does not rule out multiclause Tsetlin Machines.
