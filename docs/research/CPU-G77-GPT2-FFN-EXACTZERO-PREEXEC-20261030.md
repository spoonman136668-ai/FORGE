## Falsifiable hypothesis and method

GPT-2's original 12-block MLP NewGELU activation might produce enough **exact float32 zeros** on actual unseen user text to make sparse omission of zero-valued FFN output-projection inputs theoretically worthwhile. This experiment records sparsity and a simple *upper bound* on eliminable multiply operands, **without implementing an unsafe sparse inference replacement**. Exact-zero positions are arithmetically safe to drop in real arithmetic, but changing FP32 reduction order can alter outputs. A later separately frozen original-model forward/greedy-token-parity and wall-time candidate is mandatory before ANY acceleration claims. **Near-zero activations do not count as exact zeros or safe skips.** This differs from G73 vocabulary bound pruning, G76 BF16 numerical certification, G75 lossy INT8 KV and prior G64/G65 serving pool experiments.
