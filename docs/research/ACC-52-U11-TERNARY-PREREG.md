# ACC-52 — original U11 ternary arithmetic kernels (prospective preregistration)

Frozen before executable. Original AC08 registry research/ac07_sourcefree/ac08_portfolio.py blob 5126c860771fb024ccfc14c3f7ee8925edf29787 identifies original one-based U11 as **ternary arithmetic kernels**. Research base 45b5d8173538a566bf0f63a8e2ade2dedb6e6166. Synthetic integer-kernel study only, not proof of actual LLM or native Wingless/Yggdrasil acceleration.

Test whether a native packed ternary dot-product kernel outperforms exact conventional scalar integer-8, bitset, and indexed-sparse controls at matched accuracy, full process CPU, and physical RSS. Input dimensions: 4096 public ternary values in {-1,0,+1} and 4096 public signed eight-bit weights, with integer dot product exact (int64). Regimes DENSE (roughly equal thirds), SPARSE (about 1/16 nonzero), POSITIVE (mostly +1), ALTERNATING (structured +/- alternating). Five paired source seeds 102101,102103,102107,102109,102111; 128 independent sessions/child, 256 dot products/session with reproducible public generation.

Four arms INT8 (scalar int8 dot baseline), BITSET (two bitsets for +1/-1 and conventional indexed weight reduction), SPARSE (indices of nonzero activations and signed weight lookup), TERNARY_PACKED (2-bit codes, packed four/cell byte with exact lookup table and sign accumulation). Each arm sees the same public source, constructs its own representation without an oracle, and computes exact dot products. Charge packing, decoding, source generation, reference and hashing in whole fresh Go worker CPU; maintain actual physical peak RSS (Linux VmHWM; Windows PeakWorkingSetSize), logical representation bytes, and per-source/output SHA. Never substitute wall time for unavailable CPU. All arms must match exact reference for each dot. Five seeds x4 source regimes x4 arms = **80 actual cold children per operating system**.

Win criteria **all four regimes on both Windows and Linux**: 80/80 independent exact output parity, TERNARY_PACKED median child CPU <=0.90x fastest INT8/BITSET/SPARSE conventional, peak RSS <=1.10x corresponding fastest-control RSS, logical packed representation <=0.50x INT8 source representation. Missing workers, zero CPU/RSS, mismatched output, source drift => ACC52_U11_BLOCKED. Fully qualified with failed performance threshold => U11_NO_GENERAL_VERIFIED_NATIVE_GO_RESOURCE_WIN. All gates pass => U11_RESTRICTED_GO_ENGINEERING_POSITIVE_ONLY. Do not claim full-model speedup.

Source-honest Go tests, vet, build, original 36 historical negative checks, source/blob custody, Windows/Linux independent reconciliation and raw receipts required. Draft/unmerged research only.
