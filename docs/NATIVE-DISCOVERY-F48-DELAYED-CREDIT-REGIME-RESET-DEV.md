## Research question and mechanism

Can a causal learner assign consequences to the **one-step-delayed prior command**, retain a stable belief about the original causal regime, and selectively **reset only its working belief** on surprising observations, thereby outperforming fully trained ordinary Bayesian fixed-hazard, generic switching-Markov and recent-window filters with same training and action information? F47's "no-feedback" negative outperformed the F47 candidate; F48 is a *new explicit state/credit mechanism*, **not** tuning F47's probing coefficient or the F47 consumed scores.

**Synthetic world disclaimer:** 3-bit public state `s=0..7`, public goal `g!=s`, commands 0/1/2. Six public *possible effect families*: `EFFECTS=((1,2),(1,4),(2,4),(2,1),(4,2),(4,1))`, command 2 has no physical state effect, but yields noisy binary witness indicating whether actual current hidden mode is in {3,4,5}. **Actual mode is held evaluator-private**. Physical step applies **previously queued** action's XOR effect, then stores current requested action as next pending. At first step pending=2. Independent source-generated exogenous noise changes public state by XOR zero at probability .8, otherwise one-bit XOR (1,2,4) with .2/3 each. A queued sensor (2) gives independently 80%-accurate binary witness; else witness -1. Public environment `step(requested)` yields next public state, witness, reward, done; **all actual actions count**. Training tasks have a fixed mode; unfamiliar transfer tasks secretly shift from mode `m` to `(m+3)%6` during real physical steps **3,4,5**, returning at 6 and 7. Policies never see the switch time, truth, evaluator seed, future noise, source internals or free counterfactual real-world steps. Public time index and pending requested action are available.

**Action/goal budget:** 8 physical actions per episode, no early termination. Each step reward -1; final t=7 reward adds +10 if state=goal, otherwise subtracts 2 × final Hamming distance. An evaluator-private fixed unsigned 32-bit LCG indexed solely by source seed, task episode and step makes the exogenous noise identical across arms on corresponding worlds; different policies produce legitimately different state paths. This is **NOT original Gymnasium or independently protected first-use**, and no positive result establishes scientific transfer, general intelligence, RSI or production readiness.

## Explicit prospective policy mathematics

Given previously queued public command `pending` and actual public observation `old, next, witness`, define for hypothesis mode `m` observed likelihood `L_m = P(observed_effect=old XOR next | EFFECTS[m][pending], noise=.2) * P(witness|m)` when pending=2 (otherwise witness must -1). No zero-probability invented observation; if no model supports an observation, fail closed in genuine arms and record abstention only in mechanistic wrong-credit control.

All hypothesis-aware arms use same **goal-conditioned two-step expected physical consequence planner**, evaluating action a∈{0,1,2} by `sum_m p_m [2*I((s XOR effect(m,pending) XOR effect(m,a))==g) - Hamming(...,g)]`, deterministic lower-action ties. This uses the known six-hypothesis source grammar, not an external physics call. All have no forced sensor probing bonuses. Observation is attributed to the **pending prior command**, not the newly issued command (except the explicitly wrong-credit negative).

- **candidate stable-working-reset:** initial stable=working=shared FIT prior. Before each observation update, compute predictive probability under working `q=sum_m working_m*L_m`. **Freeze surprise cutoff `q<0.12`**; if triggered *and pending != 2* reset only working to `0.5*stable + 0.5*FIT_prior`, otherwise keep working. Then apply exact Bayesian likelihood to working with mixed prior `0.98*working+0.02*FIT_prior`. Stable is updated only after **two consecutive informative non-surprising non-sensor observations** by `stable=0.90*stable + 0.10*working`, normalized. All state is public-observation-derived and episode-local. Count resets and stable updates.
- **fixed-hazard-bayes (strong conventional):** update posterior by `(0.92*posterior + 0.08*FIT_prior)*L`, normalized; same two-step planner.
- **markov-switch-bayes (strong conventional):** predict `0.88*p_m+0.12*(1-p_m)/5` for each mode before applying likelihood, a genuine 6-state switching-filter alternative. No true switch schedule supplied.
- **recent3-bayes (strong conventional):** after each observation, keep last three *actual* public tuples (pending, effect,witness), reconstruct from FIT prior with product of their likelihoods to form posterior; no hidden mode labels.
- **no-feedback (strong conventional):** retain prior every action, same trained two-step planner.
- **trained-empirical (conventional):** same FIT per-command empirical effect table, greedy two-step state-goal planning; no privileged information.
- **candidate-wrong-credit negative:** identical stable-working-reset logic but calculate likelihood for newly requested action rather than actual pending prior action; no physical actuation changed. At each step observe receives both prior pending and just requested, this sole negative uses the latter.
- **candidate-no-stable negative:** same cutoff/resets but resets working only to FIT prior, no stable memory update.
- **candidate-no-reset negative:** same stable updates/working memory, but disables surprising-event resets.

All arms have identical eight real actions, source fit, goal, observation and allowed hypothesis grammar; online data differ only legitimately by their actual action choices. No agent receives evaluator-private current mode, switch/noise schedule or outcome oracle. Candidate never gets free probes. Record actual action/observation/reward hashes, resets, memory updates, goal rewards and compute. **Equal action count is not matched whole-process compute**; measure total training+evaluation wall-clock and per-decision nanoseconds, and fail positive diagnostic if candidate decision_ns/action >2× strongest conventional.
