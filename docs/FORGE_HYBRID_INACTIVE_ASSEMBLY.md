one existing FORGE draft PR (#1567), without enabling any third lane or worker.

## What the combined offline check now proves

1. Bounded, source-specific workflow metadata for Wingless, Yggdrasil, and
   TTT-Hybrid-Lab is actually parsed by the read-only research observer.
2. A versioned Hybrid candidate is matched to the exact PR, source SHA and
   frozen protocol SHA-256 of a detached **engineering** attestation.
3. That engineering attestation is signature-verified using an independently
   **supplied** Ed25519 public key, with exact protocol and artifact bytes.
4. The Hybrid workflow run ID, attempt, source SHA and *engineering CI success*
   match the observed GitHub metadata (caller-supplied workflow snapshots).
5. The prospective Hybrid shadow lifecycle is anchored to the complete,
   unchanged verified two-lane Wingless/Yggdrasil scientific journal, and
   reaches only a non-executing protocol or engineering phase.
6. The existing disabled resource/no-replay reviewer runs against a bounded
   Hybrid runner request. Other research's resource reserve is retained.
7. A SHA-256-linked **disabled** handoff is produced with an untrusted claimed
   Hybrid first-use ledger head, evidence digest references, and an explicit
   requirement for independent native custody verification.

All steps are pure in-memory functions using supplied inputs. No live
repository access, network, signer/secret provisioning, runner dispatch, queue,
GPU reservation, scheduled automation, first-use action, model training, or
scientific promotion is included.

## Critical limitation

**This integration does NOT authenticate the GitHub source independently.**
Snapshot content is caller-provided. A valid detached signature does not
establish that the public key belongs to the authoritative Hybrid scientific
owner. The claimed Hybrid first-use ledger hash is not checked against a
durable, independently verified original. A favorable planning result is still
`REVIEW_ONLY`, never authorization.

Consequently, no scientific result, original-start evidence, autonomous
training cycle, recursive improvement, or deployment is proven. Separate
existing project-scoped source/first-use admission, resource arbitration,
and GPU worker qualification remain mandatory.
