## Novel falsifiable purpose

F46 did not discriminate information-seeking from a strong conventional Bayesian planner. F47 tests whether spending a **scarce real action on causal information**, with **delayed effects, noisy feedback, changed hidden rules and later return/interference**, helps a goal-conditioned policy reach end-of-episode goals more reliably than same-data Bayesian planning. This is a **locally authored synthetic source development simulator**, NOT independent scientific world data, not original Gymnasium, not learned general intelligence or RSI. All actions are physically executed on the synthetic step function and count against the six-action budget; no model may ask the real environment for hidden state, rules, noise, next observations or counterfactual actions.

**Hidden world:** public 3-bit state `s in 0..7`, public 3-bit goal `g != s`, available commands 0/1/2. There are exactly six known candidate causal rule families, UNKNOWN actual mode per episode, with action effects `EFFECTS=((1,2),(1,4),(2,4),(2,1),(4,2),(4,1))`. Commands 0/1 have the respective 3-bit XOR effect; 2 is a physical sensor command with no state effect. **One-step physical delay:** the effect of the *previous* command/pending action is applied on the next real `world.step(requested)`, never immediately on issuance. Agent is explicitly informed of its own pending command. At application, evaluator switches latent mode during steps t=3 and t=4 to `(initial_mode+3)%6`, then returns at t=5 to the initial hidden mode; policy is told only its public history and its previously requested command, not hidden initial or current mode, seed, disturbance or switch timing. Six real steps t=0..5, no further step; goal success/reward evaluated only at final step t=5, with base cost -1 per physical step, terminal +10 if public state==goal else -2 times public Hamming distance. No early termination. Modes 4/5 are entirely absent from FIT training.

**Exogenous deterministic physical noise:** on every actual state transition, an independent evaluator-only pseudo-random stream driven by (seed,episode,physical step) injects XOR one of bit masks {1,2,4} with total probability **0.20**, uniformly among masks; otherwise mask 0 at probability 0.80. When the previously queued action is 2 (sensor), the source emits public binary witness `int(actual_mode>=3)`, independently inverted with probability **0.20**. Otherwise the sensor public signal is -1. All agents know these six hypothesis-effect templates and these stationary noise laws, but not realized hidden mode/switch/noise. Noise is the **same exogenous stream for each policy on a given seed/episode/step**, and actual traces differ legitimately with action choices. No party can read the stream or true mapping in its decisions. Use unsigned 32-bit fixed LCG and canonical byte-stable JSON/SHA256.

Also fit an empirical per-command majority XOR effect from the identical FIT observations. Freeze FIT transcript count, all-action coverage, prior vector/model hash before any heldout transfer trial. FIT-only tests may validate mechanics and data without running scored DEV seeds.

All hypothesis-based candidate/controls share the **same fitted prior and six-mode hypothesis grammar**. On each actually observed next state/sensor, perform the exact noisy Bayesian likelihood update for the previously pending action; mix posterior with fitted training-only prior at fixed hazard `h=0.08` per physical step (including first step). Observation likelihood for public XOR effect =0.80 if equals the mode's predicted effect; +0.20/3 for any one-bit corruption of the predicted effect (otherwise zero). If pending action==2, additionally apply witness likelihood .80 if witness matches mode>=3 else .20. Normalize to one; raise if impossible. Wrong-credit negative uses `(observed_effect+1)%8` in Bayesian likelihood, preserving actual physical actions/observations; if all models assign zero, keep prior before observation rather than invent evidence, recording such abstentions. No mode IDs, source internal state or true noise leak.

**Shared two-step model-based action scoring:** for each requested action in {0,1,2}, enumerate the six hypothetical modes. From current public state, compute predicted state after applying the *known pending action* now and after applying the candidate requested action one step later. Use expected terminal-target score `2*I(predicted state==goal)-Hamming(predicted state,goal)` weighted by the current posterior, using **clean predicted effects**; this is model planning only, no real environment calls, and omits unknown future switch/noise in both arms. Tie-break lower action. This non-oracular planner is **not** globally optimal POMDP; avoid "optimal" claims.

**Frozen eight arms:**
1. `active-probe` candidate: two-step planner above plus `beta=0.8` times the **expected entropy reduction in the six-mode posterior from the future sensor witness** when candidate action is 2, only if physical t<=3. Entropy reduction uses binary witness accuracy .80/.20 and current posterior; 0 for commands 0/1 and after t>3. Action 2 is a real paid step, not a free test.
2. `bayes-two-step` same two-step planner, identical noisy posterior, bonus=0.
3. `bayes-one-step` strong independently coded conventional: score expected public Hamming/goal after applying only known pending action plus a 0.5 coefficient on current command's predicted next effect, same posterior; no information bonus.
4. `trained-empirical` conventional: choose command minimizing predicted public Hamming after known queued effect and a newly requested empirical-fit effect, no posterior update.
5. `seeded-random` conventional: fixed private random action stream from public episode index (not world seed), same 6-step budget.
6. `wrong-credit` candidate planner/bonus but Bayesian observed XOR effect rotated +1 modulo 8 before credit assignment.
7. `no-feedback` candidate planner/bonus but never updates posterior from executed observations.
8. `info-only` sensor-information bonus only, never goal-conditioned in action choice; same Bayesian update.
