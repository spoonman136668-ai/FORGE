Frozen five arms, equally sized 500-step physical episode budget:

2. `always-td` strong conventional: same base, same gradient with constant `alpha=0.18` each real step. It is allowed exactly the same real action observations as candidate.

4. `momentum-rule` independent conventional: `2 if ω2>=0 else 0` using only public obs, no hidden truth, no model/adaptation; behavior rule available to all.
5. `wrong-credit-td` negative: same candidate gating/gradient but update block `(action+1)%3` rather than actual physically executed action, unchanged real actions/receipts.
All policies use greedy action selection from frozen/online FQI with ties selecting the lowest-index action; no exploration during scoring.
