F105 adds the first *machine-computed, reproducible, advisory next-direction choice* based on the **actual current integrated run's** four complete source-bound evidence JSON files and their SHA-256 receipts.

1. Independently verify the frozen D0 contract and exact parent mechanism Git content-blobs.
2. Read the **current-run artifacts in runner.temp**, not fabricated summaries, hardcoded scores or remote historical sources.
3. Reject missing/tampered evidence, mismatched source SHA, replay, omissions/cherry-picking, wrong cohorts, compromised strong controls, reclassified old negative results, unsupported scientific authority flags and tampered screen claims.
4. Evaluate both candidates in each lane with the **same frozen policy**. A failed public screen prioritizes falsification/repair of the weakest failed mechanism. These rules were frozen before observing F105 outputs and produce **exactly one successor hypothesis per lane**.
5. Archive a complete model-evidence summary, two advisory next directions, source digests, policy digest and explicit zeros for all execution/acceptance authority, with an independent checksum.

## Fundamental limit

F105 chooses what **should be investigated next**. It does *not* invent a new trained architecture, execute a fresh experiment, show novel generalization, invoke GPT on a schedule, or learn/improve the decision policy across repeated new scientific experiments. Repeated workflow runs on identical frozen public cohorts should yield identical advice. Sustained autonomy requires new independently qualified evidence, authority-safe experiment admission, provenance custody and fresh-outcome feedback in later gates.
