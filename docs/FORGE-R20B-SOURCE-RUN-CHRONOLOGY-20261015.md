archive byte evidence; no original retry, source ref mutation, cloud write, new
controller, scheduler, queue, signer, key, or paid API.

The existing GitHub-hosted read-only workflow checks six real original
`run_id` records, workflow paths, exact HEADs, single-attempt successful
original run identities, original commit timestamp <= recorded Actions-run
creation timestamp, and the actual preregistration **Git blob** at the pinned
original source commit. Checks are performed separately for three Wingless
and three Yggdrasil records. The test path introduces adversarial fixture
drift for source, lane, run attempt, identity, chronology, blob, and fabricated
scientific-custody flags. The source is pinned to the GitHub-visible evidence
identity; GitHub chronology is *observational* and is not trusted publication
or scientific freeze chronology.

A successful run may assert:
- `github_prereg_blob_observations=6`;
- original Actions run / source commit / prereg Git blob metadata are consistent;
- two independent research lane namespaces remained separate.

It MUST continue to assert **false** for:
`independent_source_birth_verified`,
`complete_first_use_reconciled`,
`external_signer_custody_verified`,
`scientific_accepted`, and `optimizer_promotion_authorized`.
No GitHub success check, source blob, historical ZIP SHA, D1 seal or
self-declared receipt overrides these denials.
