# F121-O — frozen two-hop-trained role alignment transferred to three-hop unseen induced graph

**Pre-implementation original source and experiment frozen first.** Parent F120-O PR #429 engineering-qualified exact source `24da38905ca7a27cd3b67690f43b67db63a9ebc4`, run `39034954625` succeeded Ubuntu and Windows. F120 nonlinear message passing LOST to a same-training-partition F119 linear model (terminal balanced accuracy 0.867133 versus 0.916084). F121 does not tune that evaluated nonlinear model. Hypothesis: an inductive role-identity alignment term trained ONLY on 2-step source graphs may generalize better to a longer 3-step source graph family with disjoint nodes. A favorable result remains **graph-index-assisted relation matching**, NOT learned connectivity or independent new corpus science.

## Preselected alternative trainable role inductive bias and controls

- Two 18×3 signed-role embedding matrices Q,E plus common gate intercept b (109 params), **one additional trainable scalar `eta`** for exact signed-role identity alignment = **110 parameters**. Gate `g(q,r) = sigmoid(b + dot(Q[q],E[r]) + eta * 1[q==r])`. The `1[q==r]` input exposes exact signed-role equality **as an inductive prior**; it is NOT learned semantic relationship meaning and this limitation must be explicit. Initialize Q/E via SHA256 `F121O-v1|Q-or-E|index|coordinate` first uint16→[-0.05,+0.05]; intercept b=0, eta=0.0. Fixed **120 full-batch training epochs**, LR **0.35**, L2 penalty **0.005** on embeddings only; analytic gradients through g and per-source real joined 2-hop paths, average over exactly 64 TRAIN root tasks; no stochastic seeds, early stopping, DEV/TEST tuning or hyperparameter mutation. Contrastive loss `softplus(log1p(mass_negative)-log1p(mass_positive))`; full-batch gradients by derivative of gates (including indicator for eta), strict original source 2-step path counts. Require logloss strictly decrease, parameter movement>0 and SHA256 8-decimal parameter fingerprint. Repeatable on Ubuntu/Windows.
- At **3-hop DEV/TEST only**, score candidate mass as exact sum over source-connected 3-hop role hist `count * g(q1,r1)*g(q2,r2)*g(q3,r3)` and compare `log1p(mass)`; choose first if tie. This is **length extrapolation from 2-hop training**; no 3-hop DEV/TEST labels used for weight updates, calibrations, or selection.
- Frozen strong baselines, all evaluated on the same 16/32 three-hop tasks: (A) constant first candidate; (B) uniform untyped physical 3-hop path count, (C) same F121 identity-biased network at its **untrained initialization** (eta=0), (D) **F119 unchanged 109-parameter low-rank linear gate trained from scratch ONLY on the same frozen 64 TRAIN 2-hop tasks** (not the previously trained F119/F120 test outcome), extrapolated to 3-hop product of 3 gates, (E) **hard role-type equality product** `1[q1=r1]1[q2=r2]1[q3=r3]` = privileged symbolic exact graph path oracle, always 100% by construction. As a diagnostic, (F) fixed soft role-alignment gate `0.75 if equal else 0.25`, no trainable weights; this prevents mistaking hardcoded equality prior for a learned breakthrough. Report full raw accuracy and balanced accuracy, confusion counts on DEV and terminal TEST, both heldout classes required.
- Precommitted exploratory win iff heldout TEST balanced accuracy of F121 ≥ best of ALL non-oracle controls +0.05 **AND** heldout has both true candidate-order classes. An apparent improvement merely shows that adding a *provided signed-role identity feature* helped matching, NOT independent novel structural reasoning. Any failure, overfit, all-one-class cohort or underpopulation reported as NEGATIVE with no acceptance/promotion.
