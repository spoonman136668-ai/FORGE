## Frozen environment, splits, and hidden laws

Four-state persistent dynamics `s[t+1]=(s[t]+base[cue]+action*effect[cue]) mod 4`. Initial state and a single world-specific additive observation offset (mod 4) are computed by the simulator from a world seed; no learner sees either. Two imperfect four-state sensors each observe the resulting offset state: sensor0 correct 90%, +1 6%, -1 4%; sensor1 correct 80%, +1 10%, -1 10%. Sensor noise is deterministic using `f27Mix(seed ^ uint32(step+1)*0x9e3779b9 ^ uint32(sensor+1)*0x85ebca6b ^ 0x6a09e667)%100`. All policies get exactly the same public cue, prescribed action, two current observations, and two delayed-next observations; no clean scorer state, upcoming regime ID, or counterfactual observation.

Training worlds, **fully consumed before transfer**: seed 241, 64 transitions of law A with balanced cues; seed 243, 64 transitions of law B with skewed cues. Same 128 transitions for all policies (including ablations), no seed reuse as transfer. Training world labels A/B are allowed to every archiving conventional control; no transfer phase labels are given. Law A base=[1,0,3,2], effect=[2,1,2,3]; law B base=[2,3,1,0], effect=[1,2,3,1]. Novel C is cuewise *cross-component recombination*: base=[A0,B1,A2,B3] and effect=[B0,A1,B2,A3] (not A or B as complete cue/action mechanisms). Novel D uses opposite recombination: base=[B0,A1,B2,A3], effect=[A0,B1,A2,B3]. Scorer/simulator alone stores A/B/C/D values.

Four never-trained DEV transfer worlds: seed 251, balanced, phases A→B→A→C; 257, skewed, phases B→A→B→D; 263, balanced, phases A→B→A→D; 269, skewed, phases B→A→B→C. Each phase lasts exactly 12 consecutive real actions (48 per world). Phase is NOT supplied to models. Balanced cue `f27Mix(seed ^ uint32(t+1)*0x27d4eb2d)&3`; skewed `(t/5+seed%2)%2` except every fifth step `(t/5+seed%4)%4`. Action is `f27Mix(seed ^ uint32(t+1)*0x165667b1)&1`. Identical schedule for all models. No first-use 59/83 or protected historical evaluator seeds.

## Frozen model portfolio (trained, not dummy controls)

All predict the same 4-way clean next *observation-offset* state before next sensor feedback, using the same prescribed actions and sensor likelihoods. Scores use probability assigned to the true next value with floor 1e-9. All models cold-restore after training and start each transfer world from an independent clone; no historical replay.

1. **contradiction-archive** candidate: estimate each credited transition's 4-way delta from *two* sensor posterior distributions, maintaining two frozen trained [cue,action,delta] Dirichlet archives A/B (uniform prior 1) plus a separate online scratch table. At each cue/action, score the last **three** credited same-cell transitions under each archive using their delta posterior, choose the bank with higher sum log likelihood only if the evidence margin exceeds **0.30 nats**, else mix archives equally. If neither archive explains current recent evidence (both average likelihood <0.22 after at least 2 same-cell credits), select adaptive scratch posterior. No phase labels, no old-data replay and no hidden-law queries. The scratch table updates with each credited observed transition, regardless of bank choice; frozen A/B archives never overwrite.
2. **factorized-bayes**: same frozen A/B tables and scratch update, but conventional per-(cue,action) Bayesian mixture weights over A/B/scratch, initialized 1/3 each and updated by each credited posterior-delta likelihood, no threshold/hard switch. Same parameter storage as candidate.
3. **switch-bayes**: same archive+scratch capacity but one global Bayesian three-regime weight, updated from all credited transitions with fixed per-transition hazard 0.08 toward uniform. No cue-local splitting.
4. **stationary-delta**: F27's fully trained recurrent causal-delta Bayesian predictor (train all A+B, persist 128 training transitions, then adapt online).
5. **markov-bayes**: F27's fully trained 4-state Markov Bayesian transition predictor.
6. **online-softmax**: F27's trained 4-class multinomial next-observation model with four passes per observed transition; unchanged hyperparameters from F27.
7. **overwrite-memory ablation**: candidate mechanism but replaces archived A table with B after all training, then processes actual transfer as usual.
8. **wrong-action ablation**: candidate mechanism but all training/transfer table updates attribute each actual observed outcome to action `1-action` (actions and simulator remain real).

No baseline sees the correct regime/hidden law, future action or scorer target. The two Bayesian archive controls are intentionally strong; do not claim compute parity with F27 baselines because parameter counts and operation profiles differ. Measure wall time/operation count diagnostics without equating them to end-to-end efficiency.
