## Distinct hypothesis

Previous F20–F26 games predict independent or context-conditioned outcomes from isolated interventions. F27 instead measures **real action-induced changes in persistent state** and adaptation after a cold restart into **unfamiliar observation-shift worlds**. Hypothesis: an explicit state-belief plus causal transition-delta learner makes more correct next-state predictions than strong trained conventional online models using identical action/observation histories. The model never receives the hidden state or clean scorer target. Any improvement must hold on every transfer arm, beyond uncertainty and negative controls; a synthetic DEV signal is not SCIENTIFIC_PASS.

## Frozen environment and data split

State `s_t` is one of 0,1,2,3. Every real action changes persistent state by `s_{t+1}=(s_t+base[cue_t]+a_t*effect[cue_t]) mod 4`. The simulator/scorer-only hidden law is `base=[1,0,3,2]`, `effect=[2,1,2,3]`; learners do not see it. Each world's observation encoding is `clean_t=(s_t + offset_world) mod 4`, with constant but unknown offset determined by the seed; two independent noisy sensors observe that clean state. Sensor 1 returns `clean,+1,-1` with probabilities `90%,6%,4%`; sensor 2 `clean,+1,-1` with `80%,10%,10%`. The simulator generates samples deterministically from independent `f27Mix(seed,step,sensor)` integers. The same sensor and action traces are delivered to ALL policies.

Train each policy with **two complete 64-transition worlds**: seed 211/balanced and seed 223/skewed. Do not score them for admission. Retain learned parameters, but reset each world's latent-state belief. Cold serialize learned parameters after those 128 actual transitions and independently restore before transfer; no historical replay. Evaluate **four never-trained-world DEV arms** in fixed order: seed 227/balanced, seed 229/skewed, seed 233/balanced and seed 239/skewed, each 48 transitions, with an independent restored copy of the trained checkpoint per arm. These are *not* protected scientific first-use seeds 59/83, which remain inaccessible. Fixed action policy for all: `a_t=1` if `t%4==0 OR t%7==0`, otherwise 0; no policy chooses or revises actions. Balanced public cue `(3*t + seed%4)%4`; skewed cue `(t/5 + seed%2)%2` except `t%5==4` uses `(t/5+seed%4)%4`. Initial state and offset are seed-derived and never supplied to learners. The models see sensor readings at time t, public cue, prescribed action, and next noisy readings after the real action, but not the clean next-state scorer target. Same 128 training and 48 transfer steps, action schedule, observations, memory export and training budgets for every policy.

## Frozen model portfolio

All methods predict **the same target**: next clean observation state (four-way MAP) before receiving consequence sensors. All use the declared observation likelihoods and can retain learned parameters across worlds.

1. **recurrent-causal-delta (candidate):** maintain a four-way posterior over current clean state, and a shared per-cue/action four-way Dirichlet posterior over state increments. Before acting, convolve state belief and increment posterior. After observing next sensors, update the joint `P(old state, delta | next sensors)` and add the posterior increment responsibilities to counts; update state posterior to the corresponding next-state marginal. Reset only the state posterior at each new world, not counts. Prior increment counts=1.
2. **markov-bayes:** fully trained conventional 4-state first-order transition model, with separate Dirichlet counts for next state per `(old state,cue,action)` (128 parameters); same Bayesian filtering/emissions and soft responsibility updates, prior=1; carries counts across worlds.
3. **delta-count:** fully trained conventional Dirichlet delta-count transition model based on maximum-posterior sensor consensus, updated on each actual observed transition, prior=1; retains counts; no recurrent Bayesian filtering.
4. **online-softmax:** fully trained conventional multinomial logistic next-state predictor with 4 outputs; features comprise bias, two sensor-derived current-state one-hots, cue one-hots, action, and cue×action interactions (fixed 18 features); deterministic online SGD, learning rate 0.05, L2=0.0001, four passes per completed real transition. Retain weights; no hidden labels.
5. **action-blind ablation:** identical causal-delta filter but attributes all causal transitions to action0, including when a real action1 occurred; actual actions and observations unchanged.
6. **cold-zero ablation:** identical candidate, but discards all 128 training-transition count updates when entering each transfer world; never replays training. World initialization always resets latent belief.

No model has privileged action, hidden-law, future-cue, clean-state, or counterfactual access. Models are trained and evaluated in the same world order, with equal actual interactions, and only observed sensors for feedback; record approximate compute work. The underlying parameter counts and actual compute are not exactly matched; **never claim matched-compute scientific qualification** from this test.

## Frozen measurements, thresholds, negative custody

For every transfer arm, score all 48 action-conditional predictions against simulator-only clean `next_state+offset` *before* the next observations are shown. Secondary diagnostics: first 16 transfer predictions (early unfamiliar adaptation), next 16, final 16; count intervention/non-intervention performance, canonical action SHA256, prediction SHA256, model checkpoint SHA256, exact transfer terminal model digest, approximate work, unique observed cues, and number of real transitions. Check every model against uninterrupted warm simulation versus cold independently restored learned state at the training boundary; byte-identical forecast trace, scores, learned parameters and heldout result are required.

**F27_DEV_SIGNAL_UNVERIFIED** only if all four transfer arms show candidate **>= strongest of markov-bayes, delta-count, online-softmax by +3/48**, **>= action-blind and cold-zero by +5/48**, with at least 1/48 gain in the first16 against the strongest conventional arm, and fully passing deterministic, no-oracle, source/custody, negative-control and cold-restoration checks. Otherwise classify **F27_DEV_NO_GO**; tie, ceiling, missing qualification and incomplete harness also NO_GO. No post-score retune, seed selection, or threshold manipulation. Record compute work, memory and wall clock as diagnostics; no whole-process efficiency claim. The strongest control is a hindsight evaluation comparison of independently trained online models, never a policy the candidate can consult.
