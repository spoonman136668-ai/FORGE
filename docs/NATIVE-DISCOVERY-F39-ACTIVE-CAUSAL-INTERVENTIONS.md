## Mechanism and environment

New three-bit **persistent state** `s in [0,7]` with two independent physical interventions. At each step t the simulator discloses public cue `c in [0,3]`, independent public goal `g in [0,7]`, and two noisy measurements of the current state. Agent chooses one of four actions: 0=passive, 1=actuator A, 2=actuator B, 3=both simultaneously. True next state `s[t+1]=(s[t]+base[regime,c]+I(A)*effectA[regime,c]+I(B)*effectB[regime,c]) mod 8`. A/B source law base/effect arrays are fixed below; C/D held-out physical regimes recombine components cue-wise from A/B, without announcing switches.

Law A: base=[1,3,0,2], effectA=[2,1,3,2], effectB=[1,3,2,1].
Law B: base=[2,0,3,1], effectA=[1,3,2,1], effectB=[3,1,1,2].
Law C uses A base with B effects on even cues, B base with A effects on odd cues. Law D uses the opposite. This is a modest, source-only synthetic causal diagnostic, **not** a representative general-intelligence benchmark.

Two actual noisy sensors each report a value 0..7: sensor0 is correct with 90% probability, +1 with 6%, -1 with 4%; sensor1 correct 80%, +1 10%, -1 10%. Both channels, initial state and public cue/goals use deterministic bit-mixing `mix(x): x ^= x>>16; x*=0x7feb352d; x ^= x>>15; x*=0x846ca68b; x ^= x>>16` with uint32 wraparound. Hash salts are defined in source and frozen by this document; scorer-only clean state, actual phase, future observations, simulator law or full counterfactual outcomes NEVER reach any model.

## Independent fully observed source training and cold retention

Two real training worlds 491 (A) and 499 (B), **192 transitions each**. At each t, `cue=(t/3)%4`, action `t%3` (0 passive, 1 A-only, 2 B-only), which yields exactly **16 real exposures per cue per action** in each law and no double-actuator training. Every learner receives identical physical action/sensor history, 384 transitions total, and learns 2 source banks of 4 cue × 4 action × 8 transition-delta Dirichlet counts from the joint posterior of two noisy sensors before/after each observed transition. Both source banks remain frozen on transfer; online scratch counts may adapt. No clean latent state/transition target is given. Cold JSON checkpoint after training is restored independently before each new world, with no training replay.

Four new **held-out DEV**, not independent scientific first-use, worlds: 503 balanced (A→B→A→C), 509 skewed (B→A→B→D), 521 balanced (A→B→A→D), 523 skewed (B→A→B→C). Each lasts 96 transitions, four hidden 24-step physical regimes. Balanced public cue `(t/4+seed%4)%4`; skewed cue `(t/6+seed%2)%2`, except `t%6==5` use `(t/6+seed%4)%4`. Goal `mix(seed ^ uint32(t+1)*0x7f4a7c15 ^ 0x52dce729)&7`. Each model sees goal before action, scores a goal hit if the *actual next clean state* equals it, and must respect at most **48 nonzero interventions per world**. Model evaluation may read clean next state but never pass it into learning/planning. Nonzero actions incur fixed 0.04 penalty for secondary net reward.

## Frozen intervention policies and matched work

All six policies share exactly the same learned two-bank Dirichlet transition model and online scratch, the same sensor-posterior belief, Bayesian mixture of A/B/scratch predicted transitions, and per-cue source posterior weights with fixed hazard .03 to a uniform three-component prior. Every transition they update only from observed previous/next sensor evidence and the *actual* credited action. Every decision computes the same four action forecasts (same counted transition operations) and immediate goal probabilities; no model uses true law. A/B source banks are frozen in every policy. Equal training interactions, equal opportunities, action limits and counted forecast work **do not prove whole-process compute parity**; record diagnostic wall time, parameter counts and work, and be explicit that on-policy action histories differ.

1. **uncertainty-directed (candidate)** selects highest `P(next_clean=goal | observed sensors, cue, action) - 0.04*I(action!=0) + 0.08/sqrt(1+N[c,a])`, where N is credited source+online real action count. This is an action-count upper-confidence bonus, not a claim of exact information gain or optimal exploration. With ties choose smallest action.
2. **greedy-bayes (strong control)** identical policy with exploration bonus ignored (its bonus is still computed for equal instrumentation cost).
3. **epsilon-greedy (strong control)** with deterministic 10% intervention exploration when `mix(seed^uint32(t+1)*0x14c2d7b1)%10==0`, choosing `mix(seed^uint32(t+1)*0x35f078da)%4`; otherwise identical greedy. Keep action cap.
4. **posterior-sampling (strong control)** deterministic Thompson-like component sample from the model's current A/B/scratch mixture weights, then choose the action maximizing that component's predicted goal probability minus action cost. It does NOT sample hidden world law or clean state; compute forecast operations on all arms identically.
5. **wrong-action (causal attribution ablation)** identical uncertainty-directed policy except when recording an actual nonzero action1/2 outcome, credit the OTHER actuator in the scratch update and source-weight likelihood. Actual simulator action, sensors and reward unchanged.
6. **cold-zero (source-memory ablation)** identical uncertainty-directed policy with frozen A/B counts cleared after otherwise identical training; online scratch may learn.
