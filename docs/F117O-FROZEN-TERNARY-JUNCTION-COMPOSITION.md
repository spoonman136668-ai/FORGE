## Preselected trainable ternary latent-junction learner
One logistic ternary factor model: `z=bias+a[left]+mid[middle]+c[right]+sum_d(U[left,d]*M[middle,d] + M[middle,d]*V[right,d] + U[left,d]*M[middle,d]*V[right,d])`; prediction `sigmoid(z)`. Signed roles indexed in lexicographic `(source-role,F/R)` order. Each U,M,V is a **separate trainable 18×4** matrix (dimension 4) with **54** per-position role biases and one intercept, **271 parameters**. The middle embedding gates both adjacent sides and a three-way interaction; this is a *latent junction compatibility model*, **NOT actual entity-variable binding**.
- Frozen parameter init SHA256 of `F117O-v1|U/M/V|index|coordinate` first 16 bits mapped to [-0.05,+0.05]. All biases zero.
- Fixed **240 epochs** full-batch gradient logistic cross entropy, learning rate **0.20**, L2 **0.01** applied only to trainable embeddings and averaged gradients; deterministic example ordering by original type indices; fixed 0.5 cutoff; clamp logits [-40,40]. No random seeds, dynamic optimization, regularizer sweep, tuning, or dev/test feedback. Publish parameter drift norm and trained parameter SHA256; if no numerical learning or training logloss improvement, **mechanism engineering fails**.
- **Frozen controls**: (A) triple train-majority constant; (B) train-only Laplace-smoothed positional signed-role marginals `(P(y|left)+P(y|middle)+P(y|right))/3`, each with +1/+2 smoothing; (C) frozen F116 **pair-only** low-rank model trained only on its preregistered 2-step TRAIN hash split, predict 3-step via `min(pair_score(left,middle),pair_score(middle,right))` with zero train triple labels.
