# FORGE F2 prospective experimental preregistration

F2 is a *new* pair of tests, not a replay of the consumed F1 original. Freeze this file and its Git blob before implementation and before F2 heldout execution. The original F1 result is historical context only and does not authorize scientific acceptance, execution or promotional claims.

Wingless F2 tests **within-episode binding of shuffled symbolic roles** over a newly selected family of six affine transformations modulo 19. Six tokens are independently permuted across heldout cohorts. Each token has exactly four labelled in-context examples. The primary applies the learned role functions in query order; the two frozen controls use an unshuffled token mapping and reversed role order. Four independent heldout seeds each contribute exactly 192 episodes. Training rows and test inputs do not overlap. The frozen four clauses and no-retuning rule are in `frozen.json`.

Yggdrasil F2 tests **dormant-memory reactivation** after three changes of ten-key hot workload over 15 keys. Both mechanisms get exactly ten slots. The new arm has five protected acquisition slots and five recency slots; the control is ordinary ten-slot LRU. The hot splits are independently seeded after acquisition, and the evaluator measures cold and hot recall plus the retention trade-off. Eight independent heldout seeds, 15 eval cases per seed, five cycles per regime. Frozen capacities and all thresholds are in `frozen.json`. Neither arm can inspect the next regime before its allocation decisions.

The sandbox uses hosted Linux and Windows source qualification first and permits **one original** on the newly created branch only, after both independent source qualifications. A transient failure must not trigger a new first-use. The F2 outcome may be SUPPORTED, MIXED, NEGATIVE or INVALID. Full original raw JSON and start receipts are retained separately from the later classifier. No automatic F3 experiment, FSA admission, production cutover, accepted-ref mutation, cross-research runner lease, or access to private scientific records.
