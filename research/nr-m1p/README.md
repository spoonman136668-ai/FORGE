## Did stored goal effects support the existing MG28 guard?

An optimistic, chronology-correct scan computes MG28's exact integer same-context prior `(changed+1)/(count+2)` per action before incorporating the current selected source event. It examines all seven possible parent action proposals because these **older MG19 actors did not execute the later MG28 policy**.

- **1,817** prior-public-change-supported hypothetical decision points, **1,717 before first positive reward** in their role/family history (NR-M1O corroboration).
- Alternatives actually supported: **1,051 left turns**, **41 right turns**, **725 forwards**. **Zero** pickup/drop/toggle/done action alternatives.
- **Zero of 1,817** alternatives had a previously observed **same-context** strict task effect (source door opening, exact target pickup, or terminal goal). The source did contain 51 door openings, 22 door closings, target first sightings and one true original terminal pickup; their evidence was simply *not selected by this change-rate decision rule*.
- **1,092** eligible decision points had exclusively turning alternatives; the other 725 had at least one forward alternative whose view change cannot prove physical progress. These are **necessary historical support upper bounds only**, not real MG28 changed action choices, causal interventions, counterfactual returns or measured native learning.

## Decision: retire raw-view-change as a goal relevance proxy

**MG28 mechanical pre-goal support is real; task-relevant decision evidence is absent in this source-readout for the same support rule.** An existing native parent still decides the actual selected action. Do not claim that the later MG28 policy or any other mechanism would be guaranteed to make zero real-world progress: different selected actions would produce a different trajectory.

**Next eligible research mechanism (new hypothesis requiring separate native source-owner qualification):** integrate a source-public action-consequence learner that estimates *task-relevant* outcomes, distinguishes original door opening from door closing, exact mission target acquisition from mere sighting, and factual terminal reward from scene novelty. Preserve native Wingless/Yggdrasil architectural independence and strict source-selected feedback/checkpoint ownership. Prior same-context evidence may be too sparse to support an override; the learner must abstain instead of acting on synthetic rewards, novel pixels or hidden goal scripts. Compare with equally trained original-data-access conventional Bayesian/model-based/recurrent alternatives, original selected goal/return changes on **new authorized** DEV cohorts, cold restart and full CPU/RSS/storage/interaction accounting. No first-use, promotion, controller, queue, production native, or source-world edits from NR-M1P.
