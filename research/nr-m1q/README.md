## What the mechanism actually learns

It accumulates own source-selected action / observed after-public-state **counts**, separately for literal original pickup mission, original heading and front object/color/state; it labels ONLY:

1. Observed selected action **toggle 5** when a publicly visible door's front pixel changes from `closed/locked` to `open` with unchanged color and heading.
2. Observed selected action **pickup 3** when the public-front object **exactly** matches the literal public pickup mission and the next public-front cell is floor with unchanged heading.

No reward is required to record a genuine door opening, so the model can obtain a bounded, task-relevant record **before its first successful goal reward**. Door **closing**, public scene/view changes, selected **turns**, target **sightings**, guessed paths, unknown objects and unselected alternate outcomes do **not** create positive task evidence. These are **engineered public semantics**, not independently discovered causal concepts.

An optional guard may change the original parent's proposal **only** to action 3 or 5, with >=2 prior source-selected observations for both inherited parent action and proposed alternative in the same original-public context, at least one actual relevant effect for the candidate action, source-only Laplace rate >=0.50 and >=parent+0.10. Otherwise it explicitly preserves the original parent's chosen action. There is no claim these thresholds are optimal or that an override on a real source will improve goals. Complete public-source selected action/returned consequence ledger conservation and SHA-canonical cold checkpoints are enforced in native forms.

## Qualification and scientific stop rules

Source-free regression tests examine authentic public-shape synthetic fixtures (NOT synthetic world performance): turns versus door-open/close, exact mission pickup, irrelevant object, prior support abstention, inherited source-selected feedback, replay rejection, full native parent checkpoint continuity, poisoned snapshot rejection and opt-in disabled policy. Both native repositories have Linux/Windows focused qualification workflows; independent stricter ICE/G29 atlas tests must also pass without bypass/waiver.

**Strict science NO-GO until separate source-owner approval** and preregistered original first-use new eligible cohorts, with actual selected action sequence and returns against matched enabled/disabled, no-effect/mission-blind/shuffled-outcome and adequately trained conventional recurrent/model-based/Bayesian controls under full input parity and resource limits. Source-only event fidelity, optional policy overrides on engineered fixtures or a green focused build do NOT prove improved action learning, retention transfer, or independent self-improving intelligence.

The current historical MG56 selected native MG19 corpus had **zero** MG28-supported alternative decisions with prior same-context task effects, despite 51 visible door openings and a genuine pickup. Therefore even a correct new task learner might abstain on those histories. It must NOT be evaluated by reusing exposed DEV seeds as sealed evidence. A real improvement would have to be demonstrated prospectively with new authorized source interaction and fair strong trained controls.
