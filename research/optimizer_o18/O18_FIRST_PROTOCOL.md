## Prospective falsifiable hypothesis
O17 phase-gating did not improve performance at delay k8 and its phase-rotation ablation was behaviorally indistinguishable. O18 tests *record-specific* observed-reward credit: whether learning to evict a record as a function of its age, repeated suits, and previous actual successful retrieval improves limited-memory decision rewards relative to equally trained strong controls. A fixed architecture with hand-designed time/age/suit/use features is not autonomous cognition. No privileged counterfactual target is available. Score-function gradients use only actual source-returned rewards from earlier actions, so any 'causal' label refers to chronological action→reward eligibility, **not identified counterfactual causal effects**.

## Frozen six arms
1. `RECORD_CREDIT`: 8 trainable linear logits on SKIP or eviction of each existing record, features bias, candidate record age/lag, recency-to-lag, equality of stored suit to incoming suit, prior genuine read frequency for that record, timestep normalized to lag and candidate position. Training stochastic softmax at saturation; decisions logged in a bounded chronological eligibility queue. After *actual* source `step`, signed reward for the executed public action credits prior choices no more than `learned_lag` old via score-function gradients; baseline = running training-only mean actual signed reward, LR .01, clip logits weights to ±6. No reward from future actions, oracle labels, synthetic counterfactuals or per-DEV updates. DEV selects max learned logit deterministically. Reused O16 memory container with 4 records, plus audited bounded training-only eligibility and 4 use counters.
2. `O17_PHASE_GATE`: frozen previous O17 four-logit learned phase writer, re-FIT on 48 genuine source episodes, equal original FIT.
3. `O16_LEGACY_EVICTION`: frozen previous O16 learned writer, re-FIT on the identical genuine 48 source episodes.
4. `TRAINED_STRIDE`: conventional stride periods 1/2/4 chosen only from 48 genuine original FIT episodes partitioned into three frozen groups of 16, no privileged target.
5. `FIFO`: always-write, oldest replacement, 4 slots.
6. `RECORD_FEATURE_ABLATION`: copy of the same trained O18 8 weights and same readout, but set record-age, age-to-lag, record-usage and equal-suit features to zero at DEV; never separately FIT/retuned. This tests whether features informative about records matter beyond learned bias/clock.

Readout for all arms: if timestamp `t-learned_lag` is present in own 4 records choose stored suit; otherwise choose public current suit. Writes happen only **after** `step` and feedback and cannot alter previously executed action. No writes during reset prior to first original step.
