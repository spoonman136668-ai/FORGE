## Question

Do R6 conventional learners fail because of *causal-sequence trainability* or merely because the public event ontology changed? R6's trained structured planner recorded **zero updates**, because R5's public event types did not match the R4 type names expected by its frozen statistics trainer. A separate FORGE R6 neutral-ontology study (PR #751, source `d1c2eee8c7863349aa0721fe7a480473e052dde0`, file `research/itd01/r6_neutral_ontology.py`) has already qualified a fail-closed **public-observation-only** mapping. Reuse those exact source bytes, with no modification to any R4/R5/R6 model or environment, to train three conventional learners on fresh public R5 experiences. This asks a narrow and falsifiable representation question, NOT whether a learned Wingless/Yggdrasil native architecture transfers.

## Frozen conditions / intervention

- Identical **R5** public three-stage causal worlds A and B (unchanged source), original scripted PUBLIC teacher and same three R4 model architectures and hyperparameters, fitting **from scratch**. All models receive the same normalized PUBLIC demonstration observations, public acts, delayed observed effects, public reward and no hidden true roles or source labels.
- The only intervention is an external semantic input adapter: normalize every public observation using exact qualified `r6_neutral_ontology.normalize_public_observation`, then express `observed-effect` with PUBLIC partial/ready as the preexisting R4 abstract `relay_pulse`, `observed-confirmation` as `relay_stable`, public unrelated events as `ambient_drift`. Both recorded FIT training features and action-time inference features/history (including the control's own history object) must pass through the same adapter. This is a human-designed representational prior, NOT self-discovered causal abstraction; attribute benefits accordingly.
- Exactly three frozen existing model classes: BPTT recurrent (8-state, 3 epochs, .055 rate); 2-stage public-delay/planner with empirical statistics (explicit structural prior disclosed); explicit case-memory. Each trains on exactly 240 A + 240 B identical PUBLIC teacher trajectories per initial seed, no extra class/prior/parameter/hyperparameter changes. All source roles are disjoint from R6 and from each other.
- Frozen seeds `{17,31,47}`; for each seed, R7 world seed `21_000_000 + role_index*2_000_000 + seed*10_000 + family_index*100_000 + episode_index`, role `FIT=0, VALID=1, DEV=2, ABLATE=3`. Every R7 episode ID is `DEV-R7-<ROLE>-<SEED>-<FAMILY>-<INDEX>`. This matches the original public wire format and is distinct from consumed R4/R5/R6 episodes.
- Generate 80 A + 80 B NEW VALID examples per seed and each model; validate fitted checkpoint with no updates. Only after all three models have completed all FIT + VALID are DEV episodes first generated: 80 A + 80 B NEW distinct DEV examples per seed and model. Never select based on DEV. After checkpoint freeze, 40 A + 40 B ABLATE episodes per seed/arm/mode with exactly paired seeds for normal/erased/blinded. Erase public history AND per-task model state, blind both PUBLIC events and history object, preserve action catalogue and budget.
- Report per-arm both-family success/legality/action count on VALID+DEV, update count, model checkpoint digest and serialized bytes, public-teacher trace digest, input adapter hash, full CPU for generating teacher training and all model fits/evaluations/ablation, shared RSS. Do not claim per-model independent memory parity or mathematical cross-OS bit identity. Store authentic positive AND negative model evidence.
- **Representation hypothesis supported at engineering DEV level only** if structured planner has >0 bona fide FIT updates on all three fresh seeds and at least one of its both-family validation success rates increases over frozen R6's exactly-0-update baseline while all action/evaluation roles remain fair. Otherwise `PUBLIC_EVENT_BRIDGE_TRAINABILITY_NEGATIVE`. This is mechanistic validation, not native cognitive superiority. For separately benchmark-qualified validation, the R4/R6 *unchanged* requirement applies: at least two independent fully trained model classes have each-family VALID success [0.40, 0.85], legal fraction 1.0 on ALL three seeds, otherwise `BENCHMARK_NOT_QUALIFIED_RETAIN_NEGATIVE`. No retuning the ceiling/floor if results fail.
- Include a no-adapter negative control on tiny handcrafted/public smoke inputs to demonstrate new-event name mismatch; do **not** rerun consumed R6 FIT/DEV cohorts or use previously seen DEV as training.
- Fully explain any mismatch between PUBLIC event categories that the adapter merges: this mapping can erase distinguishability between source-pulse and relay-pulse stages, and should NEVER be claimed to identify the causal stage in a privileged way.
