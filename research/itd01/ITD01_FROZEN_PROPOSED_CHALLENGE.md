## Standing scientific purpose and boundary

ITD-01 is the first integrated test of **acquisition through interaction -> autonomous representation -> persistent retention -> compositional reasoning -> transfer to independently unfamiliar task families**. This is a research milestone toward independent, native, non-transformer, eventually LLM-class cognitive systems. NCI-04 is the immediate underpinning, not the ceiling. A good score on a synthetic subcomponent is insufficient. Wingless and Yggdrasil remain independent model families and may learn different representations and memory rules. Neither may delegate its native cognition to a conventional LLM. Conventional transformers are allowed solely as explicitly labeled comparators.

R32's source-free active exploration NO-GO and R23-R31 positives and negatives are preserved; do not rerun or reinterpret them. Any separately active frozen work finishes before the corresponding lane switches. Do not unpause the restored CKB-plane R18 controller, launch held scientific first use, invoke another authority, touch KTRADE or original MiniGrid/Pycolab reset cohorts, or merge an active research branch because this document exists. All original P0F-C2 seeds remain scientifically unadmitted until the existing CKB owner proves source/consumption custody.

## Hypothesis

A system whose native persistent learned state supports causal exploration, long-delay memory and compositional reuse will solve **both** novel interactive world families better than the strongest independently trained conventional control **under the same observation/action access and hard resources**, while retaining capabilities through unrelated intervening experiences. Failure in either new family or retention counts against the integrated claim; no cherry-picking a high-performing subskill.

## World and action contract (common exterior, independent interiors)

Use a versioned, deterministic interface, with private stochastic reset stream and bounded logs:

- reset(task_spec_public, seed) -> public Observation; exactly one reset per task ID per run; hidden generator parameters never included in task_spec_public.
- step(public Action) -> new public Observation, public reward, done, budget; environmental validity checked BEFORE applying action. Private state remains inaccessible. No privileged world model, target answer, hidden causal graph, family name, or judge truth may enter a learner.
- observation = {schema, episode_id, turn, entities, observations, delayed_events, public_goal, interaction_budget_remaining}. Entity IDs are uniformly renamed per episode. Observation can omit causal effects; delayed_events may arrive 1–4 steps after an intervention.
- action = {verb: inspect | intervene | wait | commit, target: public_entity_id_or_null, value: bounded_public_token_or_null}. Invalid target and out-of-budget action end the task as failure without a retry. Both original learners and all controls use precisely these external verbs.
- each world supplies a public catalogue of legal entity IDs, observable feature names, and bounded action values. No free-form code or shell access. A final commit is correct only when the world private judge verifies the public goal's causal end state, not a memorized answer string.
- An episode contains <= 24 investigative turns and <= 16 execution turns, no more than 40 total interactions, then one commit. Observation sizes <= 16 KiB; all agents receive the exact same public transcript. Action/observation receipts include hash chain, deterministic source/seed identity, actor identity, timestamps measured by trusted runner, and rejection counts.
- A hidden dependency must require at least two interventions to distinguish plausible causal hypotheses, and at least one effect is delayed. Every supported family must contain counterfactual intervention tests and public identifiability proofs: an independent oracle limited to the SAME public interface can obtain >= 0.80 task success at <= 40 interactions on development calibration. Oracle access to private truth can be used for *instrument validation only*, never to train or help an evaluated agent.

## Interactive family split and genuine independence

**Public TRAIN A:** delayed relay/service circuits with interventions, unreliable sensors, hidden multi-hop dependencies and delayed failures. **Public TRAIN B:** thresholded resource-flow/repair processes with storage, delayed replenishment, partial inventories and causal side effects. They share only external protocol, not internal update code. Frozen training stream: 4,000 A tasks, then 4,000 B tasks, then 4,000 alternating A/B tasks, total **12,000 episodes per initialization**. Up to 40 interactions/task; no extra training samples, expert labels, hidden truth or simulator rollouts that bypass the action budget.

**Public VAL:** exactly 600 new tasks in A and 600 in B per trained initialization; select model checkpoint/hyperparameter only from these. Fit exactly three initializations with predeclared IDs 17, 31 and 47 for EACH candidate and baseline. No separate private validation.

**Intervening-experience retention test:** after training on A, checkpoint the learner on 400 separate public A diagnostic tasks; then expose it to 240 B experiences with permitted continual learning; test the *same capability distribution* on 400 different A diagnostic tasks (pre/post tasks are disjoint and balanced). Resume from a serialized learned state after a clean process restart. Both native systems and baselines have identical A/B order and resource limits. Training these 240 B episodes consumes a declared part of the 4,000 B schedule, not extra episodes.

**Independently born HELD H1:** novel fault isolation/recovery in a dependency network, with a different environment author, source tree, semantic names and world-generation algorithm; new sensor/event combinations, unseen intervention side effects and delayed downstream consequences. **Independently born HELD H2:** novel ecological process control with interacting populations and delayed feedback, another distinct author/source algorithm; same exterior protocol but different physical causal laws, goal structure, entities and code. These are *not* re-skins of A/B, not a changed seed of R23-R32, and not original MiniGrid/Pycolab historical cohorts.

Each held family = **480 independent tasks** evaluated under EACH of the three frozen model initializations, with paired task/reset IDs across architectures. Minimum 96 tasks per family require two or more causally chained interventions; minimum 96 test delayed effects. Evaluation reveals only public observations, actions, and aggregate statistics after all runs. Public in-task exploration/state updates permitted; **no gradient training, checkpoint selection, cross-episode persistent update or held episode replay** between H1/H2 tasks. Reset each held task's learner to the identical preheld checkpoint; newly learned in-task state may be used only inside that task. All H1/H2 data are generated independently only AFTER the design and immutable model freeze.

H1 and H2 source families must be separately implemented and attested by an evaluator independent of either learner team. Publish code SHA, upstream/license, source-birth timestamp/witness, exposure/consumption IDs, held split commitment, and contamination review before FIRST use through the existing CKB owner and independent scientific custodian. If the independent birth or original-consumption ledger is not available, **no protected first use** occurs; developer-only public synthetic qualification may continue as a separate evidence class.

## Completely independent implementations

**Wingless** supplies its OWN native learned compressed causal/predictive state and bounded persistent memory; existing broker/LLM adaptor output does not count as native cognition. **Yggdrasil** supplies its OWN developmental/cellular local update, bounded communication, genotype/phenotype and retained state; a conventional GRU wrapper performing the reasoning does not count. They may receive the same protocol fixtures and measured public interaction logs, but do not exchange model internals, weights, architectures, recurrent modules or hidden evaluation data. Their scientific claims are assessed separately, not pooled to make a combined winner.

**Strong conventional controls, equally informed, fitted from scratch:** GRU/LSTM recurrent agent with action-conditioned observation, a learned predictive world-model/planning agent with matched public interactive rollouts, and a trained explicit episodic-memory agent with retrieval/decision policy. Include random-policy and hand-designed public heuristic as lower bounds; include an ideal/structurally informed oracle only as an unprivileged-scoring explanatory upper bound, NEVER in the resource-matched baseline pool. Controls receive every ordinary training episode and previous public feedback made available to candidates; none receives hidden family identities, private causal graph, solved labels outside public terminal feedback, extra tasks or simulator truth. Three frozen initialization IDs and one fixed public validation selection rule apply to every architecture.

## Frozen hard resource and capacity budget

Per model initialization, shared CPU-only reference host, **two pinned logical CPU cores, zero GPU**, maximum 12,000 A/B train episodes (plus 1,200 public VAL episodes), 40 interactions per episode, maximum **5,400 process CPU seconds** for all training/replay/simulation/world-model planning and validation, maximum **2 GiB peak process RSS**, maximum **32 MiB all serialized persistent weights/genome, checkpoints needed to resume, memory, metadata and state**, maximum **8 MiB live resident learned/task state**, maximum **16 KiB observation** and **one agent action per turn**. Include environment simulator CPU in a separately reported common ledger; all learner-controlled forward-model rollouts and memory retrievals belong to learner CPU/step costs. Include optimizer state, gradients, latent plans, routing/communication, cache, deserialization/restart, remote calls and interim agent scratch if used; no unmetered external inference or hidden disk spill. Model may use fewer resources; spending unused episode budget on extra model updates is permitted only inside the declared 5,400 CPU-second cap.

Prospective optional **Tier B** is already specified and NOT auto enabled: 64 MiB serialized persistence, 16 MiB live state, 10,800 training CPU seconds, same episodes and interaction limits. It can be selected for the WHOLE comparator set by an immutable, separately qualified source/budget amendment signed BEFORE any H1/H2 birth or first use, **never after viewing held scores**. Tier A is primary by default. Tier B does not inherit positive Tier A qualification and must be reported separately.

For all compared models use a single host class and OS/precision/threading regime, same agent API and fixed episode order; report model params and genome bytes; active/resident/retained phenotype bytes; complete training, validation, held and restart CPU seconds; wall time; per-task action latency; peak RSS/VRAM; disk/IO bytes; memory reads/writes and communication bytes; all interaction/action counts; episodes to achieve public validation thresholds. A missing or inconsistent cost ledger is INVALID, not an efficiency pass.

## Frozen decision rules (do not change after publication)

Metric: binary end-to-end successful **causal goal completion** per held task within the budget, scored on exact private post-commit state, NOT per-step prediction accuracy. Compute a paired family-level average over the same 480 held task IDs and all three seeds. The strongest control is the maximum held success among the THREE **fully trained** GRU/LSTM, public world-model planner and explicit memory agents (selecting the strongest held control is conservative; no control retraining/selection is allowed after seeing held).

One prespecified uncertainty method: **10,000 stratified paired bootstrap resamples of unique task IDs within each held family**, retaining each task's 3 training-init scores and all model/control pairings; fixed bootstrap RNG seed 95001; all labels masked to model developers. Confidence bound is 2.5th percentile of the paired delta. Compute each family and pooled equal-weight family estimate.

**ITD-01 INTEGRATED TRANSFER PASS** requires the entire conjunction:
1. H1 AND H2 candidate held solve rate >= **0.60** each; candidate minus strongest conventional control >= **0.05** absolute **in each family**, paired 95% bootstrap delta lower bound >= **0.02** in each family; equal-weight pooled gain >= **0.07**. Do not replace these criteria with the illustrative 10-percentage-point target after seeing data.
2. Familiar retention: A post-B success >= **0.65**, absolute A pre-to-post drop <= **0.05**, and no more than **0.05** greater drop than the best explicit-memory control, under the same intervening experiences and an actual state-serialization/restart recovery.
3. Causal ablation: removal of in-episode learned causal history, while preserving identical action/observation budgets, causes >= **0.05** absolute decrease in held completion (averaged over H1/H2); separate randomized-informative-intervention ablation decreases held completion >= **0.05**. Retention-memory erase after B also decreases familiar retained success by >= **0.05**. These conditions demonstrate functional reliance, not merely descriptive representation visualizations.
4. Novel composition: on pre-tagged (BEFORE reveal) subsets requiring >= two linked hidden causal effects, success >= **0.55** in each H1/H2, and agent has verified nonzero causal intervention dependence. An independent posthoc sensor-label probe alone cannot count.
5. All action legality/custody and resource hard limits PASS; no forbidden privileged private-field access, hidden evaluator answer exposure, off-protocol actions, extra first-use, external LLM inference, out-of-budget calls or accepted-ref modification. Source/actor/model/seed/runner binary snapshots and frozen held provenance match original attestations.
6. For the strict resource-matched integrated qualification, full model-controlled training+evaluation CPU time and peak RSS must not exceed **1.25x** the strongest conventional control's measured values on that SAME hardware, and persistent bytes <= that control's bytes **or** the shared hard 32 MiB cap, whichever is larger. Always separately report absolute CPU, RAM, retained and active bytes and environmental costs. If transfer is positive but this efficiency condition fails, classify **CAPABILITY_ONLY_RESOURCE_NO_GO**, not full integrated pass.

The absolute thresholds are **a priori conservative proposed v1 scientific criteria**, not calibrated from secret results. Source-free public development calibration must establish that (a) a public-only legal-action oracle reliably reaches >= 0.80 on A and B under 40 actions and (b) at least two fitted conventional baseline classes reach >= 0.40 but <= 0.85 on A/B VAL, preventing trivial ceiling/floor. If these fixed eligibility checks fail, v1 is classified **BENCHMARK_NOT_QUALIFIED**, and any revision is a distinct prereg and held lineage, never a retuned v1 success. Do NOT touch H1/H2 first use to calibrate thresholds.

**NO_GO** if all custody/resource/evaluator validity checks PASS but any scientific criterion fails. **MIXED / CAPABILITY_ONLY_RESOURCE_NO_GO** if transfer, retention and causal checks pass but resource gate fails. **INVALID / CUSTODY_INDETERMINATE** for missing/unknown historical first use, failed source birth, unknown task contamination, broken reviewer independence, evaluator inconsistency, accidental hidden truth exposure, incomplete original-run logs or unreproducible source identity. A scientific negative is never reclassified infrastructure-invalid merely for being unfavorable.
